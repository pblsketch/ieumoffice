# 设置、语言、主题与 MCP 集成

## 打开设置

主屏左下角的那一行打开设置面板（还没有连接 AI 时显示为「连接 AI」）。面板共五个分区：账户、AI、通用、集成、关于。

**账户**显示你的 Claude、ChatGPT 和 Codex 连接当前的状态，**管理连接**会带你到 AI 分区。AI 有专门的两篇说明：[订阅连接](help://subscription)和 [AI 模型与设置](help://ai-models)。

## 语言

- 设置里可选 **22 种界面语言**：简体中文、English、日本語、한국어、Français、Deutsch、Español、ไทย、Bahasa Indonesia、Русский、العربية、Português、Italiano、Polski、Čeština、Nederlands、Bahasa Melayu、עברית、हिन्दी、繁體中文、Tiếng Việt、土耳其语。
- 切换立即生效并持久化；菜单栏（主进程菜单）随语言重建。

## 主题

浅色 / 深色 / 跟随系统三种。跟随系统时随 OS 外观自动切换，编辑器区域同步换肤，无闪白。

## 通用

- **AI 侧边栏位置**（左或右）、**AI 面板文字大小**和**AI 对话拼写检查**。
- **AI 面板** —— 可选择关闭、收起或上次状态。
- **所有文档自动保存** 会让每个编辑器默认开启自动保存；单个窗口仍然可以关掉。
- **默认保存位置**配**更改**按钮，以及**设为 Office 文档默认程序**，把 .docx / .xlsx / .pptx 交给 GenOffice 处理。
- **新建韩文文档的保存格式** 决定新建韩文文档首次保存时优先提供 HWP 还是 HWPX。已打开的文档仍按其原有格式保存。
- **AI 幻灯片字体** 设置请求中未指定字体时 AI 新建演示文稿所用的字体。可选择自动、黑体、宋体或仅标题用宋体，并分别更换黑体字体和宋体字体。选择设计模板时使用模板的字体；向已使用其他字体的演示文稿添加页面时，沿用该演示文稿的字体。

GenOffice 不收集也不发送使用统计，所以这里没有相应的开关。

## 编辑器与 AI

在这里选择要使用的编辑器，以及是否使用 AI。同样的列表还会在另外两个地方出现一次：首次启动时欢迎界面中的**选择要使用的编辑器**步骤，以及在这个设置出现之前就已在使用 GenOffice 的人在主页上看到的一次性窗口。一开始全部是打开的，保持原样就什么都不会改变。更改会立即应用到所有打开的窗口。

- **编辑器**：Word、Excel、PowerPoint、PDF、PDF 工具、Markdown 与文本、HTML、思维导图、图表、HWP、电子书（EPUB）。PDF 工具与 PDF 编辑器分开开关。至少要保留一个编辑器处于打开状态。
- **关闭的编辑器**会从新建文档的列表中消失：主页卡片、标签栏的 **+** 菜单、文件 ▸ 新建，以及默认应用列表。已经打开的文档不会被关闭，恢复副本也会保留。
- **打开已关闭编辑器的文件时**（双击、拖放、文件 ▸ 打开、最近的文件），会请你在**启用并打开**和**取消**之间选择。一次打开这个编辑器的多个文件，也只问一次。
- **会把结果用已关闭的编辑器打开的其他功能**（例如把 PDF 转换成那种格式）会在开始之前询问：**启用并打开**、**仅创建文件**（创建文件并在文件夹中显示，编辑器保持关闭）或**取消**。
- **关闭 AI 功能后**，AI 面板、AI 按钮和菜单、主页的提问面板、智能体窗口以及 AI 连接提示都会消失，设置中的账户、AI、技能标签页也会隐藏。GenOffice 不会从界面启动任何 AI 程序。登录、密钥、技能和设置都会保留，重新打开 AI 后原样恢复。如果仍有 AI 任务在运行，会先问你是否**停止并关闭**。
- 无论编辑器或 AI 是否关闭，命令行、MCP 和本帮助都照常工作。

即使 AI 处于打开状态，AI 也不会为已关闭的编辑器新建文档，而是提示你在这里打开那个编辑器。

## AI ▸ 高级

默认是收起的，要你自己展开；大多数人用不到它。**AI 模型**页签里是对话用的 API 密钥和你自己运行的服务器。在**生图、媒体与搜索**页签里，每项能力自己挑提供它的服务商，服务商的密钥和基础地址只填一次，之后各行共用：

- **网络搜索**、**生图**、**图片解析**和**视频解析**，每项都有服务商、模型、密钥和基础地址。
- **本机文件搜索**跑在这台机器上。它下面的 **Jev 搜索重排** 默认关闭。打开后，本机搜索前 20 条命中的片段——每份文档最多 1,200 个字符，外加文件名和文件夹名——会发给你选择的决策端点（OpenRouter 或 TypeSafe 的 Jev、Perplexity、Liquid AI d1、Cloudflare、本地引擎或自定义 URL），按相关性重新排序。关闭时不会有任何东西离开本机。
- **允许自动调用使用订阅**这一项**默认关闭**。它决定来自命令行或已连接的编程代理的请求，能否使用你的 Claude 或 Codex 订阅；见[连接编程助手](help://mcp)。

## 关于

- **版本**、项目的 GitHub 地址，以及一行说明，写明本应用所基于的开源项目。
- **更新通道**：稳定版或 Beta 版。改完立即生效并检查更新；它不会把 Beta 版安装退回稳定版。

## 默认应用绑定

设置里可以把 .docx / .xlsx / .pptx / .pdf 等格式关联为「由 GenOffice 打开」（写入系统级别的默认应用注册，按平台提示确认）。

## 第三方声明与更新

- 帮助菜单 ▸ 第三方软件声明：随包附带的完整开源组件许可清单。
- 菜单（☰） ▸ 检查更新（Mac 上为 帮助菜单 ▸ 检查更新）：手动触发一次更新检查；有新版本时提示安装。

## MCP 集成（面向高级用户 / AI 客户端）

**集成**是把 GenOffice 接到编程代理上的面板，它也有专门一章：连接编程代理。简单说就是——选一条路子（命令行或 MCP），照那一节做，然后开一个新对话直接问。

在**本地 HTTP 服务**下，应用也可以自己来跑这个服务——一个启用开关、一个端口——而**高级**会再加上健康检查的网址和日志文件——而不是交给助手去做。它只监听 localhost。
