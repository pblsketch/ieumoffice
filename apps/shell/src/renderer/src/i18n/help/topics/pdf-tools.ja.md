# PDF ツール

よく使う PDF の作業を、やりたいことから選んで処理するウィンドウです。結果は必ず新しいファイルとして保存され、元のファイルは変わりません。このウィンドウのツールはこの PC 内だけで処理し、AI は使いません。

## 使い方

1. ホーム画面で **PDF ツール** カードをクリックするか、PDF エディターの **ページ** タブから **PDF ツール** を開きます。別のウィンドウが開きます。
2. 作業を選ぶか名前で検索し、必要なファイルを選ぶかドラッグ＆ドロップしてオプションを決め、**新しいファイルとして保存** をクリックします。
3. 保存したら **タブで開く** ですぐに結果を確認したり、**フォルダーを開く** でフォルダーを開いたり、**このファイルで続ける** で結果をそのまま次のツールに渡せます。

## ツール一覧

| グループ             | ツール                                                                                                                        |
| -------------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| ページの整理         | PDF を結合、PDF を分割、ページを PDF として抽出、ページを整理、交互に結合、逆順に並べ替え、すべて回転、白紙ページを探して削除 |
| 印刷の準備           | 両面印刷用にそろえる、ページを集約、ページサイズ、ページを分割                                                                |
| 装飾                 | 背景を重ねる                                                                                                                  |
| 整理                 | 注釈をまとめて削除                                                                                                            |
| 変換                 | 画像から PDF を作成、文書を PDF に変換、画像を書き出す、PDF 変換、テキストとして保存、スキャン PDF OCR                        |
| サイズとセキュリティ | サイズを小さくする、パスワードを付ける、パスワードを外す、ファイルを修復                                                      |
| PDF エディターで     | 透かしとヘッダー/フッター、ページをトリミング、編集・署名・墨消し                                                             |

**PDF エディターで** グループのカードは、選んだ PDF をエディターのタブで開きます。リボンでその機能を選んでください。

## 知っておきたいこと

- 元のファイルや、未保存の変更があるまま開いているファイルには保存できません。
- ファイルをウィンドウへドラッグ＆ドロップして追加できます。単一 PDF ツールでは **一括処理** を使って複数の PDF を 1 つのフォルダーに一括処理できます（PDF を分割 を除く）。
- パスワード付き PDF を追加した場合は、ツール内でパスワードを入力してこの作業中だけロックを解除できます。保存されるコピーにはパスワードが付きません。パスワードがわからないファイルは開けません。
- **サイズを小さくする** は容量の内訳（画像・フォント・本文・メタデータ）を表示し、プリセット圧縮、目標サイズ指定、グレースケール変換、Web 表示の最適化、メタデータ削除に対応します。
- **ページを整理** ではサムネイルを見ながらページの並べ替え、回転、複製、削除、白紙ページの挿入、複数 PDF の組み合わせを行えます。
- **文書を PDF に変換** は Word、Excel、PowerPoint、HWP、Markdown、HTML、マインドマップ、EPUB ファイルを個別または結合した PDF に変換します。外部 Web 画像を参照する HTML や Markdown を変換する場合、通常のエディターからの PDF 書き出しと同様に画像 URL を取得することがあります。
- **スキャン PDF OCR** は内蔵のオフライン OCR エンジンでスキャン PDF に検索可能な透明テキスト層を追加します。
- **ファイルを修復** は読み取れる部分だけを取り戻します。新しいファイルを開き、欠けたページがないか確かめてください。
- **白紙ページを探して削除** は候補を表示するだけです。選んだページだけを削除し、1 文字でも文字があるページは候補に出ません。
- **注釈をまとめて削除** はフォームの入力欄を削除せず、リンクは選んだときだけ削除します。削除した注釈の内容は新しいファイルに残りません。
- **PDF を分割**では、範囲指定（1ファイルへの結合にも対応）、ページ数・均等分割、しおり別、最大ファイルサイズで分割でき、命名規則やサブフォルダ保存を選べます。

## こんなときに

| 状況                                                                       | 使うツール                          |
| -------------------------------------------------------------------------- | ----------------------------------- |
| 複数の文書を一度に両面印刷し、どの文書も表面から始めたい                   | 両面印刷用にそろえる → ページを集約 |
| 片面スキャナーで別々に読み取った奇数・偶数ページを 1 つの PDF にまとめたい | 交互に結合                          |
| ページの順番を変えたり、不要なページを消したり、白紙ページを差し込みたい   | ページを整理                        |
| スキャンした PDF を文字検索・コピーできるようにしたい                      | スキャン PDF OCR                    |
| Office、HWP、Markdown、HTML、マインドマップ、EPUB を PDF に変換したい      | 文書を PDF に変換                   |
| PDF のページを PNG や JPG 画像（または ZIP）として保存したい               | 画像を書き出す                      |
| PDF を Word、Excel、PowerPoint、HWPX、Markdown、EPUB に変換したい          | PDF 変換                            |
| メール添付の容量制限に合わせて PDF を小さくしたい                          | サイズを小さくする                  |
| 会社や団体のレターヘッドをすべてのページに入れたい                         | 背景を重ねる                        |
| 確認が終わった文書を送る前にコメントを整理したい                           | 注釈をまとめて削除                  |
| 複数の写真の向きや画質を整えて 1 つの PDF にまとめたい                     | 画像から PDF を作成                 |
| ダウンロードが途中で止まった PDF が開けない                                | ファイルを修復                      |
