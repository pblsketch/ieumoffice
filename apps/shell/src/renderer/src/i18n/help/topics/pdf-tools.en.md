# PDF tools

A window for everyday PDF tasks, starting from the task. The result is always saved as a new file and the original is not changed. The tools in this window work only on this PC and do not use AI.

## How it works

1. On Home, click the **PDF tools** card, or open **PDF tools** from the **Page** tab in the PDF editor. A separate window opens.
2. Pick a task (or search by name), choose or drop the files it needs, set its options and click **Save as new file**.
3. After saving, **Open in a tab** shows the result at once, **Show in folder** opens its folder, and **Continue with this file** sends the result straight into another tool.

| Prepare for print | Pad for two-sided printing, Merge pages, Page size, Split pages                                                             |
| Decorate          | Add a background                                                                                                            |
| Clean up          | Remove annotations                                                                                                          |
| Convert           | Images to PDF, Documents to PDF, Export images, PDF Converter, Save as text, Scan PDF OCR                                   |
| Size and security | Make smaller, Add password, Remove password, Repair file                                                                    |
| In the PDF editor | Watermark & header/footer, Crop pages, Edit, sign, redact                                                                   |

The cards in **In the PDF editor** open the chosen PDF in an editor tab. Pick the command there in the ribbon.

## Good to know

- You cannot save over a source file, or over a file that is open with unsaved changes.
- You can drag and drop files directly into the window. Single-PDF tools also support **Batch mode** to process multiple PDFs into one output folder (excluding Split PDF).
- If you add a password-protected PDF to a tool, enter its password inline to unlock an unencrypted copy for this task. A file whose password you do not know cannot be opened.
- **Make smaller** shows a space breakdown (images, fonts, streams, metadata) and supports presets, target file size, grayscale conversion, web optimization, and metadata removal.
- **Organize pages** lets you reorder, rotate, duplicate, delete, or insert blank pages using thumbnails, and combine pages from multiple PDFs.
- **Documents to PDF** converts Word, Excel, PowerPoint, HWP, Markdown, HTML, mind map, and EPUB files to PDF (individually or merged). When converting HTML or Markdown files that reference remote web images, those image URLs may be fetched during rendering, just like normal editor PDF export.
- **Scan PDF OCR** adds an invisible searchable text layer to scanned PDFs using the built-in offline OCR engine.
- **Repair file** brings back only the parts that can still be read. Open the new file and check that no page is missing.
- **Remove blank pages** only shows candidates. Only the pages you pick are removed, and a page with even one character is never a candidate.
- **Remove annotations** keeps form fields and removes links only when you tick them. What the removed annotations said does not stay in the new file.
- **Split PDF** can split by custom ranges (optionally merged into one file), page count or equal parts, bookmarks, or maximum file size, with custom naming and an optional subfolder.

## Try it for

| Situation                                                                       | Tools to use                             |
| ------------------------------------------------------------------------------- | ---------------------------------------- |
| Printing several documents on both sides at once, each starting on a front side | Pad for two-sided printing → Merge pages |
| Combining odd and even pages from a single-sided scanner into one PDF           | Interleave merge                         |
| Reordering pages, deleting extra pages, or inserting a blank divider page       | Organize pages                           |
| Turning a scanned PDF into a searchable PDF                                     | Scan PDF OCR                             |
| Converting Office, HWP, Markdown, HTML, mind map, or EPUB files to PDF          | Documents to PDF                         |
| Saving PDF pages as PNG or JPG images (or a ZIP archive)                        | Export images                            |
| Converting a PDF to Word, Excel, PowerPoint, HWPX, Markdown, or EPUB            | PDF Converter                            |
| Shrinking a PDF to fit an email size limit                                      | Make smaller                             |
| Putting a company or organization letterhead on every page                      | Add a background                         |
| Tidying up comments before sending a reviewed document                          | Remove annotations                       |
| Handing in several photos as one PDF with custom rotation and quality           | Images to PDF                            |
| A PDF whose download stopped partway will not open                              | Repair file                              |
