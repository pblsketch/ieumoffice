# Инструменты PDF

Окно для повседневных задач с PDF, организованное по действиям. Результат всегда сохраняется как новый файл, а исходный не изменяется. Все инструменты работают только на этом ПК и не используют ИИ.

## Как это работает

1. На главном экране нажмите карточку **Инструменты PDF** или откройте **Инструменты PDF** на вкладке **Страница** редактора PDF. Откроется отдельное окно.
2. Выберите задачу (или найдите её по названию), выберите или перетащите нужные файлы, задайте параметры и нажмите **Сохранить как новый файл**.
3. После сохранения **Открыть во вкладке** сразу откроет результат, **Показать в папке** покажет папку, а **Продолжить с этим файлом** передаст результат прямо в следующий инструмент.

## Инструменты

| Группа               | Инструменты                                                                                                                                                     |
| -------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Упорядочить страницы | Объединить PDF, Разделить PDF, Извлечь страницы в PDF, Упорядочить страницы, Чередующееся объединение, Обратный порядок, Повернуть все, Удалить пустые страницы |
| Подготовка к печати  | Подготовить к двусторонней печати, Объединить страницы, Размер страницы, Разделить страницы                                                                     |
| Оформление           | Добавить фон                                                                                                                                                    |
| Очистка              | Удалить аннотации                                                                                                                                               |
| Преобразование       | Изображения в PDF, Документы в PDF, Экспорт изображений, Конвертировать PDF, Сохранить как текст, OCR для сканов PDF                                            |
| Размер и защита      | Уменьшить размер, Поставить пароль, Снять пароль, Восстановить файл                                                                                             |
| В редакторе PDF      | Водяной знак и колонтитулы, Обрезать страницы, Правка, подпись, скрытие                                                                                         |

Карточки из группы **В редакторе PDF** открывают выбранный PDF во вкладке редактора. Выберите там нужную команду на ленте.

## Полезно знать

- Нельзя перезаписать исходный файл или файл, открытый с несохранёнными изменениями.
- Файлы можно перетаскивать прямо в окно. Инструменты для одного PDF также поддерживают **Пакетный режим**, позволяя обработать сразу несколько PDF в одну папку (кроме Разделить PDF).
- Если добавить PDF с паролем, введите пароль прямо в окне, чтобы разблокировать незашифрованную копию для этой задачи. Файл без известного пароля открыть нельзя.
- **Уменьшить размер** показывает структуру объёма (изображения, шрифты, потоки, метаданные) и поддерживает уровни сжатия, целевой размер, оттенки серого, оптимизацию для веба и очистку метаданных.
- **Упорядочить страницы** позволяет менять порядок, поворачивать, дублировать, удалять и вставлять пустые страницы по миниатюрам, а также собирать страницы из нескольких PDF.
- **Документы в PDF** преобразует файлы Word, Excel, PowerPoint, HWP, Markdown, HTML, интеллект-карты и EPUB в PDF (по отдельности или в один файл). При преобразовании HTML или Markdown со ссылками на внешние изображения эти адреса могут загружаться при отрисовке, как при обычном экспорте PDF.
- **OCR для сканов PDF** добавляет к отсканированным PDF невидимый слой текста с поддержкой поиска с помощью встроенного офлайн-OCR.
- **Восстановить файл** восстанавливает только те части, которые ещё можно прочитать. Откройте новый файл и проверьте, все ли страницы на месте.
- **Удалить пустые страницы** лишь предлагает кандидатов. Удаляются только отмеченные страницы, а страница хотя бы с одним символом никогда не попадает в список.
- **Удалить аннотации** сохраняет поля форм и удаляет ссылки только при явном выборе. Содержимое удалённых комментариев в новый файл не попадает.
- **Разделить PDF** поддерживает диапазоны (включая объединение в один файл), число страниц, закладки и ограничение размера файла, а также выбор имён и подпапки.

## Когда пригодится

| Ситуация                                                                                      | Какие инструменты выбрать                               |
| --------------------------------------------------------------------------------------------- | ------------------------------------------------------- |
| Распечатать несколько документов двусторонне за раз, чтобы каждый начинался с лицевой стороны | Подготовить к двусторонней печати → Объединить страницы |
| Соединить нечётные и чётные страницы с одностороннего сканера в один PDF                      | Чередующееся объединение                                |
| Изменить порядок страниц, удалить лишние или вставить пустой разделитель                      | Упорядочить страницы                                    |
| Сделать отсканированный PDF доступным для поиска текста                                       | OCR для сканов PDF                                      |
| Преобразовать Office, HWP, Markdown, HTML, карты памяти или EPUB в PDF                        | Документы в PDF                                         |
| Сохранить страницы PDF как изображения PNG или JPG (или ZIP-архив)                            | Экспорт изображений                                     |
| Преобразовать PDF в Word, Excel, PowerPoint, HWPX, Markdown или EPUB                          | Конвертировать PDF                                      |
| Уменьшить PDF под ограничение размера вложения в почте                                        | Уменьшить размер                                        |
| Наложить фирменный бланк компании или организации на каждую страницу                          | Добавить фон                                            |
| Убрать комментарии перед отправкой проверенного документа                                     | Удалить аннотации                                       |
| Собрать несколько фотографий в один PDF с нужным поворотом и качеством                        | Изображения в PDF                                       |
| Недогруженный PDF не открывается                                                              | Восстановить файл                                       |
