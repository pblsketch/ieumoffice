# Strumenti PDF

Una finestra dedicata alle operazioni quotidiane sui PDF, partendo dall’attività desiderata. Il risultato viene sempre salvato come nuovo file senza modificare l’originale. Gli strumenti funzionano solo su questo PC e non usano l’IA.

## Come funziona

1. Nella schermata Home fai clic sulla scheda **Strumenti PDF**, oppure apri **Strumenti PDF** dalla scheda **Pagina** dell’editor PDF. Si apre una finestra separata.
2. Scegli un’operazione (o cercala per nome), seleziona o trascina i file richiesti, imposta le opzioni e fai clic su **Salva come nuovo file**.
3. Dopo il salvataggio, **Apri in una scheda** mostra subito il risultato, **Mostra nella cartella** apre la cartella e **Continua con questo file** passa direttamente il risultato allo strumento successivo.

## Buono a sapersi

- Non è possibile sovrascrivere un file di origine né un file aperto con modifiche non salvate.
- Puoi trascinare e rilasciare i file direttamente nella finestra. Gli strumenti per PDF singolo supportano anche **Modalità batch** per elaborare più PDF in un’unica cartella di destinazione (tranne Dividi PDF).
- Se aggiungi un PDF protetto da password, inseriscila sul posto per sbloccare una copia non crittografata per questa operazione. Un file di cui non conosci la password non può essere aperto.
- **Riduci dimensioni** mostra la ripartizione dello spazio (immagini, font, flussi, metadati) e supporta livelli predefiniti, dimensione obiettivo, scala di grigi, ottimizzazione web e rimozione dei metadati.
- **Organizza pagine** consente di riordinare, ruotare, duplicare, eliminare o inserire pagine vuote dalle miniature e combinare pagine di più PDF.
- **Documenti in PDF** converte file Word, Excel, PowerPoint, HWP, Markdown, HTML, mappe mentali ed EPUB in PDF (singolarmente o uniti). Quando un file HTML o Markdown fa riferimento a immagini web remote, tali URL possono essere scaricati durante il rendering, come nella normale esportazione PDF.
- **OCR PDF scansionato** aggiunge un livello di testo invisibile e ricercabile ai PDF scansionati tramite il motore OCR offline integrato.
- **Ripara file** recupera solo le parti ancora leggibili. Apri il nuovo file e controlla che non manchino pagine.
- **Rimuovi pagine bianche** propone soltanto le candidate. Vengono rimosse solo le pagine spuntate, e qualsiasi pagina con almeno un carattere non è mai candidata.
- **Rimuovi annotazioni** conserva i campi modulo e rimuove i collegamenti solo se selezionati. Il testo delle annotazioni rimosse non resta nel nuovo file.
- **Dividi PDF** separa per intervalli personalizzati (anche uniti in un solo file), numero di pagine, segnalibri o dimensione massima, con formato del nome e sottocartella.

## Provalo per

| Situazione                                                                             | Strumenti da usare                        |
| -------------------------------------------------------------------------------------- | ----------------------------------------- |
| Stampare più documenti fronte-retro in una volta, facendo iniziare ciascuno sul fronte | Prepara per fronte-retro → Combina pagine |
| Unire pagine dispari e pari di uno scanner solo fronte in un unico PDF                 | Unione alternata                          |
| Riordinare pagine, eliminare quelle in eccesso o inserire una pagina bianca            | Organizza pagine                          |
| Rendere ricercabile un PDF scansionato                                                 | OCR PDF scansionato                       |
| Convertire file Office, HWP, Markdown, HTML, mappe mentali o EPUB in PDF               | Documenti in PDF                          |
| Salvare pagine PDF come immagini PNG o JPG (o archivio ZIP)                            | Esporta immagini                          |
| Convertire un PDF in Word, Excel, PowerPoint, HWPX, Markdown o EPUB                    | Converti PDF                              |
| Ridurre un PDF per rientrare nel limite degli allegati email                           | Riduci dimensioni                         |
| Applicare la carta intestata di un’azienda o ente su ogni pagina                       | Aggiungi uno sfondo                       |
| Ripulire i commenti prima di inviare un documento revisionato                          | Rimuovi annotazioni                       |
| Raccogliere più foto in un solo PDF scegliendo rotazione e qualità                     | Immagini in PDF                           |
| Un PDF scaricato solo in parte non si apre                                             | Ripara file                               |
