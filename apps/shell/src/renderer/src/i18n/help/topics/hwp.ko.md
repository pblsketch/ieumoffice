# 한글(HWP / HWPX): 편집, 작업창과 인쇄

GenOffice는 `.hwp`와 `.hwpx` 한글 문서를 탭에서 열고 고칩니다. 키보드 단축키, 스타일, 표, 메모, 인쇄와 AI 창을 함께 쓸 수 있으며 모든 작업은 이 PC 안에서 이루어집니다.

## 열기, 저장과 인쇄

- 홈, **파일 > 열기**, 창으로 끌어다 놓기, Google 드라이브에서 `.hwp`·`.hwpx` 파일을 열 수 있으며, **파일 > PDF 가져오기**로 PDF를 새 한글 탭으로 변환합니다.
- 열었던 파일 형식 그대로 저장하며(`.hwp`는 `.hwp`, `.hwpx`는 `.hwpx`), 첫 덮어쓰기 전에 `.bak` 백업을 남기고 HWP 다시 읽기 검사와 자동 저장·복구 사본을 유지합니다.
- 인쇄(Ctrl+P)는 실시간 미리보기, PDF 내보내기, 고급 인쇄 배치(모아찍기·소책자 등)를 지원합니다.

## 왼쪽 작업창: 개요, 찾기와 참고문헌

- 상단 막대 단추, **보기 > 작업창**(개요 / 찾기 / 참고문헌)으로 왼쪽 작업창을 열거나 **Ctrl+F**로 찾기 탭으로 바로 이동할 수 있습니다. 기존 찾기(**Ctrl+Q,F**)와 찾아 바꾸기(**Ctrl+H**)도 그대로 쓸 수 있습니다.
- **개요 탭**: 한글 기본 개요 문단과 스타일 매핑 제목(기본값 `제목 N` / `Heading N`, 개요 설정 서랍에서 문서별 또는 앱 전체로 맞춤 설정 가능)을 목록으로 보여 줍니다. 수준별 필터(`1`, `2`, `3`, ... 전체), 하위 항목 접기, 클릭 이동, 수준 올리기·내리기(기본으로 하위 제목 함께 이동, **Shift**를 누르면 해당 제목만 변경), 드래그로 절 단위 순서 바꾸기(실행 취소 1단계)를 지원합니다.
- **찾기 탭**: 본문, 표(중첩 표 포함), 글상자, 각주, 미주 전체에서(머리말·꼬리말 제외) 대소문자 구분, 온전한 낱말, 정규식, 문단 스타일, 글자 서식 조건으로 검색합니다. 결과를 누르면 바로 이동해 선택되며, 하나·선택 항목·모두 바꾸기를 실행 취소 1단계로 처리합니다(본문 내 개체나 인용 표시는 건너뛰고 건수를 알려 줍니다).
- 작업창은 열림 상태, 활성 탭, 너비를 기억하며 좁은 창에서는 아이콘 레일로 접히고 발표 모드와 인쇄 미리보기에서는 숨겨집니다. 작업창의 모든 기능은 AI 없이 동작합니다.

## 메모, 단축키와 AI 창

- 상단 막대나 **입력 > 메모**로 메모 열을 열어 문서 옆에서 일반 텍스트 메모를 읽고 추가·수정·삭제할 수 있습니다.
- 한글 문서 키보드 단축키, 가로 눈금자 문단 표식, 모양 복사(**Alt+C**), 한자 변환(**F9** / 한자 키), 문서 정보(**Ctrl+Q,I**)를 지원합니다.
- 선택 사항인 AI 창과 [터미널 명령어](help://cli)(`ieumoffice hwp read`, `ieumoffice hwp apply`)로 글, 스타일, 표, 수식, 쪽 설정, 개요, 검색 결과를 읽고 고칠 수 있으며, AI 편집 1회는 실행 취소 1단계로 묶입니다.

## 차례 만들기와 새로 고침

- **도구 > 차례 만들기**(또는 **도구 > 차례 새로 고침**, 차례 안 오른쪽 클릭)로 개요 탭의 제목 기준 **본문 차례**와 개체 캡션·캡션 문단 기준 **표 차례·그림 차례·수식 차례**를 넣을 수 있습니다.
- **점선 탭**(기본값) 또는 선 없는 2칸 **표** 모양을 고르고, 제목 깊이(1–10수준, 기본 3수준), 차례 제목, 클릭 이동 링크 포함 여부(차례 줄을 클릭하거나 **Ctrl+클릭**해 해당 제목으로 이동)를 정할 수 있습니다.
- 쪽 번호는 새 번호로 시작, 로마 숫자나 사용자 지정 번호 모양 등 문서에 실제로 찍히는 인쇄 기준 쪽 번호를 반영합니다.
- 차례를 새로 고치면 항목과 쪽 번호가 최신 내용으로 바뀌며, 손으로 직접 고친 줄이 있으면 덮어쓰기 전에 먼저 알려 줍니다. 다른 프로그램으로 만든 기존 차례가 표시 없이 들어 있으면 범위를 찾아 보여 주고 바꿀지 묻습니다.

## 색인 표시와 색인 만들기

- **도구 > 색인 표시**(또는 본문에서 오른쪽 클릭)로 선택한 낱말이나 커서 위치의 낱말을 색인 항목으로 표시할 수 있습니다. 하위 항목을 덧붙이거나 **같은 낱말 모두 표시**를 켤 수 있으며(본문만 대상이며 표·글상자·각주·미주 안에서 건너뛴 건수를 알려 줍니다), 같은 대화상자에서 기존 색인 표시를 보고 지울 수 있습니다.
- **도구 > 색인 만들기**로 커서 위치에 색인을 넣고, 문서가 바뀐 뒤에는 **도구 > 색인 새로 고침**으로 다시 맞출 수 있습니다. 기본 제목("찾아보기")은 원하는 대로 바꿀 수 있습니다.
- 색인은 가나다 → 영문 ABC → 기타 순서로 정렬되며, 자음·알파벳 머리 넣기, 1–3단 배치(기본 2단, 색인 구간에만 적용되어 문서 본문의 단 구성은 그대로 유지됨), **점선 탭** 또는 **표** 모양을 고를 수 있습니다.

## 낡은 차례·색인 알림과 제출본으로 저장

- 직접 저장, 인쇄, PDF 내보내기, 제출본으로 저장을 실행할 때 차례나 색인이 최신 문서와 다르면 알림을 띄워 한 번의 실행 취소 단계로 모두 새로 고칠 수 있게 해 줍니다. 이 검사는 자동 저장 중에는 실행되지 않으며 저장을 막지 않습니다.
- **파일 > 제출본으로 저장**을 쓰면 색인 표시·색인 구간 표시·저장된 설정 같은 내부 편집 표시를 뺀 깨끗한 사본을 별도 파일로 저장합니다. 차례와 제목 책갈피, 차례 이동 링크는 그대로 유지되며 원본 작업 파일은 건드리지 않아 나중에 계속 새로 고칠 수 있습니다.

## 참고문헌과 인용

- 왼쪽 작업창의 **참고문헌** 탭(또는 **도구 > 참고문헌**)에서 이 PC에 저장되는 단일 문헌 모음을 관리합니다. 검색, 태그 분류, 추가·수정·삭제, `BibTeX`·`RIS`·`CSL JSON` 파일 가져오기·내보내기와 함께, 기존 문서의 참고문헌 줄을 미리 보기로 확인한 뒤 모음에 읽어 올 수 있습니다.
- 네 가지 인용 양식(**APA 7**, **Chicago**, **MLA 9**, **IEEE**; 국문 문헌은 네 양식 모두에서 한국 학술 관례로 통일)을 지원합니다. 괄호·서술·다중 인용과 쪽수 지정을 본문에 넣고 내어쓰기 참고문헌 목록을 만들거나 새로 고칠 수 있으며, 양식을 바꾸면 표시된 인용과 목록이 실행 취소 1단계로 함께 갱신됩니다(직접 수정한 인용은 건드리지 않고 유지합니다).
- 내장된 6가지 인용 점검(목록 누락, 미인용 항목, 정렬 순서, 같은 연도 a/b 구분 기호 누락, 직접 수정한 인용, 미확인 문헌 인용)에서 항목을 눌러 해당 위치로 바로 이동할 수 있으며, 직접 저장·인쇄·내보내기 전에 낡은 참고문헌 목록과 IEEE 번호 어긋남을 알려 줍니다.
- 선택 사항인 AI 문헌 찾기(인터넷 도구 사용이 켜져 있을 때)로 찾은 후보는 항상 출처 주소가 메모에 담긴 **확인 필요** 상태로만 들어오며, 사용자가 직접 확인하고 **확인함**으로 표시하기 전에는 인용하거나 참고문헌 목록에 넣을 수 없습니다.

## 매크로: 키 기록과 스크립트

- **도구 > 매크로**(또는 **Alt+Shift+H**로 키 기록 시작·중지, **Alt+Shift+X**로 중지)를 쓰면 글자 입력, 커서 이동, 서식, 스타일, 표 등 지원하는 편집 동작을 바로 편집할 수 있는 스크립트로 기록합니다. 기록하는 동안 상단 막대에 기록 중 표시가 나타나며, 지원하지 않는 동작이나 마우스 클릭은 즉시 알리고 기록을 마친 뒤 건너뛴 목록으로 보여 줍니다.
- **매크로 관리**에서 이 PC에 저장된 매크로를 관리하고 최대 11개의 단축키 슬롯(**Alt+1**–**Alt+9**, **Alt+0**, **Alt+-**)을 지정하거나, 구문 오류의 줄·칸 안내를 보며 스크립트를 고치고 평문 `.ieummacro` 파일로 내보내거나 가져올 수 있습니다. 가져온 스크립트는 전문을 확인하고 저장한 뒤에만 실행할 수 있으며, 문서 파일 안에 들어 있는 매크로는 읽지도 실행하지도 않습니다.
- 모든 매크로는 앱 문서 API와 기존 매크로 스크립트 꼴(`HAction`, `HParameterSet`)을 지원하는 제한된 동기 해석기 안에서 실행되며, 시간·걸음·호출 깊이·크기 상한과 개체·메모 보호를 거칩니다. 실행 한 번은 항상 실행 취소 한 단계로 묶이며 오류, 미지원 동작, 한도 초과가 생기면 변경을 통째로 되돌립니다.
- 선택 사항인 **AI에게 쓰게 하기**(AI가 켜져 있을 때만 매크로 편집 창에 표시)에서 반복 작업을 설명하면 스크립트 초안을 만들어 줍니다. 사용자가 적은 설명과 매크로 API 안내만 보내며 문서 내용은 보내지 않습니다. 생성된 초안은 편집 칸에만 들어가며 자동으로 저장되거나 실행되지 않습니다.
