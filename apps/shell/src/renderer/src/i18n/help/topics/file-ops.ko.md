# 파일 작업: 이름 바꾸기, 삭제, 내보내기

이 장에서는 모든 편집기에 공통인 파일 작업을 설명합니다. 편집기마다 따로 있는 내보내기 선택지는 각 장에서 다룹니다.

파일 줄의 **⋯ 메뉴**(파일 줄에 마우스를 올리면 나타납니다)에 다음 작업이 모여 있습니다.

![파일 줄의 ⋯ 메뉴](img/file-ops.png)

## 이름 바꾸기

진입점은 두 개, 검사는 같습니다.

- 홈 줄의 **⋯ ▸ 이름 바꾸기**.
- **파일 탭을 더블클릭**해 그 자리에서 이름을 바꿉니다([탭과 창 관리](help://tabs-and-windows) 참고).

규칙: 확장자는 자동으로 유지됩니다. 잘못된 문자, 끝의 점, 예약 이름(CON/NUL 등)은 메시지와 함께 거부됩니다. 같은 폴더의 이름 충돌도 막힙니다. 디스크의 실제 파일 이름이 바뀌고 최근 목록과 즐겨찾기도 함께 갱신됩니다.

## 삭제

- 홈 **⋯ ▸ 삭제**: 어떤 파일인지 먼저 묻고, 그 파일들을 **시스템 휴지통**으로 옮깁니다. OS에서 되돌릴 수 있습니다. 이를 위해 GenOffice가 따로 보관하는 실행 취소는 없으며, 복구는 휴지통의 몫이지 알림의 몫이 아닙니다.

## 복제

**⋯ ▸ 복사본 만들기**는 같은 폴더에 "<이름> 사본"을 만듭니다. 이름이 겹치면 자동으로 번호가 붙습니다. 사본은 사용자에게 열지 않고 **최근 사용**에 추가됩니다 — 눈앞에 떠 있는 대신 한 번의 클릭 거리에 있습니다.

## 저장과 다른 이름으로 저장

- **⌘S / ctrl+S** 는 현재 파일을 저장합니다. 이름 없는 파일은 먼저 위치와 이름을 묻습니다.
- 대부분의 편집기에서 다른 이름으로 저장 창의 파일 형식 목록에 내보내기 형식(PDF, 그림, 다른 문서 형식 등)도 있습니다. 이런 형식을 고르면 사본만 쓰고, 열린 문서와 탭은 원래 파일 그대로입니다. 쪽이 여럿인 그림은 `이름-01.png`, `이름-02.png`…로 나뉩니다.
- **Docs**: 다른 이름으로 저장 목록에 한글 문서(.hwp, .hwpx)도 있습니다(파일 ▸ 한글 문서로 내보내기…도 같습니다). 메모, 수식, 글상자처럼 옮기지 못하는 것이 있으면 파일을 쓰기 전에 알려 줍니다.
- **다른 이름으로 저장**은 새 파일을 쓰고 원본은 그대로 둡니다. 그 뒤의 편집은 새 파일을 대상으로 합니다.
- 모든 저장은 아토믹입니다(임시 파일에 쓴 뒤 이름 변경). 쓰는 도중 종료해도 파일이 깨지지 않습니다.
- 자동 저장은 각 편집기의 토글을 따릅니다. 파일이 없는 새 문서는 첫 저장을 마친 뒤부터 자동 저장됩니다([빠른 시작](help://getting-started) 참고).

## PDF로 내보내기

- **Docs**: 파일 ▸ PDF로 내보내기(또는 리본 버튼). 현재 쪽나누기대로 내보냅니다.
- **Slides**: PDF 내보내기는 한 장씩 래스터화하며, 큰 덱에는 진행률이 표시됩니다.
- **Sheets**: PDF 내보내기는 인쇄의 쪽나누기를 따릅니다.
- 내보내기는 숨겨진 창에서 렌더링되고 고른 자리에 저장됩니다.

## Word/이미지로 내보내기

- **PDF ▸ Word로 변환**: PDF를 .docx로 바꿉니다(로컬 변환. 복잡한 레이아웃은 최대한 옮겨 보냅니다).
- **Docs** 는 페이지를 이미지로 내보낼 수 있습니다(한 장씩 PNG).

## 인쇄

각 편집기의 파일 ▸ 인쇄(⌘P/ctrl+P)는 인쇄 창을 엽니다. 워드·PDF·엑셀·슬라이드·마크다운은 원래 인쇄 창에, 한글은 인쇄 미리 보기에, HTML·마인드맵·다이어그램은 새로 생긴 작은 인쇄 창에 **쪽 배치** 칸이 있습니다. 쪽 배치에서 아무것도 고르지 않으면 전과 같은 방법으로 인쇄합니다.

- **배치 방식**: 한 장에 한 쪽, 한 장에 여러 쪽(2·4·6·9·16), 소책자(왼쪽·오른쪽 묶기), 포스터(가로·세로 장 수, 겹침 폭, 재단선), 라벨(쪽마다 한 칸씩 또는 모든 칸에 같은 쪽, 시작 칸, 흔한 A4 규격 또는 직접 입력) 가운데 하나를 고릅니다.
- **홀수 면만·짝수 면만·거꾸로 인쇄**: 배치를 마친 뒤 인쇄되는 면을 기준으로 셉니다. 양면 기능이 없는 프린터에서 앞면을 찍고 종이를 뒤집어 뒷면을 찍을 때 씁니다.
- **용지에 맞춰 줄이기**: 고른 용지보다 큰 쪽만 줄이고 작은 쪽은 키우지 않습니다. 엑셀과 마크다운은 원래 있던 용지·배율 칸을 씁니다.
- **회색조와 그림 해상도**: 쪽 배치의 선택지로 인쇄하면 쪽을 그림으로 바꿔 프린터로 보냅니다. 해상도는 자동·150·300·600dpi에서 고릅니다.
- **선택 영역만**: 워드와 마크다운은 고른 글만 첫 쪽부터 다시 나눠서, 슬라이드는 고른 슬라이드를, PDF는 고른 페이지를 인쇄합니다. 엑셀은 전처럼 선택 영역을 인쇄합니다.
- **배치도와 결과 미리 보기**: 종이 위에 쪽 번호가 어떻게 놓이는지 바로 보이고, **결과 미리 보기**를 누르면 실제로 만든 결과를 봅니다. **배치한 결과를 PDF로 저장**하면 다른 PC나 인쇄소에서 같은 모양으로 찍을 수 있습니다.
- **시스템 인쇄 창**: 소책자는 양면 인쇄를 짧은 쪽으로 넘기기로 고르세요. 쪽 범위와 한 장에 여러 쪽은 시스템 창에서 바꾸지 말고 그대로 두세요.

PDF는 현재 페이지 순서와 회전대로 인쇄됩니다.

## 이름 없는 파일은 어디에 두나

처음 저장할 때 고른 위치가 그 파일의 자리입니다. 그전에는 문서에 따로 파일이 없고, 저장하지 않은 내용은 앱 데이터 폴더의 복구 사본으로만 남아 앱이 갑자기 꺼져도 되살릴 수 있습니다([탭과 창 관리](help://tabs-and-windows) 참고). 자동 저장은 첫 저장을 마친 뒤부터 이어받습니다.
