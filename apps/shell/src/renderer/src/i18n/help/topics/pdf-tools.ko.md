# PDF 도구

PDF로 자주 하는 일을 할 일부터 골라 처리하는 창입니다. 결과는 언제나 새 파일로 저장되고 원본은 바뀌지 않습니다. 이 창의 도구는 이 PC 안에서만 처리하며 AI를 쓰지 않습니다.

## 쓰는 순서

1. 홈 화면에서 **PDF 도구** 카드를 누르거나, PDF 편집기의 **페이지** 탭에서 **PDF 도구**를 엽니다. 별도 창이 뜹니다.
2. 할 일을 고르고(또는 이름으로 찾고), 필요한 파일을 고르거나 끌어다 놓은 뒤 옵션을 정하고 **새 파일로 저장**을 누릅니다.
3. 저장한 뒤 **탭에서 열기**로 결과를 바로 보거나 **폴더 열기**로 폴더를 열고, **이 파일로 계속하기**로 결과를 다음 도구에 바로 넘길 수 있습니다.

## 도구 목록

| 묶음           | 도구                                                                                                         |
| -------------- | ------------------------------------------------------------------------------------------------------------ |
| 페이지 정리    | PDF 병합, PDF 분할, 페이지를 PDF로 추출, 페이지 정리, 교차 병합, 역순 정렬, 모두 회전, 빈 페이지 찾아 지우기 |
| 인쇄 준비      | 양면 인쇄 맞추기, 페이지 모아찍기, 페이지 크기, 페이지 분할                                                  |
| 꾸미기         | 배경 겹치기                                                                                                  |
| 정리하기       | 주석 한꺼번에 지우기                                                                                         |
| 변환           | 이미지로 PDF 만들기, 문서를 PDF로 변환, 이미지 내보내기, PDF 변환, 텍스트로 저장, 스캔 PDF OCR               |
| 용량·보안      | 용량 줄이기, 암호 걸기, 암호 풀기, 파일 복구                                                                 |
| PDF 편집기에서 | 워터마크 및 머리글/바닥글, 페이지 자르기, 편집·서명·가림                                                     |

**PDF 편집기에서** 묶음의 카드는 고른 PDF를 편집기 탭에서 엽니다. 리본에서 그 기능을 고르세요.

## 알아 둘 것

- 원본 파일이나, 저장하지 않은 변경이 있는 채 열려 있는 파일에는 저장할 수 없습니다.
- 파일을 창에 끌어다 놓아 바로 추가할 수 있습니다. 단일 PDF 도구는 **일괄 처리**로 여러 PDF를 한 출력 폴더에 한꺼번에 처리할 수 있습니다(PDF 분할 제외).
- 암호가 걸린 PDF를 도구에 넣으면 창 안에서 바로 암호를 입력해 이 작업 동안만 잠금을 풀어 쓸 수 있으며, 결과 사본에는 암호가 걸리지 않습니다. 암호를 모르는 파일은 풀 수 없습니다.
- **용량 줄이기**는 용량 구성(그림·글꼴·내용·메타데이터)을 보여 주며 단계별 압축, 목표 용량 지정, 회색조 변환, 웹 빠른 보기, 메타데이터 지우기를 지원합니다.
- **페이지 정리**는 축소판을 보며 페이지 순서 바꾸기, 회전, 복제, 삭제, 빈 페이지 넣기와 여러 PDF의 페이지 조합을 한 번에 할 수 있습니다.
- **문서를 PDF로 변환**는 워드·엑셀·파워포인트·한글·마크다운·HTML·마인드맵·EPUB 파일을 개별 PDF 또는 합친 PDF로 바꿉니다. 외부 웹 그림 주소가 든 HTML·마크다운을 바꿀 때는 일반 편집기의 PDF 내보내기와 마찬가지로 그 그림 주소를 불러올 수 있습니다.
- **스캔 PDF OCR**는 PC 안에 내장된 오프라인 OCR 엔진으로 스캔한 PDF에 검색 가능한 투명 글자 층을 넣습니다.
- **파일 복구**는 읽을 수 있는 부분만 되살립니다. 새 파일을 열어 빠진 페이지가 없는지 확인하세요.
- **빈 페이지 찾아 지우기**는 후보를 보여 줄 뿐입니다. 고른 페이지만 지우고, 글자가 한 글자라도 있는 페이지는 후보에 나오지 않습니다.
- **주석 한꺼번에 지우기**는 입력란을 지우지 않고, 링크는 고를 때만 지웁니다. 지운 주석의 내용은 새 파일에 남지 않습니다.
- **PDF 분할**은 구간 지정(하나로 합치기 포함), 페이지 수·등분, 책갈피(목차)별, 파일 크기 기준으로 나눌 수 있으며 이름 형식과 새 하위 폴더 저장을 고를 수 있습니다.
