# Работа с файлами: переименование, удаление, экспорт

Эта глава описывает операции с файлами, общие для всех редакторов; собственные параметры экспорта каждого редактора приведены в его главе.

**Меню ⋯** строки файла (наведите курсор на строку) собирает эти действия:

![Меню ⋯ строки файла](img/file-ops.png)

## Переименование

Два входа, один набор проверок:

- **⋯ ▸ Переименовать** в строке на «Главной».
- **Дважды щёлкните по вкладке файла**, чтобы переименовать на месте (см. [Вкладки и управление окнами](help://tabs-and-windows)).

Правила: расширение сохраняется автоматически; недопустимые символы, точка в конце имени и зарезервированные имена (CON/NUL и подобные) отклоняются с сообщением; совпадение имён в той же папке тоже блокируется. Переименовывается настоящий файл на диске, а список недавних и избранное обновляются.

## Удаление

- **⋯ ▸ Удалить** на «Главной»: спрашивает, какие файлы, затем перемещает их в **системную корзину**, откуда их можно восстановить средствами ОС. У GenOffice нет собственной отмены для этого — восстановление входит в обязанности корзины, а не уведомления.

## Создание копии

**⋯ ▸ Создать копию** создаёт копию <имя> в той же папке; при совпадении имён счётчик добавляется автоматически. Копия попадает в **Недавние**, а не открывается сама — на один клик дальше, а не перед вами.

## Сохранить и Сохранить как

- **⌘S / ctrl+S** сохраняет текущий файл; файл без названия сначала спросит папку и имя.
- В большинстве редакторов в списке типов файлов окна «Сохранить как» есть и форматы экспорта (PDF, изображения, другие форматы документов). При выборе такого формата записывается только копия; открытый документ и его вкладка остаются привязаны к исходному файлу. Изображения нескольких страниц разбиваются на `имя-01.png`, `имя-02.png`, ….
- **Docs**: список «Сохранить как» также предлагает .hwp и .hwpx (Файл ▸ Экспорт в документ HWP… делает то же самое). Если что-то не удаётся перенести, например примечания, формулы или надписи, вы узнаете об этом до записи файла.
- **Сохранить как…** создаёт новый файл и оставляет оригинал нетронутым; дальнейшие правки идут по новому файлу.
- Каждое сохранение атомарно (временный файл + переименование), поэтому выход посреди записи не испортит файл.
- Автосохранение следует переключателю в каждом редакторе; новый документ без собственного файла начинает работу после первого сохранения (см. [Быстрый старт](help://getting-started)).

## Экспорт в PDF

- **Docs**: Файл ▸ Экспортировать в PDF… (или кнопка на ленте), с разбивкой по текущей вёрстке.
- **Slides**: при экспорте страницы растеризуются по одной, с индикатором хода для больших презентаций.
- **Sheets**: экспорт следует разбивке на страницы при печати.
- Экспорт рендерится в скрытом окне, а результат попадает в выбранное вами место.

## Экспорт в Word / изображения

- **PDF ▸ PDF в Word**: превращает PDF в .docx (конвертация локальная; сложная вёрстка сохраняется настолько, насколько возможно).
- **Docs** умеет экспортировать страницы как изображения (PNG по одной странице).

## Печать

Файл ▸ Печать (⌘P/ctrl+P) в каждом редакторе открывает окно печати. В Docs, PDF, Sheets, Slides и Markdown раздел **Расположение страниц** есть в привычном окне печати, в HWP — в предварительном просмотре печати, а в HTML, интеллект-картах и диаграммах — в новом небольшом окне печати. Если в разделе «Расположение страниц» ничего не выбрать, печать идёт так же, как раньше.

- **Способ размещения**: выберите один из вариантов: Одна страница на лист, Несколько страниц на лист (2, 4, 6, 9 или 16), Брошюра (переплёт слева или справа), Плакат (листов по ширине и высоте, перекрытие, линии разреза) или Наклейки (по одной странице на наклейку или одна и та же страница на всех, начальная наклейка, распространённый формат A4 или свой размер).
- **Только нечётные стороны, только чётные стороны, обратный порядок**: стороны считаются после размещения, по тому, что реально выходит из принтера. Пригодится на принтере без двусторонней печати: напечатайте лицевые стороны, переверните бумагу и напечатайте оборотные.
- **Уменьшить по размеру бумаги**: уменьшаются только страницы крупнее выбранной бумаги; меньшие не увеличиваются. Sheets и Markdown используют свои прежние поля бумаги и масштаба.
- **Оттенки серого и разрешение изображений**: при печати с параметрами расположения страниц каждая страница превращается в изображение и уже в таком виде уходит на принтер. Разрешение выбирается из вариантов: автоматически, 150, 300 или 600 dpi.
- **Только выделенное**: Docs и Markdown печатают только выделенный текст, заново разбитый на страницы с первой; Slides печатает выбранные слайды, а PDF — выбранные страницы. Sheets, как и раньше, печатает выделенный диапазон.
- **Схема размещения и просмотр результата**: схема сразу показывает, куда на бумаге попадает каждый номер страницы, а кнопка **Просмотр результата** показывает то, что получилось на самом деле. Кнопка **Сохранить результат в PDF** позволяет напечатать то же размещение на другом компьютере или в типографии.
- **Системное окно печати**: для брошюры выберите двустороннюю печать с переворотом по короткому краю. Диапазон страниц и число страниц на листе в системном окне оставьте как есть.

PDF печатается с текущим порядком страниц и поворотом.

## Где живут файлы без названия

Папка, выбранная вами при первом сохранении, становится его домом. До этого у документа нет собственного файла: его несохранённое содержимое хранится только как копия для восстановления в папке данных приложения, поэтому его можно вернуть, если приложение внезапно выключится (см. [Вкладки и управление окнами](help://tabs-and-windows)). Автосохранение берёт его на себя лишь после этого первого сохранения.
