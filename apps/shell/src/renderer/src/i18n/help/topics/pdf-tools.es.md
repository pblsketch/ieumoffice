# Herramientas PDF

Una ventana para las tareas habituales con PDF, empezando por lo que quiere hacer. El resultado se guarda siempre como un archivo nuevo sin alterar el original. Todas las herramientas funcionan solo en este PC y no usan IA.

## Cómo funciona

1. En Inicio, haga clic en la tarjeta **Herramientas PDF** o abra **Herramientas PDF** desde la pestaña **Página** del editor PDF. Se abrirá una ventana independiente.
2. Elija una tarea (o búsquela por nombre), seleccione o arrastre los archivos necesarios, ajuste las opciones y pulse **Guardar como archivo nuevo**.
3. Tras guardar, **Abrir en una pestaña** abre el resultado al instante, **Mostrar en la carpeta** muestra la carpeta y **Continuar con este archivo** envía el resultado directo a otra herramienta.

## Conviene saber

- No puede sobrescribir un archivo de origen ni un archivo abierto con cambios sin guardar.
- Puede arrastrar y soltar archivos directamente en la ventana. Las herramientas de un solo PDF también admiten **Modo por lotes** para procesar varios PDF en una misma carpeta de salida (salvo Dividir PDF).
- Si añade un PDF protegido con contraseña, introdúzcala en la misma ventana para desbloquear una copia sin cifrar para esta tarea. No se puede abrir un archivo cuya contraseña desconoce.
- **Reducir tamaño** muestra el desglose de espacio (imágenes, fuentes, flujos, metadatos) y admite niveles predefinidos, tamaño objetivo, escala de grises, optimización web y eliminación de metadatos.
- **Organizar páginas** permite reordenar, girar, duplicar, eliminar o insertar páginas en blanco con miniaturas y combinar páginas de varios PDF.
- **Documentos a PDF** convierte archivos de Word, Excel, PowerPoint, HWP, Markdown, HTML, mapas mentales y EPUB a PDF (por separado o combinados). Al convertir HTML o Markdown que enlacen imágenes web remotas, esas URL pueden descargarse durante el renderizado, igual que al exportar a PDF desde el editor.
- **OCR de PDF escaneado** añade una capa de texto invisible y buscable a los PDF escaneados mediante el motor OCR local sin conexión.
- **Reparar archivo** recupera solo las partes aún legibles. Abra el archivo nuevo y compruebe que no falte ninguna página.
- **Quitar páginas en blanco** solo propone candidatas. Únicamente se eliminan las páginas marcadas, y cualquier página con al menos un carácter nunca aparece como candidata.
- **Quitar anotaciones** conserva los campos de formulario y solo borra los enlaces si los marca. El contenido de las anotaciones borradas no queda en el archivo nuevo.
- **Dividir PDF** permite separar por rangos personalizados (con opción de combinar), cantidad de páginas, marcadores o tamaño máximo, con formato de nombre y subcarpeta.

## Pruébelo para

| Situación                                                                              | Herramientas                                |
| -------------------------------------------------------------------------------------- | ------------------------------------------- |
| Imprimir varios documentos a doble cara a la vez, empezando cada uno en una cara impar | Preparar para doble cara → Combinar páginas |
| Unir páginas impares y pares de un escáner a una cara en un solo PDF                   | Combinar intercalado                        |
| Reordenar páginas, quitar sobrantes o intercalar una página en blanco                  | Organizar páginas                           |
| Hacer que un PDF escaneado permita buscar texto                                        | OCR de PDF escaneado                        |
| Convertir archivos Office, HWP, Markdown, HTML, mapas mentales o EPUB a PDF            | Documentos a PDF                            |
| Guardar páginas PDF como imágenes PNG o JPG (o en un ZIP)                              | Exportar imágenes                           |
| Convertir un PDF a Word, Excel, PowerPoint, HWPX, Markdown o EPUB                      | Convertir PDF                               |
| Reducir un PDF para ajustarse al límite de tamaño de un correo                         | Reducir tamaño                              |
| Aplicar el membrete de una empresa u organización a todas las páginas                  | Añadir un fondo                             |
| Limpiar comentarios antes de enviar un documento revisado                              | Quitar anotaciones                          |
| Entregar varias fotos en un solo PDF con giro y calidad ajustados                      | Imágenes a PDF                              |
| Un PDF cuya descarga se cortó a medias no se puede abrir                               | Reparar archivo                             |
