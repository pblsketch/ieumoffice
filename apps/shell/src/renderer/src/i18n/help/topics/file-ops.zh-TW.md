# 檔案操作：重新命名、刪除、匯出

本章說明各編輯器共用的檔案操作；各編輯器自己的匯出選項請見對應章節。

檔案列的 **⋯ 選單**（滑鼠停留時出現）匯集了這些動作：

![檔案列的 ⋯ 選單](img/file-ops.png)

## 重新命名

兩個入口，同一套檢查：

- 首頁檔案列的 **⋯ ▸ 重新命名**。
- **在檔案分頁上按兩下**就地重新命名（見[分頁與視窗管理](help://tabs-and-windows)）。

規則：副檔名會自動保留；非法字元、結尾的點與保留名稱（CON／NUL 之類）會被拒絕並顯示訊息；同一資料夾內的同名衝突也會被擋下。實際的磁碟檔案會被重新命名，最近使用與收藏也會同步更新。

## 刪除

- 首頁 **⋯ ▸ 刪除**：先詢問要刪除哪些檔案，再把它們移到**系統垃圾桶**，可從作業系統還原。GenOffice 本身不為這件事保留復原——復原是垃圾桶的事，不是提示訊息的事。

## 建立副本

**⋯ ▸ 建立副本** 會在同一個資料夾中建立 `<名稱> 副本`；名稱衝突時會自動加上編號。副本會加入**最近**，而不是直接替你開啟——它在一點點擊之外，而不在你眼前。

## 儲存與另存新檔

- **⌘S / ctrl+S** 儲存目前的檔案；未命名的檔案會先請你選擇位置與名稱。
- 在大多數編輯器中，另存新檔對話方塊的檔案類型清單裡也有匯出格式（PDF、圖片、其他文件格式等）。選擇這些格式時只寫入副本，開啟的文件和分頁仍指向原檔案。多頁的圖片會分成 `名稱-01.png`、`名稱-02.png`…。
- **Docs**：另存新檔清單也提供 .hwp 和 .hwpx（檔案 ▸ 匯出為 HWP 文件… 效果相同）。若有無法轉換的內容（如註解、方程式、文字方塊），會在寫入檔案前告訴你。
- **另存新檔** 會寫入一個新檔案並保持原檔不變；之後的編輯都作用在新檔案上。
- 每次儲存都是原子操作（暫存檔＋改名）；寫到一半強制結束也不會讓檔案損毀。
- 自動儲存遵循各編輯器的開關。沒有檔案的新文件要等第一次儲存之後才會自動儲存（見[快速上手](help://getting-started)）。

## 匯出為 PDF

- **Docs**：檔案 ▸ 匯出為 PDF（或功能區上的對應按鈕），依目前的版面分頁輸出。
- **Slides**：匯出時會逐頁點陣化，大型簡報有進度顯示。
- **Sheets**：匯出依列印分頁。
- 匯出都在隱藏視窗中算繪，輸出到你選擇的位置。

## 匯出為 Word／圖片

- **PDF ▸ 匯出為 Word…**：把 PDF 轉成 .docx（在本機轉換；複雜版面以盡力保留的方式處理）。
- **Docs** 可把頁面匯出為圖片（逐頁 PNG）。

## 列印

各編輯器的 檔案 ▸ 列印（⌘P/ctrl+P）會開啟列印視窗。Docs、PDF、Sheets、Slides、Markdown 在原有的列印視窗中，HWP 在預覽列印中，HTML、心智圖、圖表在新增的小型列印視窗中，都有 **頁面編排** 欄。頁面編排中什麼都不選時，會照原本的方式列印。

- **編排方式**：從每張一頁、每張多頁（2、4、6、9、16）、小冊子（左側裝訂、右側裝訂）、海報（橫向與縱向張數、重疊寬度、裁切線）、標籤（每頁佔一個標籤或所有標籤同一頁、起始標籤、常見 A4 規格或自訂）中選一種。
- **僅奇數面、僅偶數面、反序列印**：以編排完成後實際印出的面來計算。適用於沒有雙面功能的印表機：先印正面，把紙翻過來再印背面。
- **縮小以符合紙張**：只縮小比所選紙張大的頁面，較小的頁面不會放大。Sheets 和 Markdown 使用原有的紙張與縮放欄位。
- **灰階與影像解析度**：以頁面編排的選項列印時，會把頁面轉成影像再送到印表機。解析度可在自動、150、300、600dpi 中選擇。
- **僅選取範圍**：Docs 和 Markdown 會把選取的文字從第一頁起重新分頁後列印，Slides 列印選取的投影片，PDF 列印選取的頁面。Sheets 照舊列印選取範圍。
- **編排示意圖與預覽結果**：頁碼在紙上的位置一目了然，按 **預覽結果** 就能看到實際產生的結果。以 **將編排結果儲存為 PDF** 儲存後，在其他電腦或印刷店也能印出相同的樣子。
- **系統列印視窗**：小冊子請選擇雙面列印並沿短邊翻頁。頁面範圍和每張多頁請在系統視窗中維持原樣，不要更改。

PDF 會依目前的頁序與旋轉列印。

## 未命名檔案放在哪裡

第一次儲存時你選的位置就是它的家。在那之前，文件沒有自己的檔案：未儲存的內容只以復原副本的形式留在應用程式的資料夾中，應用程式突然關閉後也能找回（參見[分頁與視窗管理](help://tabs-and-windows)）。自動儲存也要等過了那一次儲存才會接手。
