# เครื่องมือ PDF

หน้าต่างสำหรับงาน PDF ประจำวัน โดยเริ่มจากการเลือกงานที่ต้องการ ผลลัพธ์จะถูกบันทึกเป็นไฟล์ใหม่เสมอและไม่แก้ไขไฟล์ต้นฉบับ เครื่องมือทั้งหมดในหน้าต่างนี้ทำงานบนเครื่องนี้เท่านั้นและไม่ใช้ AI

## วิธีใช้งาน

1. บนหน้าแรก คลิกการ์ด **เครื่องมือ PDF** หรือเปิด **เครื่องมือ PDF** จากแท็บ **หน้า** ในตัวแก้ไข PDF หน้าต่างแยกจะเปิดขึ้น
2. เลือกงาน (หรือค้นหาตามชื่อ) เลือกหรือวางไฟล์ที่ต้องการ ตั้งค่าตัวเลือก แล้วคลิก **บันทึกเป็นไฟล์ใหม่**
3. หลังบันทึก **เปิดในแท็บ** จะเปิดดูผลลัพธ์ทันที **แสดงในโฟลเดอร์** จะเปิดโฟลเดอร์ และ **ทำต่อด้วยไฟล์นี้** จะส่งผลลัพธ์ต่อไปยังเครื่องมืออื่นได้ทันที

## เครื่องมือทั้งหมด

| กลุ่ม              | เครื่องมือ                                                                                                |
| ------------------ | --------------------------------------------------------------------------------------------------------- |
| จัดระเบียบหน้า     | รวม PDF, แยก PDF, แยกหน้าเป็น PDF, จัดระเบียบหน้า, รวมแบบสลับหน้า, เรียงย้อนกลับ, หมุนทั้งหมด, ลบหน้าว่าง |
| เตรียมพิมพ์        | เตรียมพิมพ์สองหน้า, รวมหน้า, ขนาดหน้า, แยกหน้า                                                            |
| ตกแต่ง             | เพิ่มพื้นหลัง                                                                                             |
| จัดระเบียบ         | ลบคำอธิบายประกอบ                                                                                          |
| แปลง               | รูปภาพเป็น PDF, แปลงเอกสารเป็น PDF, ส่งออกรูปภาพ, แปลง PDF, บันทึกเป็นข้อความ, OCR ไฟล์ PDF สแกน          |
| ขนาดและความปลอดภัย | ลดขนาด, ใส่รหัสผ่าน, เอารหัสผ่านออก, ซ่อมไฟล์                                                             |
| ในตัวแก้ไข PDF     | ลายน้ำและหัว/ท้ายกระดาษ, ครอบตัดหน้า, แก้ไข ลงนาม ปิดทับ                                                  |

การ์ดในกลุ่ม **ในตัวแก้ไข PDF** จะเปิด PDF ที่เลือกในแท็บตัวแก้ไข แล้วเลือกคำสั่งจากริบบอนในหน้านั้น

## สิ่งที่ควรรู้

- ไม่สามารถบันทึกทับไฟล์ต้นฉบับ หรือไฟล์ที่เปิดอยู่พร้อมการแก้ไขที่ยังไม่บันทึกได้
- สามารถลากและวางไฟล์ลงในหน้าต่างได้โดยตรง เครื่องมือสำหรับ PDF เดียวยังรองรับ **โหมดชุดงาน** เพื่อประมวลผลหลายไฟล์ลงโฟลเดอร์ปลายทางเดียวกัน (ยกเว้น แยก PDF)
- หากเพิ่ม PDF ที่ติดรหัสผ่าน ให้กรอกรหัสผ่านในแผงเพื่อปลดล็อกสำเนาที่ไม่เข้ารหัสสำหรับงานนี้ ไฟล์ที่ไม่ทราบรหัสผ่านจะเปิดไม่ได้
- **ลดขนาด** แสดงสัดส่วนพื้นที่ (รูปภาพ ฟอนต์ สตรีม เมทาดาทา) และรองรับระดับสำเร็จรูป ขนาดไฟล์เป้าหมาย โทนสีเทา การปรับให้เปิดบนเว็บเร็ว และการลบเมทาดาทา
- **จัดระเบียบหน้า** ช่วยจัดลำดับ หมุน ทำซ้ำ ลบ หรือแทรกหน้าว่างจากภาพย่อ และรวมหน้าจาก PDF หลายไฟล์ได้
- **แปลงเอกสารเป็น PDF** แปลงไฟล์ Word, Excel, PowerPoint, HWP, Markdown, HTML, แผนผังความคิด และ EPUB เป็น PDF (แยกไฟล์หรือรวมไฟล์) เมื่อแปลง HTML หรือ Markdown ที่มีลิงก์รูปภาพบนเว็บ ระบบอาจดึง URL รูปภาพนั้นระหว่างเรนเดอร์เช่นเดียวกับการส่งออก PDF ปกติ
- **OCR ไฟล์ PDF สแกน** เพิ่มชั้นข้อความที่ค้นหาได้แบบโปร่งใสลงใน PDF ที่สแกนด้วยเครื่องมือ OCR ออฟไลน์ในตัว
- **ซ่อมไฟล์** กู้คืนได้เฉพาะส่วนที่ยังอ่านได้ ควรเปิดไฟล์ใหม่ตรวจดูว่าไม่มีหน้าใดหายไป
- **ลบหน้าว่าง** แสดงเฉพาะหน้าที่น่าจะว่าง และจะลบเฉพาะหน้าที่คุณเลือก หน้าที่มีตัวอักษรแม้เพียงตัวเดียวจะไม่ถูกเสนอ
- **ลบคำอธิบายประกอบ** เก็บช่องแบบฟอร์มไว้และลบลิงก์เฉพาะเมื่อเลือก เนื้อหาของหมายเหตุที่ลบจะไม่หลงเหลือในไฟล์ใหม่
- **แยก PDF** แยกได้ตามช่วงหน้า (รวมเป็นไฟล์เดียวได้) จำนวนหน้า บุ๊กมาร์ก หรือขนาดไฟล์สูงสุด พร้อมเลือกรูปแบบชื่อไฟล์และโฟลเดอร์ย่อย

## ลองใช้เมื่อ

| สถานการณ์                                                              | เครื่องมือที่ใช้             |
| ---------------------------------------------------------------------- | ---------------------------- |
| พิมพ์เอกสารหลายฉบับแบบสองหน้าพร้อมกัน โดยให้แต่ละฉบับเริ่มที่ด้านหน้า  | เตรียมพิมพ์สองหน้า → รวมหน้า |
| รวมหน้าคี่และหน้าคู่จากเครื่องสแกนหน้าเดียวเป็น PDF เดียว              | รวมแบบสลับหน้า               |
| จัดลำดับหน้า ลบหน้าส่วนเกิน หรือแทรกหน้าว่างคั่น                       | จัดระเบียบหน้า               |
| ทำให้ PDF ที่สแกนสามารถค้นหาข้อความได้                                 | OCR ไฟล์ PDF สแกน            |
| แปลงไฟล์ Office, HWP, Markdown, HTML, แผนผังความคิด หรือ EPUB เป็น PDF | แปลงเอกสารเป็น PDF           |
| บันทึกหน้า PDF เป็นรูป PNG หรือ JPG (หรือไฟล์ ZIP)                     | ส่งออกรูปภาพ                 |
| แปลง PDF เป็น Word, Excel, PowerPoint, HWPX, Markdown หรือ EPUB        | แปลง PDF                     |
| ย่อขนาด PDF ให้พอดีกับขีดจำกัดไฟล์แนบอีเมล                             | ลดขนาด                       |
| ใส่หัวจดหมายของบริษัทหรือหน่วยงานบนทุกหน้า                             | เพิ่มพื้นหลัง                |
| ลบความเห็นทั้งหมดก่อนส่งเอกสารที่ตรวจเสร็จแล้ว                         | ลบคำอธิบายประกอบ             |
| รวมรูปถ่ายหลายรูปเป็น PDF เดียวพร้อมตั้งค่าการหมุนและคุณภาพ            | รูปภาพเป็น PDF               |
| ไฟล์ PDF ที่ดาวน์โหลดค้างไว้เปิดไม่ได้                                 | ซ่อมไฟล์                     |
