# Hangul（HWP / HWPX）：編輯、工作窗格與列印

GenOffice 可在分頁中開啟並編輯 `.hwp` 與 `.hwpx` 格式的 Hangul 文件，提供鍵盤快捷鍵、樣式、表格、備忘、列印與 AI 面板功能。所有操作皆在本機電腦上執行。

## 開啟、儲存與列印

- 可透過首頁、**檔案 > 開啟**、拖曳至視窗或 Google 雲端硬碟開啟 `.hwp` 與 `.hwpx` 檔案；亦可透過**檔案 > 匯入 PDF** 將 PDF 轉換為新的 Hangul 分頁。
- 依原開啟格式存回（`.hwp` 維持 `.hwp`，`.hwpx` 維持 `.hwpx`），首次覆寫前保留 `.bak` 備份，執行 HWP 回讀檢查，並維持自動儲存與當機復原副本。
- 列印（Ctrl+P）支援即時預覽、匯出為 PDF 以及多頁列印版面選項。

## 左側工作窗格：大綱、尋找與參考文獻

- 可透過頂部列按鈕、**檢視 > 工作窗格**（大綱 / 尋找 / 參考文獻）開啟左側工作窗格，或按 **Ctrl+F** 直接跳至「尋找」分頁。傳統的尋找（**Ctrl+Q,F**）與尋找與取代（**Ctrl+H**）仍可照常使用。
- **大綱分頁**：列出原生 Hangul 大綱標題以及依樣式對應的標題（預設為 `제목 N` / `Heading N`，可在大綱設定抽屜中依文件或應用程式整體自訂）。支援依層級篩選（`1`、`2`、`3`、……全部）、摺疊分支、點擊跳轉、升級或降級標題（預設連同子標題一併調整，按住 **Shift** 則僅調整單一標題），以及拖曳標題以單一復原步驟重新排列整個章節。
- **尋找分頁**：可在內文、表格（含巢狀表格）、文字方塊、註腳與章節附註中搜尋（不含頁首與頁尾），並支援區分大小寫、全字拼寫須相符、正規表示式、段落樣式與字元格式篩選。點擊結果即可跳轉並選取，亦可在單一復原步驟內取代單一、已選取或全部符合項目（遇到內嵌物件與引用標記時會自動略過並顯示數量）。
- 工作窗格會記住開啟狀態、作用中分頁與寬度，在較窄視窗中會摺疊為圖示列，並在簡報模式與列印預覽中自動隱藏。所有工作窗格功能皆不需 AI 即可運作。

## 備忘、快捷鍵與 AI 面板

- 可由頂部列或**插入 > 備忘**開啟備忘欄，在文件旁閱讀、新增、編輯與刪除純文字備忘。
- 支援 Hangul 文件鍵盤快捷鍵、水平尺規段落標記、複製格式（**Alt+C**）、漢字轉換（**F9** / 漢字鍵）與文件資訊（**Ctrl+Q,I**）。
- 選用的 AI 面板與[命令列工具](help://cli)（`ieumoffice hwp read`、`ieumoffice hwp apply`）可讀取並編輯文字、樣式、表格、方程式、頁面配置、大綱與搜尋結果；每次 AI 編輯皆為單一復原步驟。

## 建立與更新目錄

- 透過**工具 > 建立目錄**（或**工具 > 更新目錄**、在目錄內按右鍵），可依據大綱中的標題插入**本文目錄**，並依據物件標號與標號段落建立**表目錄**、**圖目錄**與**公式目錄**。
- 可選擇**點線定位點**（預設）或**無框線表格**（2 欄）版面，設定標題層級深度（1–10 層，預設 3 層）、自訂目錄標題，並選擇是否加入跳轉連結（按一下或 **Ctrl+按一下** 目錄項目即可跳至對應標題）。
- 頁碼會反映實際列印頁碼，包含重新編排的起始頁碼以及羅馬數字或自訂頁碼格式。
- 更新目錄會就地更新項目與頁碼；若偵測到手動修改過的內容，會在覆寫前發出提醒。若文件中存在其他程式建立的未標記目錄，也會標出範圍並在取代前先詢問確認。

## 標記索引與建立索引

- 透過**工具 > 標記索引**（或在本文中按右鍵），可將選取詞彙或游標所在詞彙標記為索引項目，可選擇新增子項目或勾選**標記所有相同詞彙**（僅套用於本文，並回報表格、文字方塊與註釋中略過的次數）；亦可在同一個對話方塊中檢視並刪除現有標記。
- 透過**工具 > 建立索引**可在游標處插入索引，編輯後再以**工具 > 更新索引**同步內容。預設標題（「索引」）可自由修改。
- 索引依 Hangul（가나다）→ 英文（ABC）→ 其他順序排序，可選配字母或首音分組標題、1–3 欄配置（預設 2 欄，僅限索引區段，不影響文件其餘部分的分欄），以及**點線定位點**或**無框線表格**版面。

## 過期提醒與另存為提交版

- 手動儲存、列印、匯出 PDF 或另存為提交版時，編輯器會檢查目錄或索引是否已過時，並提供以單一復原步驟一次全部更新的選項。此檢查不會在自動儲存時執行，也不會阻擋儲存流程。
- 使用**檔案 > 另存為提交版**會另存一份乾淨的副本，移除索引標記、索引區塊標記與儲存設定等內部編輯標記，同時保留目錄、標題錨點與目錄連結；原始工作檔案維持不變，方便日後繼續更新。

## 參考文獻與引用

- 開啟左側工作窗格的**參考文獻**分頁（或**工具 > 參考文獻**），即可管理儲存於本機電腦的單一文獻庫，支援搜尋、標籤分類、新增／編輯／刪除、匯入與匯出（`BibTeX`、`RIS`、`CSL JSON`），以及從現有文件的參考文獻列表經預覽確認後匯入文獻庫。
- 支援四種引用樣式（**APA 7**、**Chicago**、**MLA 9**、**IEEE**；韓文文獻在四種樣式下皆遵循韓國學術格式）。可插入附帶頁碼的括號引用、敘述引用或多筆引用，並建立或更新具凸排縮排的參考文獻清單；切換樣式時，標記過的引用與清單會以單一復原步驟同步更新，同時略過手動修改過的引用。
- 內建 6 項引用檢查（清單遺漏、未引用條目、排序錯誤、缺少年份 a/b 區分符號、手動修改引用、未驗證項目），點選即可直接跳至對應位置；手動儲存、列印或匯出前也會提醒過期的參考文獻清單與 IEEE 編號不一致。
- 選用的 AI 文獻搜尋（需啟用網際網路工具）取得的候選項目一律以**待驗證**狀態加入並將來源網址記於備註；在您親自確認並標為**已驗證**之前，無法引用或納入參考文獻清單。

## 巨集：按鍵錄製與指令碼

- 使用**工具 > 巨集**（或按 **Alt+Shift+H** 開始／停止按鍵錄製，按 **Alt+Shift+X** 停止）可將文字輸入、游標移動、格式設定、樣式、表格與支援的編輯動作直接錄製為可編輯指令碼。錄製期間頂端列會顯示錄製中指示，遇到不支援的操作或滑鼠點擊會立即提醒，並於停止後列出略過項目。
- 開啟**巨集管理**可管理本機儲存的巨集、指派最多 11 個快捷鍵槽位（**Alt+1**–**Alt+9**、**Alt+0**、**Alt+-**）、搭配語法錯誤行與欄提示編輯指令碼，以及匯出或匯入純文字 `.ieummacro` 檔案。匯入的指令碼會完整顯示內容，須經確認並儲存後才可執行；文件檔案內嵌的巨集絕不讀取亦不執行。 在 macOS 上，由於 Option 組合鍵會輸入字元，請從**工具 > 巨集**選單啟動與管理巨集。
- 所有巨集皆在受限的同步直譯器中執行，支援應用程式文件 API 與相容巨集指令碼物件（`HAction`、`HParameterSet`），並強制執行時間、步數、呼叫深度與記憶體上限以及物件與備註保護。每次執行皆為單一復原步驟，若發生錯誤、不支援動作或超出上限則完整還原。
- 選用的**讓 AI 撰寫**（僅於啟用 AI 時顯示於巨集編輯器中）可依您描述的重複工作起草指令碼；只傳送您的描述與巨集 API 說明，絕不傳送文件內容。產生的草稿僅填入編輯欄位，絕不自動儲存或自動執行。
