# PDF 工具

按任务分类处理日常 PDF 工作的专用窗口。结果始终另存为新文件，不会修改原文件。本窗口中的工具仅在本机运行，不使用 AI。

## 使用方法

1. 在主页点击 **PDF 工具** 卡片，或在 PDF 编辑器的 **页面** 选项卡中打开 **PDF 工具**，随后会打开独立窗口。
2. 选择任务（或按名称搜索），选择或拖放所需文件，设置选项后点击 **另存为新文件**。
3. 保存后，可点击 **在标签页中打开** 立即查看结果、点击 **打开所在文件夹** 打开所在文件夹，或点击 **用此文件继续** 将结果直接送到下一个工具。

## 注意事项

- 不能覆盖源文件，也不能覆盖已打开且有未保存更改的文件。
- 可直接将文件拖放到窗口中添加。单 PDF 工具还支持 **批量模式**，可将多个 PDF 批量输出到同一文件夹（拆分 PDF 除外）。
- 将加密 PDF 添加到工具时，可直接在界面内输入密码以临时解锁并生成未加密副本。不知道密码的文件无法打开。
- **压缩大小** 可显示空间占用分布（图片、字体、内容流、元数据），并支持预设压缩、目标文件大小、灰度转换、网页快速查看和清除元数据。
- **整理页面** 支持通过缩略图调整页面顺序、旋转、复制、删除、插入空白页，以及组合多个 PDF 的页面。
- **文档转 PDF** 可将 Word、Excel、PowerPoint、HWP、Markdown、HTML、思维导图和 EPUB 文件逐个或合并转为 PDF。转换引用远程网络图片的 HTML 或 Markdown 时，渲染过程可能获取这些图片链接，与编辑器常规导出 PDF 一致。
- **扫描 PDF OCR** 使用内置离线 OCR 引擎为扫描 PDF 添加可搜索的隐藏文字层。
- **修复文件** 仅恢复仍可读取的部分。请打开新文件检查是否缺少页面。
- **查找并删除空白页** 仅列出候选页面。只删除您勾选的页面，哪怕含有一个字符的页面也不会被列为候选。
- **批量删除注释** 会保留表单域，仅在勾选时删除链接。已删除注释的内容不会留在新文件中。
- **拆分 PDF** 支持按自定义范围（可合并为一个文件）、页数、书签层级或最大文件大小拆分，并可设置命名前缀与自动新建子文件夹。

| 压缩 PDF 以满足邮件附件大小限制                               | 压缩大小                |
| 为每一页添加公司或机构的信纸背景                              | 叠加背景                |
| 发送审阅完成的文档前批量清理批注                              | 批量删除注释            |
| 将多张照片调整旋转和画质后合并为一个 PDF                      | 图片转 PDF              |
| 下载中断导致损坏的 PDF 无法打开                               | 修复文件                |
