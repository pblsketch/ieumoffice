# PDF 工具

依任務分類處理日常 PDF 工作的專用視窗。結果一律另存為新檔案，不會修改原檔案。此視窗中的工具僅在本機執行，不使用 AI。

## 使用方式

1. 在首頁按一下 **PDF 工具** 卡片，或在 PDF 編輯器的 **頁面** 分頁中開啟 **PDF 工具**，隨即會開啟獨立視窗。
2. 選擇任務（或依名稱搜尋），選取或拖放所需檔案，設定選項後按一下 **另存為新檔案**。
3. 儲存後，可按一下 **在分頁中開啟** 立即檢視結果、按一下 **開啟所在資料夾** 開啟資料夾，或按一下 **以此檔案繼續** 將結果直接送到下一個工具。

## 工具清單

| 分類            | 工具                                                                                         |
| --------------- | -------------------------------------------------------------------------------------------- |
| 整理頁面        | 合併 PDF、拆分 PDF、擷取頁面為 PDF、整理頁面、交錯合併、倒序排列、全部旋轉、尋找並刪除空白頁 |
| 列印準備        | 雙面列印對齊、合併頁面、頁面大小、拆分頁面                                                   |
| 裝飾            | 疊加背景                                                                                     |
| 整理            | 批次刪除註解                                                                                 |
| 轉換            | 圖片轉 PDF、文件轉 PDF、匯出圖片、PDF 轉換、儲存為文字檔、掃描 PDF OCR                       |
| 大小與安全      | 縮減大小、加上密碼、移除密碼、修復檔案                                                       |
| 在 PDF 編輯器中 | 浮水印與頁首頁尾、裁剪頁面、編輯、簽名、遮蔽                                                 |

**在 PDF 編輯器中** 分類中的卡片會在編輯器分頁中開啟所選 PDF，請於功能區選擇對應指令。

## 注意事項

- 無法覆寫來源檔案，也無法覆寫已開啟且有未儲存變更的檔案。
- 可直接將檔案拖放到視窗中加入。單一 PDF 工具也支援 **批次模式**，可將多個 PDF 批次輸出至同一資料夾（拆分 PDF 除外）。
- 將受密碼保護的 PDF 加入工具時，可直接在介面中輸入密碼以臨時解鎖並產生未加密副本。不知道密碼的檔案無法開啟。
- **縮減大小** 會顯示空間佔用分布（圖片、字型、內容串流、中繼資料），並支援預設壓縮、目標檔案大小、灰階轉換、網頁快速檢視與移除中繼資料。
- **整理頁面** 可透過縮圖重新排列頁面、旋轉、複製、刪除、插入空白頁，並整合多個 PDF 的頁面。
- **文件轉 PDF** 可將 Word、Excel、PowerPoint、HWP、Markdown、HTML、心智圖與 EPUB 檔案個別或合併轉為 PDF。轉換含有遠端網頁圖片連結的 HTML 或 Markdown 時，繪製過程可能會載入該圖片，與一般編輯器匯出 PDF 相同。
- **掃描 PDF OCR** 使用內建離線 OCR 引擎為掃描 PDF 加上可搜尋的隱藏文字層。
- **修復檔案** 僅能復原仍可讀取的部分。請開啟新檔案確認是否有缺頁。
- **尋找並刪除空白頁** 僅顯示候選頁面。只會刪除您勾選的頁面，只要含有任何一個字元就不會列入候選。
- **批次刪除註解** 會保留表單欄位，僅在勾選時刪除連結。已刪除註解的內容不會留在新檔案中。
- **拆分 PDF** 支援依自訂範圍（可合併為單一檔案）、頁數、書籤層級或檔案大小上限拆分，並可自訂命名格式與自動建立子資料夾。

## 常見用途

| 情境                                                          | 使用工具                |
| ------------------------------------------------------------- | ----------------------- |
| 一次雙面列印多份文件，且每份文件都從正面開始                  | 雙面列印對齊 → 合併頁面 |
| 將單面掃描器分別掃描的奇數頁與偶數頁合併為一個 PDF            | 交錯合併                |
| 調整頁面順序、刪除多餘頁面或插入空白分隔頁                    | 整理頁面                |
| 將掃描 PDF 轉為可搜尋文字的 PDF                               | 掃描 PDF OCR            |
| 將 Office、HWP、Markdown、HTML、心智圖或 EPUB 轉為 PDF        | 文件轉 PDF              |
| 將 PDF 頁面儲存為 PNG 或 JPG 圖片（或 ZIP 封存檔）            | 匯出圖片                |
| 將 PDF 轉換為 Word、Excel、PowerPoint、HWPX、Markdown 或 EPUB | PDF 轉換                |
| 縮小 PDF 以符合電子郵件附件大小限制                           | 縮減大小                |
| 在每一頁套用公司或機構的信紙背景                              | 疊加背景                |
| 寄出審閱完成的文件前一次清理註解                              | 批次刪除註解            |
| 將多張相片調整旋轉與畫質後合併為單一 PDF                      | 圖片轉 PDF              |
| 下載中斷而受損的 PDF 無法開啟                                 | 修復檔案                |
