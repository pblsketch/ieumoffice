# Ferramentas de PDF

Uma janela para tarefas diárias com PDF, começando pela tarefa desejada. O resultado é sempre salvo como um novo arquivo e o original não é alterado. Todas as ferramentas funcionam apenas neste PC e não usam IA.

## Como funciona

1. Na tela inicial, clique no cartão **Ferramentas de PDF**, ou abra **Ferramentas de PDF** na guia **Página** do editor de PDF. Uma janela separada será aberta.
2. Escolha uma tarefa (ou pesquise pelo nome), selecione ou arraste os arquivos necessários, ajuste as opções e clique em **Salvar como novo arquivo**.
3. Após salvar, **Abrir em uma aba** abre o resultado na hora, **Mostrar na pasta** abre a pasta e **Continuar com este arquivo** envia o resultado direto para outra ferramenta.

| Organizar páginas       | Mesclar PDF, Dividir PDF, Extrair páginas como PDF, Organizar páginas, Mesclagem intercalada, Inverter ordem, Girar todas, Remover páginas em branco |
| Preparar para impressão | Preparar para frente e verso, Combinar páginas, Tamanho da página, Dividir páginas                                                                   |

Os cartões de **No editor de PDF** abrem o PDF escolhido em uma guia do editor. Escolha o comando na faixa de opções.

## Bom saber

- Não é possível sobrescrever um arquivo de origem nem um arquivo aberto com alterações não salvas.
- Você pode arrastar e soltar arquivos diretamente na janela. Ferramentas de PDF único também aceitam **Modo em lote** para processar vários PDFs em uma pasta de saída (exceto Dividir PDF).
- Ao adicionar um PDF protegido por senha, digite a senha no próprio painel para desbloquear uma cópia sem criptografia para esta tarefa. Arquivos cuja senha você não conhece não podem ser abertos.
- **Reduzir tamanho** mostra o uso de espaço (imagens, fontes, fluxos, metadados) e oferece níveis prontos, tamanho-alvo, tons de cinza, otimização para web e remoção de metadados.
- **Organizar páginas** permite reordenar, girar, duplicar, excluir ou inserir páginas em branco com miniaturas e combinar páginas de vários PDFs.
- **Documentos para PDF** converte arquivos Word, Excel, PowerPoint, HWP, Markdown, HTML, mapas mentais e EPUB em PDF (um a um ou mesclados). Ao converter HTML ou Markdown com imagens remotas na web, essas URLs podem ser buscadas durante a renderização, como na exportação normal para PDF.
- **OCR de PDF digitalizado** adiciona uma camada de texto invisível e pesquisável a PDFs digitalizados usando o mecanismo de OCR offline integrado.
- **Reparar arquivo** recupera apenas as partes ainda legíveis. Abra o novo arquivo e confira se não falta nenhuma página.
- **Remover páginas em branco** exibe apenas candidatas. Só as páginas marcadas são removidas, e qualquer página com pelo menos um caractere nunca aparece como candidata.
- **Remover anotações** mantém campos de formulário e remove links apenas quando marcados. O conteúdo das anotações removidas não permanece no novo arquivo.
- **Dividir PDF** separa por intervalos personalizados (com opção de mesclar), número de páginas, marcadores ou tamanho máximo, com escolha de nomenclatura e subpasta.
