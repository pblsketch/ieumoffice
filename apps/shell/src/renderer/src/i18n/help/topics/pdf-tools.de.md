# PDF-Werkzeuge

Ein eigenes Fenster für alltägliche PDF-Aufgaben, geordnet nach dem Ziel. Das Ergebnis wird stets als neue Datei gespeichert, ohne das Original zu verändern. Alle Werkzeuge laufen ausschließlich auf diesem PC und nutzen keine KI.

## So funktioniert es

1. Klicken Sie auf der Startseite auf die Karte **PDF-Werkzeuge** oder öffnen Sie **PDF-Werkzeuge** über die Registerkarte **Seite** im PDF-Editor. Es öffnet sich ein separates Fenster.
2. Wählen Sie eine Aufgabe (oder suchen Sie nach dem Namen), wählen oder ziehen Sie die benötigten Dateien hinein, legen Sie die Optionen fest und klicken Sie auf **Als neue Datei speichern**.
3. Nach dem Speichern öffnet **In einem Tab öffnen** das Ergebnis sofort, **Im Ordner anzeigen** zeigt den Ordner und **Mit dieser Datei fortfahren** übergibt das Ergebnis direkt an das nächste Werkzeug.

## Die Werkzeuge

| Gruppe               | Werkzeuge                                                                                                                                                                  |
| -------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Seiten ordnen        | PDFs zusammenführen, PDF aufteilen, Seiten als PDF extrahieren, Seiten organisieren, Verschränkt zusammenführen, Reihenfolge umkehren, Alle drehen, Leere Seiten entfernen |
| Druck vorbereiten    | Für Duplexdruck ausgleichen, Seiten zusammenfassen, Seitengröße, Seiten teilen                                                                                             |
| Gestalten            | Hintergrund hinzufügen                                                                                                                                                     |
| Bereinigen           | Anmerkungen entfernen                                                                                                                                                      |
| Umwandeln            | Bilder zu PDF, Dokumente zu PDF, Bilder exportieren, PDF umwandeln, Als Text speichern, Scan-PDF OCR                                                                       |
| Größe und Sicherheit | Verkleinern, Passwort hinzufügen, Passwort entfernen, Datei reparieren                                                                                                     |
| Im PDF-Editor        | Wasserzeichen & Kopf-/Fußzeile, Seiten zuschneiden, Bearbeiten, signieren, schwärzen                                                                                       |

Die Karten unter **Im PDF-Editor** öffnen das gewählte PDF in einem Editor-Tab. Wählen Sie dort den Befehl im Menüband.

## Gut zu wissen

- Eine Quelldatei oder eine geöffnete Datei mit ungespeicherten Änderungen kann nicht überschrieben werden.
- Dateien lassen sich per Drag-and-drop direkt ins Fenster ziehen. Werkzeuge für einzelne PDFs unterstützen zudem **Stapelverarbeitung**, um mehrere PDFs in einen Zielordner zu verarbeiten (außer PDF aufteilen).
- Wenn Sie ein passwortgeschütztes PDF hinzufügen, geben Sie das Passwort direkt im Werkzeug ein, um für diesen Vorgang eine unverschlüsselte Kopie freizuschalten. Dateien ohne bekanntes Passwort lassen sich nicht öffnen.
- **Verkleinern** zeigt die Speicherverteilung (Bilder, Schriften, Ströme, Metadaten) und unterstützt Stufen, Zielgröße, Graustufen, Web-Optimierung sowie das Entfernen von Metadaten.
- **Seiten organisieren** ermöglicht das Umsortieren, Drehen, Duplizieren, Löschen und Einfügen leerer Seiten per Miniaturansicht sowie das Kombinieren mehrerer PDFs.
- **Dokumente zu PDF** wandelt Word-, Excel-, PowerPoint-, HWP-, Markdown-, HTML-, Mindmap- und EPUB-Dateien einzeln oder zusammengeführt in PDF um. Verweisen HTML- oder Markdown-Dateien auf externe Webbilder, können diese beim Rendern geladen werden – wie beim normalen PDF-Export im Editor.
- **Scan-PDF OCR** ergänzt gescannte PDFs mithilfe der integrierten Offline-OCR-Engine um eine unsichtbare, durchsuchbare Textebene.
- **Datei reparieren** stellt nur noch lesbare Teile wieder her. Prüfen Sie nach dem Öffnen, ob Seiten fehlen.
- **Leere Seiten entfernen** schlägt leere Seiten nur vor. Entfernt werden ausschließlich die markierten Seiten; Seiten mit auch nur einem Zeichen werden nie vorgeschlagen.
- **Anmerkungen entfernen** behält Formularfelder bei und entfernt Links nur auf ausdrückliche Auswahl. Der Inhalt entfernter Kommentare verbleibt nicht in der neuen Datei.
- **PDF aufteilen** teilt nach eigenen Bereichen (optional zusammengeführt), Seitenanzahl, Lesezeichen oder maximaler Dateigröße – inklusive Benennung und Unterordner.

## Anwendungsbeispiele

| Situation                                                                              | Passendes Werkzeug                                  |
| -------------------------------------------------------------------------------------- | --------------------------------------------------- |
| Mehrere Dokumente zusammen doppelseitig drucken, jedes beginnend auf einer Vorderseite | Für Duplexdruck ausgleichen → Seiten zusammenfassen |
| Ungerade und gerade Seiten eines einseitigen Scanners zu einem PDF vereinen            | Verschränkt zusammenführen                          |
| Seiten neu anordnen, überflüssige Seiten löschen oder ein Trennblatt einfügen          | Seiten organisieren                                 |
| Ein gescanntes PDF durchsuchbar machen                                                 | Scan-PDF OCR                                        |
| Office-, HWP-, Markdown-, HTML-, Mindmap- oder EPUB-Dateien in PDF umwandeln           | Dokumente zu PDF                                    |
| PDF-Seiten als PNG- oder JPG-Bilder (oder ZIP-Archiv) speichern                        | Bilder exportieren                                  |
| Ein PDF in Word, Excel, PowerPoint, HWPX, Markdown oder EPUB umwandeln                 | PDF umwandeln                                       |
| Ein PDF für das Größenlimit einer E-Mail verkleinern                                   | Verkleinern                                         |
| Briefpapier eines Unternehmens oder einer Organisation auf jede Seite legen            | Hintergrund hinzufügen                              |
| Kommentare vor dem Versand eines geprüften Dokuments bereinigen                        | Anmerkungen entfernen                               |
| Mehrere Fotos mit eigener Drehung und Qualität zu einem PDF zusammenfassen             | Bilder zu PDF                                       |
| Ein abgebrochen heruntergeladenes PDF lässt sich nicht öffnen                          | Datei reparieren                                    |
