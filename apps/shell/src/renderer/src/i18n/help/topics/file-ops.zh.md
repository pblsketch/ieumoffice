# 文件操作：重命名、删除、导出

这一章讲跨编辑器通用的文件操作。各编辑器自己的导出选项见对应章节。

文件行的 **⋯ 菜单**（悬停出现）集中了这些操作：

![文件行的 ⋯ 菜单](img/file-ops.png)

## 重命名

两种入口，同一套校验：

- 主屏文件行的 **⋯ ▸ 重命名**。
- **双击文件标签**就地重命名（见[标签页与窗口管理](help://tabs-and-windows)）。

规则：扩展名自动保留；非法字符、结尾的点、保留名（如 CON/NUL）会被拒绝并提示；同目录同名冲突也会被拦下。改的是磁盘上的真实文件名，最近列表与收藏同步更新。

## 删除

- 主屏 **⋯ ▸ 删除**：先询问要删除哪些文件，再把它们移入**系统废纸篓**，可从系统还原。GenOffice 本身不为这件事保留撤销——恢复是废纸篓的事，不是提示条的事。

## 复制

**⋯ ▸ 复制**在原目录创建「<文件名> 副本」；重名时自动追加序号。副本会加入**最近**，而不是直接替你打开——它在一键之遥，而不在你眼前。

## 保存与另存为

- **⌘S / ctrl+S** 保存当前文件；未命名文件先弹出位置/文件名选择。
- 在大多数编辑器中，另存为对话框的文件类型列表里也有导出格式（PDF、图片、其他文档格式等）。选择这些格式时只写入副本，打开的文档和标签页仍指向原文件。多页的图片会分成 `名称-01.png`、`名称-02.png`…。
- **Docs**：另存为列表还提供 .hwp 和 .hwpx（文件 ▸ 导出为 HWP 文档… 效果相同）。如有无法转换的内容（如批注、公式、文本框），会在写入文件前告诉你。
- **另存为**写一个新文件，原文件保持不变；之后编辑的是新文件。
- 所有保存都是原子写（临时文件 + 改名），不会因为中途退出留下损坏文件。
- 自动保存遵循各编辑器的开关。没有文件的新文档要等第一次保存之后才会自动保存（见[快速入门](help://getting-started)）。

## 导出为 PDF

- **Docs**：文件 ▸ 导出为 PDF（或功能区对应按钮），按当前分页导出。
- **Slides**：导出为 PDF 会逐页栅格化，大演示文稿有进度提示。
- **Sheets**：导出为 PDF 按打印分页。
- 导出使用隐藏窗口渲染，完成后落到你选择的位置。

## 导出为 Word / 图片

- **PDF ▸ 转为 Word**：把 PDF 转成 .docx（本地转换，复杂版式尽力保留）。
- **Docs**：可导出为图片（逐页 PNG）。

## 打印

每个编辑器的 文件 ▸ 打印（⌘P/ctrl+P）会打开打印窗口。文档、PDF、表格、幻灯片、Markdown 在原有的打印窗口里，HWP 在打印预览里，HTML、思维导图、图表在新增的小打印窗口里，都有 **页面排版** 栏。页面排版里什么都不选时，按原来的方式打印。

- **排版方式**：在每张一页、每张多页（2、4、6、9、16）、小册子（左侧装订、右侧装订）、海报（横向和纵向张数、重叠宽度、裁切线）、标签（每页占一个标签或所有标签同一页、起始标签、常见 A4 规格或自定义）中选一种。
- **仅奇数面、仅偶数面、倒序打印**：按排版完成后实际打印出来的面计数。适用于没有双面功能的打印机：先打正面，把纸翻过来再打背面。
- **缩小以适合纸张**：只缩小比所选纸张大的页面，小的页面不放大。表格和 Markdown 使用原有的纸张和缩放栏。
- **灰度与图像分辨率**：用页面排版的选项打印时，会把页面转成图像再送到打印机。分辨率可在自动、150、300、600dpi 中选择。
- **仅选定区域**：文档和 Markdown 把选中的文字从第一页起重新分页后打印，幻灯片打印选中的幻灯片，PDF 打印选中的页面。表格照旧打印选定区域。
- **排版示意图与预览结果**：页码在纸上的位置一眼可见，点 **预览结果** 能看到实际生成的结果。用 **将排版结果保存为 PDF** 保存后，在别的电脑或打印店也能印出同样的样子。
- **系统打印窗口**：小册子请选择双面打印并沿短边翻转。页范围和每张多页请在系统窗口中保持原样，不要更改。

PDF 按当前页面顺序与旋转打印。

## 未命名文件放在哪

第一次保存时你选的位置就是它的家。在此之前，文档没有自己的文件：未保存的内容只以恢复副本的形式留在应用的数据文件夹中，应用突然关闭后也能找回（参见[标签页与窗口管理](help://tabs-and-windows)）。保存过后自动保存才接管。
