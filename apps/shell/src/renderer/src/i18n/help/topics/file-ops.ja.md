# ファイル操作：名前の変更、削除、書き出し

この章では、すべてのエディターで共通するファイル操作を説明します。各エディター独自の書き出しの選択肢は、それぞれの章にあります。

ファイル行の **⋯ メニュー**（ファイル行にホバーすると現れます）には、次の操作が集まっています。

![ファイル行の ⋯ メニュー](img/file-ops.png)

## 名前の変更

入口は 2 つ、チェックは同一のものです。

- ホームの行の **⋯ ▸ 名前の変更**。
- **ファイルタブをダブルクリック**すると、その場で名前を変更します（[タブとウィンドウの管理](help://tabs-and-windows)を参照）。

規則：拡張子は自動的に保持されます。不正な文字、末尾のドット、予約名（CON／NUL など）はメッセージ付きで拒否されます。同じフォルダーでの名前衝突もブロックされます。ディスク上の実ファイルが改名され、最近の一覧とお気に入りにも反映されます。

## 削除

- ホームの **⋯ ▸ 削除**：どのファイルかを尋ね、それらを**システムのごみ箱**に移します。OS 側から元に戻せます。このために GenOffice 自身が持つ取り消しはなく、復旧はごみ箱の役割であって、通知の役割ではありません。

## 複製

**⋯ ▸ 複製**は、同じフォルダーに「<名前> コピー」を作ります。名前が衝突した場合は自動的に連番が付きます。コピーは勝手に開かれず、**最近使用**に追加されます — 目の前に出すのではなく、ワンクリック先で済みます。

## 保存と名前を付けて保存

- **⌘S／ctrl+S** で現在のファイルを保存します。無題のファイルでは、保存先と名前を先に尋ねられます。
- ほとんどのエディターでは、名前を付けて保存のダイアログのファイルの種類に書き出し形式（PDF、画像、ほかの文書形式など）も並びます。これらを選ぶとコピーだけを書き、開いている文書とタブは元のファイルのままです。複数ページの画像は `名前-01.png`、`名前-02.png`… に分かれます。
- **Docs**: 名前を付けて保存の一覧に .hwp と .hwpx もあります（ファイル ▸ HWP 文書としてエクスポート… も同じです）。コメント、数式、テキスト ボックスなど移せないものがあると、ファイルを書き込む前にお知らせします。
- **名前を付けて保存**は新しいファイルを書き、元のファイルはそのまま残します。その後の編集は新しいファイルが対象です。
- 保存はすべてアトミックです（一時ファイルに書いてからリネーム）。書き込みの途中で終了してもファイルが壊れることはありません。
- 自動保存は各エディターの切り替えに従います。ファイルのない新規文書は、最初の保存を済ませてから自動保存されます（[クイックスタート](help://getting-started)を参照）。

## PDF への書き出し

- **Docs**：ファイル ▸ PDF として書き出す（またはリボンのボタン）。現在の改ページどおりに書き出します。
- **Slides**：PDF への書き出しは 1 枚ずつラスタライズし、大きいスライド集では進捗を表示します。
- **Sheets**：PDF への書き出しは印刷の改ページに従います。
- 書き出しは非表示のウィンドウで描画され、選んだ場所に保存されます。

## Word／画像への書き出し

- **PDF ▸ Word に変換**：PDF を .docx に変換します（ローカルで変換。複雑なレイアウトは可能な限り再現します）。
- **Docs** はページを画像として書き出せます（1 枚ずつ PNG）。

## 印刷

各エディターの ファイル ▸ 印刷（⌘P／ctrl+P）は印刷ウィンドウを開きます。Docs・PDF・Sheets・Slides・Markdown はもとからある印刷ウィンドウに、HWP は印刷プレビューに、HTML・マインドマップ・ダイアグラムは新しく加わった小さな印刷ウィンドウに **ページ配置** 欄があります。ページ配置で何も選ばなければ、これまでと同じ方法で印刷します。

- **配置方法**：1枚に1ページ、1枚に複数ページ（2・4・6・9・16）、小冊子（左とじ・右とじ）、ポスター（横・縦の枚数、重なり幅、切り取り線）、ラベル（1ページずつ順に、または全ラベルに同じページ、開始ラベル、よく使う A4 規格またはユーザー設定）から一つを選びます。
- **奇数面のみ・偶数面のみ・逆順に印刷**：配置を終えたあとに印刷される面を基準に数えます。両面印刷機能のないプリンターで表面を印刷し、用紙を裏返して裏面を印刷するときに使います。
- **用紙に合わせて縮小**：選んだ用紙より大きいページだけを縮小し、小さいページは拡大しません。Sheets と Markdown はもとからある用紙・倍率の欄を使います。
- **グレースケールと画像の解像度**：ページ配置の選択肢で印刷すると、ページを画像に変えてプリンターへ送ります。解像度は自動・150・300・600dpi から選びます。
- **選択範囲のみ**：Docs と Markdown は選んだ文章だけを最初のページから割り付け直して、Slides は選んだスライドを、PDF は選んだページを印刷します。Sheets はこれまでどおり選択範囲を印刷します。
- **配置図と結果のプレビュー**：用紙の上にページ番号がどう並ぶかがすぐに見え、**結果をプレビュー** を押すと実際に作った結果を確認できます。**配置した結果をPDFで保存** すれば、ほかの PC や印刷所でも同じ形で印刷できます。
- **システムの印刷ウィンドウ**：小冊子では両面印刷を短辺とじにしてください。ページ範囲と1枚に複数ページはシステムのウィンドウで変えずに、そのままにしてください。

PDF は現在のページ順序と回転のまま印刷されます。

## 無題のファイルはどこに置かれるか

最初に保存するときに選んだ場所が、そのファイルの本拠地になります。それまで文書には自分のファイルがなく、保存していない内容はアプリのデータフォルダーに回復用コピーとしてだけ残り、アプリが突然終了しても戻せます（[タブとウィンドウの管理](help://tabs-and-windows)を参照）。自動保存は、最初の保存を済ませてから引き継ぎます。
