# 設定、語言、主題與 MCP 整合

## 開啟設定

首頁左下角的那一列會開啟設定面板（尚未連結 AI 時顯示為「連結 AI」）。面板共五個分區：帳戶、AI、一般、整合、關於。

**帳戶**會顯示你的 Claude、ChatGPT 與 Codex 連線目前的狀態，**管理連線**則會帶你到 AI 分區。AI 另有兩篇專文說明：[訂閱連線](help://subscription)與 [AI 模型與設定](help://ai-models)。

## 語言

- 設定中提供 **22 種介面語言**：English、简体中文、日本語、한국어、Français、Deutsch、Español、ไทย、Bahasa Indonesia、Русский、العربية、Português、Italiano、Polski、Čeština、Nederlands、Bahasa Melayu、עברית、हिन्दी、繁體中文、Tiếng Việt、土耳其語。
- 切換後立即生效並會保留；原生選單列也會隨語言重建。

## 主題

淺色／深色／跟隨系統三種。跟隨系統時會依作業系統的外觀切換，編輯器區域同步換膚且不會閃白。

## 一般

- **AI 側邊欄位置**（左或右）、**AI 面板文字大小**與**AI 對話拼字檢查**。
- **AI 面板** —— 可選擇關閉、收合或上次狀態。
- **所有文件自動儲存** 會讓每個編輯器預設開啟自動儲存；單一視窗仍然可以關閉。
- **預設儲存位置**搭配**變更**按鈕，以及**設為 Office 文件預設程式**，讓 .docx / .xlsx / .pptx 由 GenOffice 開啟。
- **新增 HWP 文件的儲存格式** 決定新增文件首次儲存時優先提供 HWP 或 HWPX。已開啟的文件仍按其原有格式儲存。
- **AI 投影片字型** 設定要求中未指定字型時 AI 新建簡報所用的字型。可選擇自動、黑體、明體或僅標題用明體，並分別更換黑體字型和明體字型。選擇設計範本時使用範本的字型；在已使用其他字型的簡報中新增頁面時，沿用該簡報的字型。

GenOffice 不會收集也不會傳送使用統計，所以這裡沒有對應的開關。

## 編輯器與 AI

在這裡選擇要使用的編輯器，以及是否使用 AI。同樣的清單也會在另外兩個地方出現一次：第一次啟動時歡迎畫面中的**選擇要使用的編輯器**步驟，以及在這個設定出現之前就已在使用 GenOffice 的人在首頁看到的一次性視窗。一開始全部都是開啟的，維持原樣就什麼都不會改變。變更會立即套用到所有開啟中的視窗。

- **編輯器**：Word、Excel、PowerPoint、PDF、PDF 工具、Markdown 與文字、HTML、心智圖、圖表、HWP、電子書（EPUB）。PDF 工具與 PDF 編輯器分開開關。至少要保留一個編輯器為開啟狀態。
- **關閉的編輯器**會從新文件的清單中消失：首頁卡片、分頁列的 **+** 選單、檔案 ▸ 新增，以及預設應用程式清單。已經開啟的文件不會被關閉，復原副本也會保留。
- **開啟已關閉編輯器的檔案時**（按兩下、拖放、檔案 ▸ 開啟、最近的檔案），會請你在**啟用並開啟**和**取消**之間選擇。一次開啟這個編輯器的多個檔案，也只問一次。
- **會把結果用已關閉的編輯器開啟的其他功能**（例如把 PDF 轉換成那種格式）會在開始之前詢問：**啟用並開啟**、**僅建立檔案**（建立檔案並在資料夾中顯示，編輯器維持關閉）或**取消**。
- **關閉 AI 功能後**，AI 面板、AI 按鈕和選單、首頁的提問面板、代理程式視窗以及 AI 連結提示都會消失，設定中的帳戶、AI、技能分頁也會隱藏。GenOffice 不會從畫面啟動任何 AI 程式。登入、金鑰、技能和設定都會保留，重新開啟 AI 後原樣恢復。如果仍有 AI 工作在執行，會先問你是否要**停止並關閉**。
- 不論編輯器或 AI 是否關閉，命令列、MCP 和本說明都照常運作。

即使 AI 為開啟狀態，AI 也不會為已關閉的編輯器建立新文件，而是提醒你在這裡開啟那個編輯器。

## AI ▸ 進階

預設是收合的，要你自己展開；大多數人用不到它。**AI 模型**分頁放的是對話用的 API 金鑰，以及你自己架設的伺服器。在**生圖、媒體與搜尋**分頁，每一項能力都會自行挑選提供服務的供應商，供應商的金鑰與基礎網址只需填寫一次，各欄位共用：

- **網路搜尋**、**生圖**、**圖片解析**與**影片解析**，每一項都有供應商、模型、金鑰與基礎網址。
- **本機檔案搜尋**在這台機器上執行。它下方的 **Jev 搜尋重排** 預設關閉。開啟後，本機搜尋前 20 筆命中的摘錄——每份文件最多 1,200 個字元，外加檔名和資料夾名——會送给你選擇的決策端點（OpenRouter 或 TypeSafe 的 Jev、Perplexity、Liquid AI d1、Cloudflare、本機引擎或自訂 URL），按相關性重新排序。關閉時不會有任何東西離開本機。
- **允許自動呼叫使用訂閱**這一項**預設關閉**。它決定來自命令列或已連接的程式開發代理的要求，能不能使用你的 Claude 或 Codex 訂閱；請見[連接程式設計助手](help://mcp)。

## 關於

- **版本**、專案的 GitHub 網址，以及一行說明，寫明本應用程式所根據的開放原始碼專案。
- **更新通道**：穩定版或 Beta 版。變更後立即生效並檢查更新；它不會把 Beta 版的安裝降回穩定版。

## 預設應用程式關聯

設定中可以把 .docx / .xlsx / .pptx / .pdf 等格式註冊為由 GenOffice 開啟（作業系統層級的預設應用程式註冊；出現提示時請確認）。

## 第三方聲明與更新

- 說明 ▸ 第三方軟體聲明：隨附於應用程式的完整 OSS 授權清單。
- 選單（☰） ▸ 檢查更新（Mac 上為 說明 ▸ 檢查更新）：手動觸發一次更新檢查；有新版本時會提示安裝。

## MCP 整合（供進階使用者／AI 用戶端使用）

**整合**是把 GenOffice 接上程式開發代理的面板，它也有專門一章：連接程式開發代理。簡單說就是——選一條路（命令列或 MCP），照那一節做，然後開一個新對話直接問。

在**本機 HTTP 服務**之下，應用程式也可以自己跑這個服務——一個啟用開關、一個連接埠——而**進階**會再加上健康檢查的網址和日誌檔案——而不是丟給助理處理。它只監聽 localhost。
