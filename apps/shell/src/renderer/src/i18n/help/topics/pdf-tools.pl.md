# Narzędzia PDF

Okno do codziennych zadań z plikami PDF, ułożone według czynności. Wynik jest zawsze zapisywany jako nowy plik, a oryginał pozostaje bez zmian. Wszystkie narzędzia działają wyłącznie na tym komputerze i nie korzystają z AI.

## Jak to działa

1. Na ekranie głównym kliknij kartę **Narzędzia PDF** lub otwórz **Narzędzia PDF** z karty **Strona** w edytorze PDF. Otworzy się osobne okno.
2. Wybierz zadanie (lub wyszukaj je po nazwie), wskaż lub upuść potrzebne pliki, ustaw opcje i kliknij **Zapisz jako nowy plik**.
3. Po zapisaniu **Otwórz na karcie** od razu wyświetla wynik, **Pokaż w folderze** otwiera jego folder, a **Kontynuuj z tym plikiem** przekazuje wynik prosto do kolejnego narzędzia.

## Narzędzia

| Grupa                    | Narzędzia                                                                                                                                        |
| ------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| Porządkowanie stron      | Scal PDF, Podziel PDF, Wyodrębnij strony jako PDF, Porządkuj strony, Scalanie naprzemienne, Odwróć kolejność, Obróć wszystkie, Usuń puste strony |
| Przygotowanie do druku   | Przygotuj do druku dwustronnego, Scal strony, Rozmiar strony, Podziel strony                                                                     |
| Ozdabianie               | Dodaj tło                                                                                                                                        |
| Porządkowanie            | Usuń adnotacje                                                                                                                                   |
| Konwertuj                | Obrazy do PDF, Dokumenty na PDF, Eksportuj obrazy, Konwertuj PDF, Zapisz jako tekst, OCR skanu PDF                                               |
| Rozmiar i bezpieczeństwo | Zmniejsz rozmiar, Dodaj hasło, Usuń hasło, Napraw plik                                                                                           |
| W edytorze PDF           | Znak wodny i nagłówek/stopka, Przytnij strony, Edycja, podpis, zaczernienie                                                                      |

Karty w grupie **W edytorze PDF** otwierają wybrany plik PDF w karcie edytora. Tam wybierz odpowiednie polecenie ze wstążki.

## Warto wiedzieć

- Nie można nadpisać pliku źródłowego ani pliku otwartego z niezapisanymi zmianami.
- Pliki można przeciągać i upuszczać bezpośrednio do okna. Narzędzia dla pojedynczego PDF obsługują też **Tryb wsadowy**, przetwarzając wiele plików PDF do jednego folderu docelowego (z wyjątkiem Podziel PDF).
- Po dodaniu PDF chronionego hasłem wpisz hasło na miejscu, aby odblokować niezaszyfrowaną kopię dla tego zadania. Pliku z nieznanym hasłem nie można otworzyć.
- **Zmniejsz rozmiar** pokazuje podział zajętego miejsca (obrazy, czcionki, strumienie, metadane) oraz obsługuje poziomy kompresji, rozmiar docelowy, skalę szarości, optymalizację pod sieć i usuwanie metadanych.
- **Porządkuj strony** pozwala zmieniać kolejność, obracać, powielać, usuwać i wstawiać puste strony za pomocą miniatur oraz łączyć strony z wielu plików PDF.
- **Dokumenty na PDF** konwertuje pliki Word, Excel, PowerPoint, HWP, Markdown, HTML, mapy myśli i EPUB do PDF (osobno lub w jeden plik). Przy konwersji HTML lub Markdown z zewnętrznymi obrazami sieciowymi adresy tych obrazów mogą zostać pobrane podczas renderowania, tak jak przy zwykłym eksporcie do PDF.
- **OCR skanu PDF** dodaje do zeskanowanych plików PDF niewidoczną warstwę tekstu do wyszukiwania przy użyciu wbudowanego silnika OCR offline.
- **Napraw plik** odzyskuje wyłącznie części, które nadal da się odczytać. Otwórz nowy plik i sprawdź, czy nie brakuje żadnej strony.
- **Usuń puste strony** wskazuje jedynie propozycje. Usuwane są tylko zaznaczone strony, a strona z choćby jednym znakiem nigdy nie trafia na listę.
- **Usuń adnotacje** zachowuje pola formularza, a linki usuwa tylko po zaznaczeniu. Treść usuniętych adnotacji nie zostaje w nowym pliku.
- **Podziel PDF** dzieli według zakresów (z opcją scalenia), liczby stron, zakładek lub maksymalnego rozmiaru pliku, z wyborem nazewnictwa i podfolderu.

## Wypróbuj, gdy

| Sytuacja                                                                                              | Narzędzia                                     |
| ----------------------------------------------------------------------------------------------------- | --------------------------------------------- |
| Drukowanie kilku dokumentów dwustronnie naraz, tak aby każdy zaczynał się na pierwszej stronie kartki | Przygotuj do druku dwustronnego → Scal strony |
| Łączenie stron nieparzystych i parzystych ze skanera jednostronnego w jeden PDF                       | Scalanie naprzemienne                         |
| Zmiana kolejności stron, usuwanie zbędnych lub wstawianie pustej przekładki                           | Porządkuj strony                              |
| Zamiana zeskanowanego PDF na plik z możliwością wyszukiwania tekstu                                   | OCR skanu PDF                                 |
| Konwersja plików Office, HWP, Markdown, HTML, map myśli lub EPUB do PDF                               | Dokumenty na PDF                              |
| Zapisywanie stron PDF jako obrazów PNG lub JPG (albo archiwum ZIP)                                    | Eksportuj obrazy                              |
| Konwersja PDF do Word, Excel, PowerPoint, HWPX, Markdown lub EPUB                                     | Konwertuj PDF                                 |
| Zmniejszenie PDF, aby zmieścił się w limicie załącznika e-mail                                        | Zmniejsz rozmiar                              |
| Nałożenie papieru firmowego firmy lub instytucji na każdą stronę                                      | Dodaj tło                                     |
| Wyczyszczenie komentarzy przed wysłaniem sprawdzonego dokumentu                                       | Usuń adnotacje                                |
| Połączenie kilku zdjęć w jeden PDF z wybranym obrotem i jakością                                      | Obrazy do PDF                                 |
| Plik PDF przerwany podczas pobierania nie chce się otworzyć                                           | Napraw plik                                   |
