# Alat PDF

Jendela khusus untuk pekerjaan PDF sehari-hari, dimulai dari tugas yang ingin dilakukan. Hasil selalu disimpan sebagai file baru dan file asli tidak diubah. Semua alat di jendela ini hanya berjalan di PC ini dan tidak menggunakan AI.

## Cara menggunakan

1. Di Beranda, klik kartu **Alat PDF**, atau buka **Alat PDF** dari tab **Halaman** di editor PDF. Jendela terpisah akan terbuka.
2. Pilih tugas (atau cari berdasarkan nama), pilih atau seret file yang dibutuhkan, atur opsi, lalu klik **Simpan sebagai file baru**.
3. Setelah disimpan, **Buka di tab** langsung membuka hasilnya, **Tampilkan di folder** membuka foldernya, dan **Lanjutkan dengan berkas ini** meneruskan hasil langsung ke alat berikutnya.

## Daftar alat

| Kelompok            | Alat                                                                                                                                          |
| ------------------- | --------------------------------------------------------------------------------------------------------------------------------------------- |
| Atur halaman        | Gabungkan PDF, Pisahkan PDF, Ekstrak halaman sebagai PDF, Atur halaman, Gabung selang-seling, Balik urutan, Putar semua, Hapus halaman kosong |
| Persiapan cetak     | Siapkan cetak bolak-balik, Gabung halaman, Ukuran halaman, Pisahkan halaman                                                                   |
| Hias                | Tambahkan latar                                                                                                                               |
| Rapikan             | Hapus anotasi                                                                                                                                 |
| Konversi            | Gambar ke PDF, Dokumen ke PDF, Ekspor gambar, Konversi PDF, Simpan sebagai teks, OCR PDF pindaian                                             |
| Ukuran dan keamanan | Perkecil ukuran, Tambah kata sandi, Hapus kata sandi, Perbaiki file                                                                           |
| Di editor PDF       | Tanda air & header/footer, Pangkas halaman, Edit, tanda tangan, sensor                                                                        |

Kartu di kelompok **Di editor PDF** membuka PDF yang dipilih di tab editor. Pilih perintahnya dari pita di sana.

## Perlu diketahui

- Anda tidak dapat menimpa file sumber atau file yang sedang terbuka dengan perubahan belum disimpan.
- Anda dapat menyeret dan menjatuhkan file langsung ke jendela. Alat PDF tunggal juga mendukung **Mode batch** untuk memproses banyak PDF ke satu folder keluaran (kecuali Pisahkan PDF).
- Jika Anda menambahkan PDF ber kata sandi, masukkan kata sandinya langsung di panel untuk membuka salinan tanpa enkripsi bagi tugas ini. File yang kata sandinya tidak diketahui tidak dapat dibuka.
- **Perkecil ukuran** menampilkan rincian ruang (gambar, font, aliran, metadata) serta mendukung preset, ukuran target, skala abu-abu, optimasi web, dan penghapusan metadata.
- **Atur halaman** memungkinkan Anda mengatur ulang, memutar, menggandakan, menghapus, atau menyisipkan halaman kosong lewat pratinjau kecil, serta menggabungkan halaman dari beberapa PDF.
- **Dokumen ke PDF** mengonversi file Word, Excel, PowerPoint, HWP, Markdown, HTML, peta pikiran, dan EPUB ke PDF (terpisah atau digabung). Saat mengonversi HTML atau Markdown yang merujuk gambar web jarak jauh, URL gambar tersebut dapat diambil saat merender, seperti ekspor PDF biasa di editor.
- **OCR PDF pindaian** menambahkan lapisan teks tak terlihat yang dapat dicari ke PDF hasil pindai menggunakan mesin OCR luring bawaan.
- **Perbaiki file** hanya memulihkan bagian yang masih dapat dibaca. Buka file baru dan periksa apakah tidak ada halaman yang hilang.
- **Hapus halaman kosong** hanya menampilkan kandidat. Hanya halaman yang Anda centang yang dihapus, dan halaman dengan satu karakter pun tidak pernah menjadi kandidat.
- **Hapus anotasi** mempertahankan bidang formulir dan hanya menghapus tautan jika dicentang. Isi anotasi yang dihapus tidak tersisa di file baru.
- **Pisahkan PDF** dapat membagi menurut rentang khusus (bisa digabung menjadi satu file), jumlah halaman, markah buku, atau ukuran maksimum dengan opsi penamaan dan subfolder.

## Coba untuk

| Situasi                                                                                   | Alat yang digunakan                        |
| ----------------------------------------------------------------------------------------- | ------------------------------------------ |
| Mencetak beberapa dokumen bolak-balik sekaligus dengan tiap dokumen dimulai di sisi depan | Siapkan cetak bolak-balik → Gabung halaman |
| Menggabungkan halaman ganjil dan genap dari pemindai satu sisi menjadi satu PDF           | Gabung selang-seling                       |
| Mengatur ulang halaman, menghapus halaman berlebih, atau menyisipkan halaman kosong       | Atur halaman                               |
| Mengubah PDF hasil pindai menjadi PDF yang teksnya bisa dicari                            | OCR PDF pindaian                           |
| Mengonversi file Office, HWP, Markdown, HTML, peta pikiran, atau EPUB ke PDF              | Dokumen ke PDF                             |
| Menyimpan halaman PDF sebagai gambar PNG atau JPG (atau arsip ZIP)                        | Ekspor gambar                              |
| Mengonversi PDF ke Word, Excel, PowerPoint, HWPX, Markdown, atau EPUB                     | Konversi PDF                               |
| Mengecilkan PDF agar sesuai batas ukuran lampiran email                                   | Perkecil ukuran                            |
| Memasang kop surat perusahaan atau lembaga pada setiap halaman                            | Tambahkan latar                            |
| Membersihkan komentar sebelum mengirim dokumen yang sudah ditinjau                        | Hapus anotasi                              |
| Menyatukan beberapa foto menjadi satu PDF dengan rotasi dan kualitas pilihan              | Gambar ke PDF                              |
| PDF yang unduhannya terputus di tengah tidak bisa dibuka                                  | Perbaiki file                              |
