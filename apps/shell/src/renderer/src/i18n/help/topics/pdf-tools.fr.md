# Outils PDF

Une fenêtre dédiée aux tâches PDF courantes, organisée par action. Le résultat est toujours enregistré dans un nouveau fichier sans modifier l’original. Tous les outils de cette fenêtre s’exécutent uniquement sur ce PC et n’utilisent pas l’IA.

## Comment l’utiliser

1. Sur l’écran d’accueil, cliquez sur la carte **Outils PDF**, ou ouvrez **Outils PDF** depuis l’onglet **Page** de l’éditeur PDF. Une fenêtre séparée s’ouvre.
2. Choisissez une tâche (ou recherchez-la par nom), sélectionnez ou déposez les fichiers nécessaires, réglez les options puis cliquez sur **Enregistrer comme nouveau fichier**.
3. Après l’enregistrement, **Ouvrir dans un onglet** affiche aussitôt le résultat, **Afficher dans le dossier** ouvre son dossier et **Continuer avec ce fichier** envoie directement le résultat vers un autre outil.

## Bon à savoir

- Vous ne pouvez pas écraser un fichier source ni un fichier ouvert comportant des modifications non enregistrées.
- Vous pouvez glisser-déposer des fichiers directement dans la fenêtre. Les outils à PDF unique prennent aussi en charge **Mode par lot** pour traiter plusieurs PDF dans un même dossier de sortie (sauf Diviser le PDF).
- Si vous ajoutez un PDF protégé par mot de passe, saisissez le mot de passe sur place pour déverrouiller une copie non chiffrée pour cette tâche. Un fichier dont vous ignorez le mot de passe ne peut pas être ouvert.
- **Réduire la taille** affiche la répartition de l’espace (images, polices, flux, métadonnées) et prend en charge les préréglages, la taille cible, les niveaux de gris, l’optimisation web et la suppression des métadonnées.
- **Organiser les pages** permet de réordonner, pivoter, dupliquer, supprimer ou insérer des pages vierges via des miniatures, et de combiner les pages de plusieurs PDF.
- **Documents vers PDF** convertit les fichiers Word, Excel, PowerPoint, HWP, Markdown, HTML, cartes mentales et EPUB en PDF (séparément ou fusionnés). Lors de la conversion de fichiers HTML ou Markdown référençant des images distantes, ces adresses d’images peuvent être téléchargées pendant le rendu, comme lors de l’export PDF habituel.
- **OCR de PDF numérisé** ajoute une couche de texte invisible et consultable aux PDF numérisés grâce au moteur OCR hors ligne intégré.
- **Réparer le fichier** ne récupère que les parties encore lisibles. Ouvrez le nouveau fichier pour vérifier qu’aucune page ne manque.
- **Supprimer les pages blanches** n’affiche que des candidates. Seules les pages que vous cochez sont supprimées, et toute page contenant ne serait-ce qu’un caractère n’est jamais proposée.
- **Supprimer les annotations** conserve les champs de formulaire et ne supprime les liens que si vous les cochez. Le contenu des annotations supprimées ne subsiste pas dans le nouveau fichier.
- **Diviser le PDF** découpe par plages personnalisées (avec fusion possible), nombre de pages, signets ou taille maximale, avec nommage personnalisé et sous-dossier en option.

## Exemples d’usage

| Situation                                                                             | Outils à utiliser                             |
| ------------------------------------------------------------------------------------- | --------------------------------------------- |
| Imprimer plusieurs documents en recto verso d’un coup, chacun commençant sur un recto | Préparer le recto verso → Fusionner les pages |
| Assembler les pages impaires et paires d’un scanner recto simple en un seul PDF       | Fusion alternée                               |
| Réorganiser les pages, retirer des pages en trop ou insérer une page blanche          | Organiser les pages                           |
| Rendre un PDF numérisé interrogeable par recherche de texte                           | OCR de PDF numérisé                           |
| Convertir des fichiers Office, HWP, Markdown, HTML, cartes mentales ou EPUB en PDF    | Documents vers PDF                            |
| Enregistrer des pages PDF en images PNG ou JPG (ou en archive ZIP)                    | Exporter les images                           |
| Convertir un PDF en Word, Excel, PowerPoint, HWPX, Markdown ou EPUB                   | Convertir le PDF                              |
| Réduire un PDF pour respecter la limite de taille d’un courriel                       | Réduire la taille                             |
| Appliquer un papier à en-tête d’entreprise ou d’organisme sur chaque page             | Ajouter un arrière-plan                       |
| Nettoyer les commentaires avant d’envoyer un document relu                            | Supprimer les annotations                     |
| Regrouper plusieurs photos dans un seul PDF avec rotation et qualité choisies         | Images en PDF                                 |
| Un PDF dont le téléchargement s’est interrompu ne s’ouvre plus                        | Réparer le fichier                            |
