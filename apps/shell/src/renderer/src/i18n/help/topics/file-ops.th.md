# การจัดการไฟล์: เปลี่ยนชื่อ ลบ และส่งออก

บทนี้ครอบคลุมการจัดการไฟล์ที่ใช้ร่วมกันทุกตัวแก้ไข ส่วนตัวเลือกการส่งออกเฉพาะของแต่ละตัวแก้ไขอยู่ในบทของมัน

**⋯ เมนู** ของแถวไฟล์ (วางเลื่อนเมาส์เหนือแถวไฟล์) รวบรวมการทำงานเหล่านี้ไว้:

![⋯ เมนูของแถวไฟล์](img/file-ops.png)

## การเปลี่ยนชื่อ

มีสองทางเข้า แต่ใช้ชุดการตรวจสอบชุดเดียวกัน:

- **⋯ ▸ เปลี่ยนชื่อ** จากแถวในหน้าแรก
- **ดับเบิลคลิกที่แท็บไฟล์** เพื่อเปลี่ยนชื่อแบบอินไลน์ (ดูบท [แท็บและการจัดการหน้าต่าง](help://tabs-and-windows))

กฎ: นามสกุลไฟล์จะถูกคงไว้โดยอัตโนมัติ อักขระต้องห้าม จุดท้ายชื่อ และชื่อที่สงวนไว้ (เช่น CON/NUL) จะถูกปฏิเสธพร้อมข้อความแจ้ง และการชนกับชื่อเดิมในโฟลเดอร์เดียวกันก็ถูกกันไว้เช่นกัน ไฟล์จริงบนดิสก์จะถูกเปลี่ยนชื่อ และรายการไฟล์ล่าสุดกับรายการโปรดจะอัปเดตตาม

## การลบ

- **⋯ ▸ ลบ** จากหน้าแรก: จะถามว่าเป็นไฟล์ใดบ้าง แล้วย้ายไปยัง **ถังขยะของระบบ** ซึ่งกู้คืนจากระบบปฏิบัติการได้ ส่วน GenOffice ไม่มีคำสั่งเลิกทำของตัวเองสำหรับงานนี้ — การกู้คืนเป็นหน้าที่ของถังขยะ ไม่ใช่ของข้อความแจ้ง

## การสร้างสำเนา

**⋯ ▸ สร้างสำเนา** จะสร้างไฟล์ชื่อ <ชื่อไฟล์> สำเนา ในโฟลเดอร์เดิม หากชื่อซ้ำ ระบบจะเติมเลขนับให้อัตโนมัติ สำเนาจะถูกเพิ่มเข้า **ล่าสุด** แทนที่จะเปิดให้คุณ นั่นคืออยู่ห่างออกไปหนึ่งคลิก ไม่ใช่อยู่ตรงหน้าคุณ

## การบันทึกและบันทึกเป็น

- **⌘S / ctrl+S** บันทึกไฟล์ปัจจุบัน ไฟล์ที่ยังไม่มีชื่อจะให้เลือกตำแหน่งและชื่อก่อน
- ในตัวแก้ไขส่วนใหญ่ รายการชนิดไฟล์ในกล่องโต้ตอบบันทึกเป็นมีรูปแบบการส่งออกด้วย (PDF, รูปภาพ, รูปแบบเอกสารอื่น) เมื่อเลือกรูปแบบเหล่านี้จะเขียนเฉพาะสำเนา เอกสารที่เปิดอยู่และแท็บยังคงอยู่กับไฟล์เดิม รูปภาพที่มีหลายหน้าจะแยกเป็น `ชื่อ-01.png`, `ชื่อ-02.png`, …
- **Docs**: รายการบันทึกเป็นมี .hwp และ .hwpx ด้วย (ไฟล์ ▸ ส่งออกเป็นเอกสาร HWP… ทำได้เหมือนกัน) หากมีสิ่งที่ย้ายไปไม่ได้ เช่น ข้อคิดเห็น สมการ หรือกล่องข้อความ จะแจ้งให้ทราบก่อนเขียนไฟล์
- **บันทึกเป็น…** จะเขียนไฟล์ใหม่และปล่อยต้นฉบับไว้ไม่ให้ถูกแตะ การแก้ไขหลังจากนั้นจะทำกับไฟล์ใหม่
- ทุกการบันทึกเป็นแบบอะตอมิก (เขียนไฟล์ชั่วคราวแล้วเปลี่ยนชื่อ) การออกกลางคันจึงไม่ทำให้ไฟล์เสียหาย
- บันทึกอัตโนมัติเป็นไปตามสวิตช์ในแต่ละตัวแก้ไข เอกสารใหม่ที่ยังไม่มีไฟล์ของตัวเองจะเริ่มหลังการบันทึกครั้งแรก (ดู [เริ่มต้นอย่างรวดเร็ว](help://getting-started))

## การส่งออกเป็น PDF

- **Docs**: ไฟล์ ▸ ส่งออกเป็น PDF… (หรือปุ่มในแถบเครื่องมือ) โดยแบ่งหน้าตามที่จัดวางไว้
- **Slides**: การส่งออกจะแปลงทีละหน้า พร้อมความคืบหน้าสำหรับงานนำเสนอขนาดใหญ่
- **Sheets**: การส่งออกจะทำตามการแบ่งหน้าสำหรับพิมพ์
- การส่งออกเรนเดอร์ในหน้าต่างที่ซ่อนอยู่ และไฟล์จะไปอยู่ในตำแหน่งที่คุณเลือก

## การส่งออกเป็น Word / รูปภาพ

- **PDF ▸ แปลง PDF เป็น Word**: แปลง PDF เป็น .docx (แปลงในเครื่อง เลย์เอาต์ที่ซับซ้อนจะทำได้เท่าที่ทำได้)
- **Docs** ส่งออกหน้าเป็นรูปภาพได้ (PNG ทีละหน้า)

## การพิมพ์

เมนู ไฟล์ ▸ พิมพ์ (⌘P/ctrl+P) ในแต่ละตัวแก้ไขจะเปิดหน้าต่างพิมพ์ Docs, PDF, Sheets, Slides และ Markdown มีส่วน **การจัดวางหน้า** อยู่ในหน้าต่างพิมพ์เดิม HWP อยู่ในตัวอย่างก่อนพิมพ์ ส่วน HTML แผนผังความคิด และไดอะแกรมอยู่ในหน้าต่างพิมพ์เล็กที่เพิ่มเข้ามาใหม่ หากไม่เลือกอะไรในการจัดวางหน้า ก็จะพิมพ์ด้วยวิธีเดิม

- **วิธีจัดวาง**: เลือกหนึ่งอย่างจาก หนึ่งหน้าต่อแผ่น, หลายหน้าต่อแผ่น (2, 4, 6, 9 หรือ 16), สมุดเล่มเล็ก (เย็บเล่มด้านซ้ายหรือขวา), โปสเตอร์ (จำนวนแผ่นตามแนวนอนและแนวตั้ง ระยะซ้อนทับ เส้นตัด) หรือป้ายฉลาก (หนึ่งหน้าต่อหนึ่งป้ายหรือหน้าเดียวกันทุกป้าย ป้ายเริ่มต้น ขนาด A4 ที่ใช้กันทั่วไปหรือกำหนดเอง)
- **เฉพาะด้านคี่ เฉพาะด้านคู่ และพิมพ์เรียงย้อนกลับ**: นับตามด้านที่พิมพ์ออกมาจริงหลังจัดวางแล้ว ใช้กับเครื่องพิมพ์ที่พิมพ์สองหน้าเองไม่ได้ โดยพิมพ์ด้านหน้าก่อน พลิกกระดาษ แล้วพิมพ์ด้านหลัง
- **ย่อให้พอดีกระดาษ**: ย่อเฉพาะหน้าที่ใหญ่กว่ากระดาษที่เลือก หน้าที่เล็กกว่าจะไม่ถูกขยาย Sheets และ Markdown ใช้ช่องกระดาษและอัตราส่วนที่มีอยู่เดิม
- **สีเทาและความละเอียดภาพ**: เมื่อพิมพ์ด้วยตัวเลือกของการจัดวางหน้า แต่ละหน้าจะถูกแปลงเป็นภาพก่อนส่งไปยังเครื่องพิมพ์ เลือกความละเอียดได้จาก อัตโนมัติ, 150, 300 หรือ 600 dpi
- **เฉพาะส่วนที่เลือก**: Docs และ Markdown พิมพ์เฉพาะข้อความที่เลือกโดยแบ่งหน้าใหม่ตั้งแต่หน้าแรก Slides พิมพ์สไลด์ที่เลือก และ PDF พิมพ์หน้าที่เลือก ส่วน Sheets ยังพิมพ์ช่วงที่เลือกเหมือนเดิม
- **แผนผังการจัดวางและตัวอย่างผลลัพธ์**: แผนผังแสดงทันทีว่าเลขหน้าแต่ละหน้าไปอยู่ตรงไหนบนกระดาษ และกด **ดูตัวอย่างผลลัพธ์** เพื่อดูผลที่สร้างขึ้นจริง ใช้ **บันทึกผลที่จัดวางแล้วเป็น PDF** เพื่อพิมพ์ออกมาแบบเดียวกันบนเครื่องอื่นหรือที่ร้านพิมพ์
- **หน้าต่างพิมพ์ของระบบ**: สำหรับสมุดเล่มเล็ก ให้เลือกพิมพ์สองหน้าแบบพลิกด้านสั้น ส่วนช่วงหน้าและจำนวนหน้าต่อแผ่นในหน้าต่างของระบบให้ปล่อยไว้ตามเดิม

PDF จะพิมพ์ตามลำดับหน้าและการหมุนปัจจุบัน

## ไฟล์ที่ยังไม่มีชื่ออยู่ที่ไหน

ตำแหน่งที่คุณเลือกตอนบันทึกครั้งแรกคือ "บ้าน" ของไฟล์นั้น ก่อนหน้านั้นเอกสารยังไม่มีไฟล์ของตัวเอง เนื้อหาที่ยังไม่ได้บันทึกถูกเก็บไว้เป็นสำเนากู้คืนในโฟลเดอร์ข้อมูลของแอปเท่านั้น จึงเรียกกลับมาได้หากแอปดับไปกะทันหัน (ดู [แท็บและการจัดการหน้าต่าง](help://tabs-and-windows)) และบันทึกอัตโนมัติจะเข้ามาดูแลต่อก็ต่อเมื่อบันทึกครั้งแรกเสร็จแล้วเท่านั้น
