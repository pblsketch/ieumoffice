# כלי PDF

חלון לפעולות PDF יומיומיות, שמתחיל מבחירת הפעולה. התוצאה נשמרת תמיד כקובץ חדש והמקור אינו משתנה. כל הכלים בחלון זה פועלים אך ורק על מחשב זה ואינם משתמשים בבינה מלאכותית.

## איך זה עובד

1. במסך הבית לחצו על הכרטיס **כלי PDF**, או פתחו את **כלי PDF** מלשונית **עמוד** בעורך ה-PDF. ייפתח חלון נפרד.
2. בחרו פעולה (או חפשו לפי שם), בחרו או גררו את הקבצים הנדרשים, הגדירו אפשרויות ולחצו על **שמירה כקובץ חדש**.
3. לאחר השמירה, **פתיחה בכרטיסייה** מציג מיד את התוצאה, **הצגה בתיקייה** פותח את התיקייה, ו-**המשך עם קובץ זה** מעביר את התוצאה ישירות לכלי הבא.

## כדאי לדעת

- לא ניתן לשמור על גבי קובץ מקור או על גבי קובץ פתוח עם שינויים שלא נשמרו.
- ניתן לגרור ולשחרר קבצים ישירות לחלון. כלי PDF יחיד תומכים גם ב-**מצב אצווה** לעיבוד מספר קובצי PDF לתיקיית פלט אחת (למעט פיצול PDF).
- אם הוספתם PDF מוגן בסיסמה, הזינו את הסיסמה במקום כדי לפתוח עותק לא מוצפן למשימה זו. קובץ שסיסמתו אינה ידועה לא ניתן לפתיחה.
- **הקטנת הגודל** מציג פילוח נפח (תמונות, גופנים, זרמים, מטא-נתונים) ותומך ברמות מוכנות, גודל יעד, גווני אפור, מיטוב לרשת והסרת מטא-נתונים.
- **סידור עמודים** מאפשר לסדר מחדש, לסובב, לשכפל, למחוק או להוסיף עמודים ריקים באמצעות תמונות ממוזערות, ולשלב עמודים ממספר קובצי PDF.
- **מסמכים ל-PDF** ממיר קובצי Word, Excel, PowerPoint, HWP, Markdown, HTML, מפות חשיבה ו-EPUB ל-PDF (בנפרד או מאוחד). בהמרת HTML או Markdown שמפנים לתמונות רשת מרוחקות, כתובות אלה עשויות להיטען בזמן הרינדור, בדומה לייצוא PDF רגיל.
- **זיהוי טקסט (OCR) לסריקות** מוסיף שכבת טקסט בלתי נראית הניתנת לחיפוש לקובצי PDF סרוקים באמצעות מנוע OCR מקומי ללא אינטרנט.
- **תיקון קובץ** משחזר רק חלקים שעדיין ניתנים לקריאה. פתחו את הקובץ החדש ובדקו שלא חסר אף עמוד.
- **הסרת עמודים ריקים** מציג מועמדים בלבד. רק העמודים שתבחרו יימחקו, ועמוד עם אפילו תו אחד לעולם לא יוצע כמועמד.
- **הסרת הערות** שומר על שדות טופס ומוחק קישורים רק אם סימנתם אותם. תוכן ההערות שנמחקו אינו נשאר בקובץ החדש.
- **פיצול PDF** מאפשר פיצול לפי טווחים מותאמים (כולל מיזוג לקובץ אחד), מספר עמודים, סימניות או גודל קובץ מרבי, עם תבנית שמות ותיקיית משנה.
