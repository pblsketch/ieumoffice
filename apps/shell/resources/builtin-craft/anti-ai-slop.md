# Anti-AI-Slop Craft

- Never leave placeholder copy (`lorem ipsum`, `Feature One`, `여기에 입력`, `TBD`) in any heading, table cell, or caption.
- Never invent impressive-sounding metrics (`10x faster`, `99.9% uptime`) unless those exact figures came from the user's request or attached materials.
- Do not decorate headings or buttons with repetitive emoji icons unless the user explicitly asked for emojis.
- Replace vague filler prose with specific actions, owners, dates, and verifiable facts from the user's source material.
