# Color Craft

- Anchor the document on neutral ink and paper tones, plus one primary accent and at most one secondary semantic accent.
- Maintain readable contrast (at least 4.5:1 for body text, 3:1 for large headings and UI chrome).
- Avoid rainbow cards or alternating loud backgrounds; use subtle tinted fills and crisp borders for hierarchy.
- Never apply unrequested default purple/indigo accents or loud two-stop gradients unless the user explicitly asks for them.
