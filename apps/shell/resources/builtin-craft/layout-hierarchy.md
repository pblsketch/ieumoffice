# Layout Hierarchy Craft

- Lead with the conclusion or key takeaway so busy readers grasp the core message within five seconds.
- Leave deliberate breathing room around headings, tables, and visual blocks; avoid wall-to-wall dense paragraphs.
- Keep visual elements strictly inside safe page/slide margins and clear of footer rails and page numbers.
- Group related facts into scannable comparison tables, numbered steps, or aligned cards with consistent spacing.
