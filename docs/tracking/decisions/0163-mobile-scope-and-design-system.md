# 0163. 모바일판의 기능 범위(1판·2판)와 디자인 시스템

- 날짜: 2026-11-24
- 상태: 확정

## 맥락

1차 모바일 프로토타입(한글·마크다운·AI 시트, Tauri 2)이 에뮬레이터와 CI에서 돌아가게 되었다. 본격 개발 전에 두 가지를 정해야 했다. 하나는 PC판의 기능 가운데 무엇을 언제 모바일에 둘지, 다른 하나는 작은 화면과 두 플랫폼에 맞는 화면 규칙이다. 프로토타입은 데스크톱 색 토큰만 썼고, 간격·글자 크기·터치 크기는 화면마다 직접 적은 값이었다(간격 20가지, 글자 크기 11가지, 36px 조작부). 국내외 모바일 문서 앱의 공개 자료에서는 "저장하다 날아감"이 가장 흔한 불만이었고, 한글 문서를 작은 화면 폭에 맞춰 다시 흘려 보여 주는 앱은 찾지 못했다.

## 결정

1. **PC판 기능을 모바일에도 두는 것이 기본이다.** 예외는 셋으로만 적는다. 가져오지 않는 것(구독 프로그램 실행, 터미널 명령어·MCP 서버, 에이전트 모드, 앱 자체 업데이트 등), 다르게 가져오는 것(폴더 연결, OS 인쇄, 기기 안 글자 인식, Rust 부속 프로그램을 앱 안 명령으로 등), 모바일에만 만드는 것. 목록은 [mobile-scope.md](../../plans/mobile-scope.md).
2. **판은 1판·2판 둘만 둔다.** 1판에서 고치는 편집기는 한글·PDF·마크다운·HTML·엑셀, 읽기만 하는 것은 EPUB·PPT다. 마인드맵·워드·화이트보드·PPT 편집·다이어그램은 2판이다. 엑셀은 `xlsx-engine` 크레이트를 고치지 않고 앱 안 Tauri 명령으로 부른다.
3. **PDF 도구는 1판에 넣는다**(페이지 정리, 변환, 용량·보안, 주석 지우기). 인쇄 준비와 배경 겹치기는 2판이다. **2판에 PC판에 없는 PDF 스캔 도구를 만든다.** 문서 모드는 OS 스캐너(ML Kit 문서 스캐너, VisionKit)를 쓰고, 책 모드(휜 쪽 펴기, 두 쪽 나누기, 손가락 지우기)는 직접 만든다. 사진은 기기 밖으로 보내지 않는다.
4. **AI는 1판에 넣되 기본은 꺼짐이다.** 설정의 스위치로 켜고, 꺼져 있으면 AI 단추가 어디에도 보이지 않는다. 첫 실행에서 묻지 않는다. 모바일 ChatGPT 바로 연결은 약관 판단 전까지 켜지 않는다(빌드에 client ID를 넣지 않음).
5. **디자인 시스템**: 겉모습은 두 플랫폼에서 하나이고, 플랫폼별로는 동작만 가른다(뒤로 가기, 키보드 높이, 시스템 막대, 확인 창 단추 순서, 파일·공유). 색은 데스크톱 토큰을 그대로 쓰고, 모바일 토큰(`--m-*`: 4px 간격, rem 글자 크기, 48px 터치, 움직임)을 더한다. 창 크기는 600/840/1200px로 나누고 기기가 아니라 웹뷰 폭으로 판단한다. 자세한 것은 [mobile-design-system.md](../../plans/mobile-design-system.md).
6. **모바일에만 두는 것(1판)**: 보기 모드에서 늘 보이는 [공유] 단추와 공유 시트, 공유로 받기, 한글 흐름(읽기) 보기, 첫 실행 안내(권한 창 없이 폴더 연결만)와 처음 쓰는 순간의 도움말, 홈 아래 탭 [최근][폴더][도구][설정].

## 버린 대안

- **플랫폼별 겉모습(iOS 모양 / Material 모양 두 벌)**: 웹뷰에서 두 벌을 맞춰 가꾸는 비용이 크고, 데스크톱과 같은 이음오피스의 얼굴이 흐려진다.
- **3판까지 나누기**: 편집기 대부분이 웹 엔진이라 2판 안에서 들어올 수 있고, 판이 길어지면 PC판과의 차이가 오래 남는다.
- **AI 기본 켜짐(PC판과 같게)**: 모바일은 키 방식과 무료 연결만 있어 처음 쓰는 사람에게 연결 절차가 먼저 보이게 된다. 문서 편집으로 시작하고, 원하는 사람이 켠다.
- **첫 실행에서 권한 창을 모아 띄우기**: 두 스토어 지침이 기능을 쓰는 순간에 묻게 하고, 이 앱은 파일·사진·폴더를 모두 시스템 선택 창으로 받아 권한 창이 필요 없다.
- **"모든 파일 접근" 권한**: Google Play는 사람이 파일을 직접 고르는 앱에 허용하지 않는다.

## 결과

- `apps/mobile`의 화면 규칙이 토큰과 창 크기 구분으로 바뀐다. 태블릿 배치(옆 패널)는 768px가 아니라 840px부터다.
- 기존 설치본은 저장된 설정을 그대로 쓰고, 새로 설치하면 AI가 꺼진 채로 시작한다.
- 엑셀 1판은 격자 화면(Univer 모바일 UI 플러그인)의 터치 사용성, iPhone 웹뷰 메모리, Rust 엔진의 모바일 빌드, 모바일 저장 경로의 원본 바이트 보존을 시제품으로 먼저 확인한다.
- ChatGPT 바로 연결의 모바일 사용 여부는 저장소 주인의 약관 판단으로 남는다.
