# 0117 — ChatGPT 직접 연결과 Codex를 화면에서 ChatGPT 하나로 보이고, 길은 앱이 정한다

저장소 주인이 2026-11-09에 정했다. 계획은 [`docs/plans/chatgpt-one-account.md`](../../plans/chatgpt-one-account.md)다. 구현은 OpenAI의 사용량 통합이 시행되는 12월에 맞춘다.

## 맥락

ChatGPT 요금제로 AI를 쓰는 길은 둘이다. 앱이 직접 로그인하는 ChatGPT 직접 연결(결정 0081)과 PC에 설치된 Codex 프로그램이다. 결정 0081은 두 길을 구독 제공자 둘(`chatgpt`, `codex`)로 두고, 설정에 카드를 따로 두었다. 카드 하나에 "연결 방식"을 고르게 하는 안은 그 선택이 `auto` 순서와 따로 논다는 이유로 버렸다.

2026-10 말 OpenAI는 12월부터 Plus·Pro·Business 요금제에서 ChatGPT와 Codex가 사용량 하나를 함께 쓰게 한다고 알렸다. 사용량은 토큰으로 세고, Instant 대화는 빠진다. 같은 계정이면 두 길은 같은 사용량에서 빠진다.

지금의 화면은 두 길을 서로 다른 AI로 다룬다. 막힌 실행의 "…로 계속"은 ChatGPT가 막히면 Codex를, Codex가 막히면 ChatGPT를 권한다. 같은 계정이면 눌러도 곧바로 다시 막힌다. 또 OpenAI는 직접 연결의 한도 오류가 사용자가 이 앱에만 정해 둔 한도일 수 있다고 적었다. 그 자리에서 Codex를 권하면 사용자가 정한 한도를 돌아가게 된다.

## 결정

- **화면의 구독 AI는 Claude와 ChatGPT 둘이다.** 설정 카드, "사용할 AI", 모델 선택기에서 ChatGPT는 하나다. ChatGPT 카드 안에 "앱에서 바로 연결"과 "Codex 프로그램"이 한 줄씩 있다.
- **길은 앱이 정한다.** 사용자에게 연결 방식을 고르게 하지 않는다. 앱 안의 AI 창은 직접 연결이 `ready`이면 그것을, 아니면 구독 로그인으로 `ready`인 Codex를 쓴다. 종량 로그인으로는 이 대체가 가지 않는다. 정하는 곳은 `selectAiProvider` 하나이고, 보낼 때 정하며 실행 중에는 바꾸지 않는다. 0081이 버린 "연결 방식 선택"과 달리 사용자가 고르는 값이 없으므로 `auto` 순서와 겹치지 않는다.
- **두 길의 계정이 달라도 대체는 같다.** 계정이 다르면 카드에 "두 길의 계정이 다릅니다"를 보인다. 계정 주소는 두 상태에 이미 있는 값을 메모리에서 견주고 저장하지 않는다.
- **Codex로 고정하는 자리는 카드 안 Codex 줄의 스위치다.** "앱 안의 AI 창도 이 길로", 기본은 꺼짐이다. 이미 저장된 `provider: 'codex'`도 고정으로 읽는다.
- **"…로 계속"은 같은 집안을 권하지 않는다.** ChatGPT 직접 연결과 Codex는 서로의 후보가 아니다.
- **에이전트 모드와 터미널 명령어·MCP는 지금처럼 Codex만 쓴다.**
- **내부 식별자와 설정 파일은 그대로다.** `chatgpt`·`codex`, `providers.<id>`, `subscriptionOff`, 명령어의 `--provider codex`를 바꾸지 않는다.
- **로그인 방식은 그대로다.** 직접 연결은 OpenAI가 오픈소스 앱에 연 공식 길만 쓴다. 다른 프로그램의 로그인을 빌리거나 ChatGPT의 비공개 주소를 쓰는 방식은 쓰지 않는다.

## 택하지 않은 것

- **지금처럼 둔다.** 12월부터 한 사용량을 쓰는 것을 두 AI로 보이고, 막히면 같은 사용량의 다른 길을 권하게 된다.
- **직접 연결만 남기고 Codex를 없앤다.** 에이전트 모드와 터미널 명령어에는 Codex가 필요하다.
- **Codex의 로그인 방식으로 앱이 직접 로그인한다.** Codex 행세를 하는 로그인이고, 0081이 정한 공식 길과 맞지 않는다. 약관 판단이 필요하다.
- **카드 하나에 연결 방식 선택을 둔다.** 0081이 버린 까닭(`auto` 순서와 따로 논다)이 그대로다.
- **두 길의 계정이 같을 때만 대체한다.** 막으면 Codex가 연결돼 있는데도 왜 쓰이지 않는지 화면에서 알기 어렵다. 대체하고, 계정이 다르다는 것을 카드에 알린다.

## 결과

- 한도 문구는 이 결정과 따로 먼저 고쳤다. 직접 연결의 한도 소진은 "이 앱이 쓸 수 있는 사용량을 다 썼다, 요금제 전체 또는 이 앱의 한도일 수 있다"로 말하고 시각을 붙이지 않는다(`errChatGptAppLimit`).
- 12월 시행 뒤 저장소 주인이 실제 계정으로 확인할 것: Codex의 5시간·7일 값을 직접 연결을 쓸 때도 보일지, ChatGPT에서 산 크레딧이 이 앱의 요청에 쓰이는지(쓰인다면 절대 규칙 2에 닿으므로 안내를 정한다).
- 구현되면 결정 0081의 "설정에는 Claude, ChatGPT, Codex 카드가 차례로 있다"가 바뀐다. 나머지는 그대로다.
