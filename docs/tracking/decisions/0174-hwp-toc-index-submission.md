# 0174 — 한글 차례(점선 탭·표·캡션), 색인, 낡은 것 알림, 제출본 저장과 캡션 읽기 엔진 패치 0059

날짜: 2026-11-27

## 맥락

긴 보고서와 학위논문에서는 본문 개요와 표·그림·수식 캡션에서 차례를 만들고 문서가 바뀔 때마다 쪽 번호와 항목을 제자리에서 새로 고쳐야 하며, 본문 낱말에 색인 표시를 달아 다단 찾아보기를 만들고, 저장·인쇄·PDF·제출 직전에 낡은 차례·색인을 놓치지 않아야 한다. 기존 차례 도구는 선 없는 2칸 표만 만들었고, 문서를 다시 열면 자신이 만든 차례를 알아보지 못했으며, 개체(표·그림·도형)에 달린 진짜 캡션 글을 엔진에서 읽을 수 없었다. 또한 색인 표시나 설정 책갈피는 작업본에는 남아야 하지만, 최종 제출 파일에는 남기지 않고 차례와 이동 링크만 남긴 깔끔한 사본을 떼어 낼 길이 필요했다.

## 결정

1. **개체 캡션 읽기 전용 엔진 패치(`vendor/rhwp-core/patches/0059-list-object-captions.patch`)**: `HwpDocument.listObjectCaptions()` 읽기 전용 조회를 더한다. 본문과 표 셀·글상자·묶음 개체 안에 중첩된 표·그림·도형(차트·OLE 포함)의 캡션 글(캡션 안 `AutoNumber` 자동 번호 전개 포함)과 개체 위치(`sec`·`para`·`controlIndex`·`cellPath`·`direction`)를 문서 읽기 순서로 돌려준다. 단, 엔진 `v0.9.1`의 `Equation` 모델에는 캡션 필드가 없어 수식 차례는 캡션 스타일·머리 글이 붙은 본문 문단만 모으며, 묶음 도형 안 글상자에 달린 캡션은 `listObjectCaptions`가 읽지 않는다. 모델·조판·그리기·HWP/HWPX 직렬화는 일절 바꾸지 않는다. 패치 번호는 `main`의 마지막(`0057`)과 진행 중인 다른 가지(`0057`·`0058`)와 겹치지 않는 가장 작은 번호인 `0059`를 썼다. 호출이 없는 엔진 빌드에서는 개체 캡션을 건너뛰고 알리며 캡션 꼴 본문 문단은 계속 모은다.
2. **본문 및 표·그림·수식 차례 생성기(`studio-plugin/toc.mjs`, `studio-hyperlink-bookmark`)**:
   - 본문 차례는 개요 읽기(`outline.mjs`, `설정:개요수준` > 앱 기본값 > 기본 스타일, 수준 1–10·기본 3)를 쓰고, 표·그림·수식 차례는 `listObjectCaptions()`와 캡션 스타일·머리 글(`표`/`그림`/`수식`/`Table`/`Figure`/`Equation` 등) 본문 문단을 문서 읽기 순서로 합친다.
   - 꼴은 **점선 탭(기본)**(본문 오른쪽 끝에 오른쪽 점선 탭 정지, `차례 N` 스타일 또는 본문 글꼴+수준 들여쓰기, 기존 탭 폭 저장 보정 결정 0026 활용)과 **선 없는 2칸 표** 가운데 고른다.
   - 링크(기본 켬)는 대상 제목·캡션(개체 캡션은 개체가 놓인 본문 문단)에 `제목:` 책갈피를 달고 차례 줄에 `#제목:…` 내부 하이퍼링크를 건다. 편집기 패치 `studio-hyperlink-bookmark`는 `#…`와 `?…` 내부 책갈피 링크를 누르거나 Ctrl+클릭할 때 원문 이름 우선 일치로 책갈피 자리로 커서와 화면을 옮기며, 방문한 링크 색 변경을 건너뛰어 내부 책갈피 링크가 원래 글자 서식을 유지하고 문서를 더럽히지 않는다.
   - 쪽 번호는 인쇄 기준 글자 폭(`withPortableWidths`)으로 새 번호 시작과 쪽 번호 모양(로마 숫자 등)을 반영해 차례를 넣은 뒤의 배치로 잰다.
   - 각 차례는 `차례:<종류>:시작`/`끝` 범위 표시와 `설정:차례:<종류>` 옵션·기대 줄 목록으로 관리하므로 다시 연 문서에서도 알아보고 제자리에서 새로 고친다. 손으로 고친 줄이 있으면 덮어쓰기 전에 보이고 확인받으며, 표시 없는 기존 차례(점선/탭+쪽 번호 줄 또는 옛 2칸 표)를 발견하면 범위를 칠해 보이고 바꿀지 묻는다.
3. **색인 표시와 색인 만들기(`studio-plugin/index-marks.mjs`)**:
   - 본문 낱말에 `색인:` 책갈피(첫째·둘째 색인어, 64자 초과 시 자동 분할)를 달고, "같은 낱말 모두 표시"는 온전한 낱말 기준으로 본문만 표시하며 표 칸·글상자·각주·미주에서 건너뛴 수를 알린다.
   - 색인 블록(`색인블록:`)은 찍히는 쪽 번호를 중복 없이 오름차순으로 모으고, 국문 가나다 → 영문 ABC → 기타 순으로 정렬하며, 자음·알파벳 머리(겹자음 `ㄲ/ㄸ/ㅃ/ㅆ/ㅉ`은 기본 자음으로 묶음, 기본 켬)와 둘째 색인어 들여쓰기를 지원한다.
   - 다단(1–3단, 기본 2단)은 색인 블록만 별도 구역으로 분리해 새 쪽에서 시작하도록 적용하고, 뒤에 본문이 이어지면 "색인 앞뒤가 새 쪽으로 나뉩니다" 안내 후 확인을 받는다. 분리한 색인 구역과 뒤 본문 구역에는 앞 구역의 쪽 설정·머리말/꼬리말·쪽 번호 위치와 이어지는 쪽 번호 매기기를 복사해 원래 단 수와 쪽 모양을 그대로 유지하며, 새로 고침 때 1단으로 되돌리면 구역을 다시 합친다.
4. **대화상자·메뉴(`studio-plugin/toc-dialogs.mjs`, `i18n/toc/`)**: 도구 메뉴에 차례 만들기·차례 새로 고침·색인 표시·색인 만들기·색인 새로 고침 다섯 항목을 두고, 본문·표 오른쪽 클릭 메뉴(`studio-toc-index-context-menu`)에 차례/색인 안 새로 고침과 색인 표시를 넣는다. 모든 대화상자는 편집기 `ModalDialog`와 `dialog-theme.mjs` 스킨을 쓰며, 문구는 22개 언어로 앱에서 넘긴다. 모든 편집은 사람의 편집(`foreign`)이며 한 동작 = 실행 취소 한 단계다.
5. **낡은 것 알림과 제출본으로 저장(`studio-plugin/staleness.mjs`, `StalenessModal.tsx`, `save-flow.ts`, `print-flow.ts`, `hwp-main.ts`, `i18n/submission/`)**:
   - 확장 가능한 낡은 것 검사 등록부(`createStalenessRegistry`)에 차례·색인 검사를 기본 등록하고(추후 참고문헌·번호식 검사가 같은 자리에 붙는다), 수동 저장·인쇄·PDF 내보내기·제출본 저장 직전에 검사한다. 자동 저장과 `--headless-export`에서는 검사하지 않으며, 검사 오류가 저장이나 인쇄를 막지 않는다. "모두 새로 고치기"는 실행 취소 한 단계로 처리한다.
   - 파일 메뉴(`installFileMenu`)와 껍데기 창 메뉴에 "제출본으로 저장…"을 둔다. 열린 문서를 건드리지 않고 복제본에서만 `SUBMISSION_STRIP_PREFIXES`(`색인:`, `색인블록:`, `인용:`, `참고문헌:`, `설정:`)를 제거해(`차례:`·`제목:`·차례 링크는 유지) 저장 바로잡기를 거쳐 새 경로에 쓴다. 원본 경로·저장 안 됨 상태·복구 사본·`.bak`·탭 제목은 그대로다. 새 IPC 창구는 모두 `hwpViews.has(e.sender.id)`를 확인한다.
6. **AI·명령어·도움말**: `insert_toc`·`refresh_toc`를 새 차례 엔진으로 옮기고 `mark_index`·`list_index_marks`·`remove_index_mark`·`insert_index`·`refresh_index`를 `hwp-skill.ts`, 22개 언어 활동 줄 문구, `ieumoffice hwp apply`/MCP/`guide hwp`, `docs/contracts.md`에 연결한다. 22개 언어 도움말 `hwp` 주제에 차례·색인·제출본 절을 더한다.

## 버린 대안

- **표·그림·수식 캡션을 HWPX로 직렬화해 JS에서 파싱**: 문서 전체를 직렬화하고 압축을 풀어야 해 큰 문서에서 느리고 동기 플러그인 흐름에 맞지 않으며 `.hwp` 단독 경로와 어긋난다. 읽기 전용 WASM 조회 한 개를 더하는 편이 빠르고 저장 바이트에 영향이 없다.
- **제출본 저장 시 열린 문서의 표시를 지운 뒤 저장하고 실행 취소로 되돌리기**: 실행 취소 기록과 더티 상태가 오염되고 중간 실패 시 원본 표시가 사라질 위험이 있다. 메모리 복제본에서만 표시를 빼고 내보내는 쪽이 원본을 완전히 지킨다.
- **차례를 기존 2칸 표 방식에만 묶어 두기**: 문서 편집기에서 흔히 쓰는 점선 탭 차례와 이동 링크, 표·그림·수식 차례, 재열기 후 새로 고침 요구를 채우지 못한다. 점선 탭을 기본으로 두고 2칸 표를 선택지로 유지했다.

## 결과

- 다시 연 `.hwp`/`.hwpx` 문서에서도 본문·표·그림·수식 차례와 다단 색인을 제자리에서 새로 고치고, 차례 줄을 Ctrl+클릭해 해당 제목으로 이동하며, 수동 저장·인쇄·PDF·제출본 저장 전 낡은 항목을 한 번에 갱신할 수 있다.
- 작업본의 편집 표식은 유지하면서 제출용 깔끔한 파일만 따로 떼어 저장할 수 있고, `docs/tracking/findings.md`의 "차례를 다시 열면 알아보지 못한다" 한계가 해소되었다.
- 외부 한글 편집기에서 저장 파일을 열어 책갈피·차례 링크(Ctrl+클릭)·점선 탭 차례·다단 색인·제출본을 확인하는 항목과 22개 언어 대화상자 넘침 확인은 사람 확인 항목으로 남긴다.
