# 0175. 모바일 1판 PDF 도구와 공용 패키지 `@genoffice/pdf-ops`

- 날짜: 2026-11-26
- 상태: 모바일 1판(배포 전), 주인 승인(2026-11-26)

## 맥락

결정 [0165](0165-mobile-scope-and-design-system.md)에 따라 PC "PDF 도구"의 1판 13종(페이지 정리 6, 변환 2, 용량·보안 4, 주석 지우기 1)을 모바일 `[도구]` 화면으로 내야 했다. PC 도구는 `apps/pdf/src/main/*`과 `apps/shell/src/main/pdf-tools/tools.ts`에 모여 있었는데, 이 가운데 일부는 이음오피스가 새로 만든 파일이고 `save-pdf.ts`·`read-text.ts` 등은 원본 GenOffice와 함께 쓰는 파일이다. PC 동작과 결과 바이트를 바꾸지 않으면서 모바일 웹 워커에서 같은 도구 규칙과 처리를 돌릴 구조가 필요했다. 2026-11-26 기획 질문 11건을 저장소 주인이 모두 권장대로 승인했다.

## 결정

1. **공용 패키지 `@genoffice/pdf-ops`는 이음오피스 파일만 옮기고, 원본 공유 파일은 거울 함수로 둔다(주인 승인 2026-11-26).** 분할, 페이지 범위, 이미지로 PDF, 양면 인쇄, 배경 겹치기, 주석 지우기, 용량 줄이기, 빈 페이지 찾기, 복구, qpdf 핵심, 셸 `tools.ts`의 규칙·실행기를 `packages/pdf-ops`로 옮기고 원래 자리에서는 같은 이름을 다시 내보낸다(소유 밖 파일 셋 `split-plan.ts`, `page-range.ts`, `pdf-tools-api.ts`는 다시 내보내기만). Node·Electron·네트워크 의존을 두지 않고 PDFium·qpdf·그림 다시 쓰기는 호출자가 주입한다. 원본 공유 파일(`save-pdf.ts`·`read-text.ts`·`text-edit.ts`)은 고치지 않고, 모바일용 거울 함수(`mirrorPageEngine`)가 같은 바이트·텍스트 결과를 낸다.
2. **PC 결과 기준선 시험을 두고 기준 표를 고치지 않는다.** 옮기기 전에 PC 도구 결과 160항목(결정적 결과는 SHA-256, 암호 등 실행마다 바뀌는 결과는 구조·내용)을 `apps/shell/tests/pdf-tools-golden.test.ts`에 기록했다. 원본 받아오기로 PC 결과가 바뀌면 시험이 깨지며, 사람이 확인한 뒤에만 표를 갱신한다.
3. **화면·preload용으로 `pdf-lib` 없는 진입점을 분리한다.** `./tool-ids`, `./tool-rules`, `./split-plan`, `./page-range`를 별도 진입점으로 내보내 PC 도구 창과 모바일 도구 화면 번들에 `pdf-lib`이 끌려 들어오지 않게 한다(`pdf-lib`은 모바일 작업 스레드에만 적재).
4. **결과는 메모리에만 두고, 저장은 열린 문서를 바꾸지 않는 전용 명령으로 하며, [열기]는 이름 없는 문서로 연다(주인 승인 2026-11-26).** 결과 시트에서 `[열기][공유][다른 곳에 저장]`을 고를 때까지 디스크에 쓰지 않는다. 결과 저장·공유는 열린 문서 세션·최근 목록·복구 사본을 건드리지 않는 T3 전용 Rust 명령(`mobile_pdf_tools_save_copy`, `mobile_pdf_tools_share`)을 쓴다(결정 [0176](0176-mobile-v1-html-and-markdown.md)의 내보내기 명령과 같은 원칙).
5. **분할·사진·결과 이름 규칙(주인 승인 2026-11-26).**
   - 분할은 네 방식(구간·페이지 수·책갈피·파일 크기)과 이름 설정을 모두 지원하고, 결과는 조각별 저장·공유와 함께 ZIP 하나로 묶어 저장·공유할 수 있다.
   - 이미지로 PDF는 기기가 디코딩할 수 있는 사진(HEIC·WebP 등 포함)이면 JPEG(품질 0.92)로 변환해 넣는다.
   - 결과 파일 이름은 PC 규칙(영어 꼬리 포함)을 그대로 따른다.
   - PDF 편집기 연계 카드는 "편집·서명" 하나로 두고, 처리 중 화면 꺼짐 막기는 T6 훅(`useKeepScreenOn`)을 쓰며, PC `annot-delete.ts` 확장은 하지 않는다.

## 버린 대안

- **원본 공유 파일(`save-pdf.ts` 등)까지 `@genoffice/pdf-ops`로 이전:** 원본 GenOffice 변경을 받아올 때마다 충돌이 생긴다.
- **T2의 Node 대역 빌드로 PC 코드를 그대로 호출:** T2 병합에 종속되고 PC와 모바일의 공용 패키지 구조를 세울 수 없다.
- **기존 공용 "다른 이름으로 저장" 명령으로 도구 결과 저장:** 현재 열려 있는 문서 세션이 결과 파일로 바뀌어 버려 원본 문서 편집과 충돌한다.

## 결과

- PC 도구 창 화면 번들 크기는 0.35 MB로 유지되고(모바일 도구 화면 덩어리 33 KB), PC 기준선 161개·`pdf-ops` 120개·PC PDF 2,392개 시험이 통과했다.
- Android 16 에뮬레이터 실제 Web Worker에서 PDF 병합·분할·용량 줄이기와 결과 시트가 동작함을 확인했다.
- 실기기 다중 선택·사진 선택 창·iPhone HEIC 변환·대용량 메모리 확인과, `package-lock.json` 재생성 및 루트 검사 목록 등록이 남는다.
