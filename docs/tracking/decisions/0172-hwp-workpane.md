# 0172 — 한글 왼쪽 작업창(개요·찾기)과 문서 안 표시 기반

날짜: 2026-11-27

## 맥락

339쪽짜리 학위논문 같은 긴 한글 문서를 쓰고 다듬으려면, 본문 왼쪽에서 개요 나무를 보며 제목 수준을 조절하거나 장·절을 통째로 옮기고, 본문뿐 아니라 표(표 안의 표 포함)·글상자·각주·미주까지 한 번에 찾아 목록에서 골라 바꿀 수 있어야 한다. 또한 앞으로 이어질 차례·색인·참고문헌과 문서별 설정이 문서를 다른 PC로 보내거나 이름을 바꿔도 따라가려면, 엔진 직렬화나 저장 바이트 규칙을 바꾸지 않고 문서 안에 표식을 남길 공용 바탕이 필요하다.

## 결정

1. **왼쪽 작업창 틀(`WorkpaneSide`)**: 한글 편집기 화면 왼쪽에 메모 칸과 독립된 탭 작업창(`[개요 | 찾기]`, 추후 참고문헌 탭 확장 자리 포함)을 둔다. 열림·탭·너비를 기억하고, 문서 폭이 최소 360px 아래로 줄어들면 아이콘 띠로 접히며, 발표 모드와 인쇄 미리 보기에서는 숨긴다. 위쪽 띠 단추, 편집기 보기 메뉴(`작업창 › 개요 / 찾기`), `Ctrl+F`(찾기 탭 열기·입력 칸 초점)로 연다. 한컴 한글 2024 기준에 따라 기존 찾기 대화상자는 `Ctrl+Q,F`, 찾아 바꾸기는 `Ctrl+H`로 남긴다. 모든 기능은 AI 없이 동작한다.
2. **문서 안 표시 모듈(`studio-plugin/doc-marks.mjs`)**: 엔진이 `.hwp`·`.hwpx` 저장 왕복에서 보존하는 본문 책갈피 위에 일곱 접두어(`차례:`, `제목:`, `색인:`, `색인블록:`, `인용:`, `참고문헌:`, `설정:`)와 64자 이름 한도(자동 분할·복원), 유일화, 범위 쌍 찾기·정리, 제출본 표시 제거를 구현한다. `설정:`은 첫 본문 문단 머리에 쓰고 문서 전체에서 마지막 값을 읽는다. 표 칸·글상자·각주·미주·머리말에서는 `unsupported_place`로 거절한다. `agent-plugin.mjs`의 개체 보호(`objectsOf`/`keepingObjects`)는 앱 소유 책갈피와 `제목:` 대상 차례 링크를 내용 개체 변화로 세지 않되, 편집으로 지워진 앱 표시는 AI 답에 적는다.
3. **개요 읽기와 수준 연결(`studio-plugin/outline.mjs`, `src/main/outline-settings.ts`)**: 본문 문단만 대상으로 한글 개요 문단(`getOutlineNavigation()`, 9–10수준 포함)과 문단 스타일 수준 연결(1–10, 기본 `제목 N`·`Heading N`, 삭제 가능)을 문서 순서로 합치고 새 번호 시작·구역 형식 상속을 반영한 찍히는 쪽 번호를 낸다. 앱 전체 기본값은 `userData/app-settings.json`의 `hwpOutlineStyleMap`에 원자적으로 저장하고, 문서별 값은 `설정:개요수준` 책갈피에 두어 문서별 값이 먼저 이긴다.
4. **개요 편집과 찾기 엔진(`outline.mjs`, `find.mjs`)**: 수준 올리기·내리기(기본 하위 함께, Shift로 해당 제목만)는 1–10 범위와 연결 스타일 존재를 미리 검증해 하나라도 어긋나면 아무것도 바꾸지 않고 거절하며 `applyStyle`로 한 단계 실행 취소에 묶는다. 단락 옮기기는 구역 경계·조판 부호(`secd`·`cold` 등)가 든 첫 문단·자기 하위 대상은 거절하고, 옮긴 앞뒤 개체 수와 책갈피 전체가 다르면 변경 묶음을 통째로 되돌린다. 찾기는 본문·표(중첩 표 포함)·글상자·각주·미주를 문서 순서로 돌고(머리말·꼬리말 제외), 목록에서 바꾸기는 한 번의 실행 취소로 줄 안 개체(`spansObject`)와 `인용:` 범위를 건너뛰며 건너뛴 수를 알린다. 작업창에서 한 편집은 모두 사람의 편집(`foreign`)으로 기록한다.
5. **AI·명령어·도움말**: `read_outline`, `change_outline_level`, `move_outline_section`, `find_in_document`를 `hwp-skill.ts`와 `ieumoffice hwp apply` / MCP / `guide hwp`에 연결한다(CLI도 `app-settings.json`의 `hwpOutlineStyleMap`을 읽는다). 껍데기 앱 도움말에 22개 언어 `hwp` 주제를 더한다.

## 버린 대안

- **문서별 설정을 앱 데이터에 파일 경로 기준으로 저장**: 문서를 다른 PC로 옮기거나 이름을 바꾸면 설정이 끊어지므로 문서 안 `설정:` 책갈피로 두었다.
- **엔진(Rust)에 전용 개요 이동·찾기 호출 추가**: 이번 작업창 단계는 엔진 저장·조판 동작을 건드리지 않고 기존 엔진 호출과 플러그인 조합으로 완결할 수 있어 엔진 패치를 넣지 않았다.
- **`Ctrl+F`를 기존 대화상자로 남기고 작업창에 새 단축키 부여**: 한컴 한글 2024의 `Ctrl+F`([보기]-[작업 창]-[탐색])와 맞추는 것이 기존 한글 사용자에게 자연스럽다(결정 0060).

## 결과

- 339쪽급 긴 논문에서도 AI 없이 왼쪽 작업창에서 개요 탐색·수준 편집·단락 이동과 다범위 찾기·바꾸기를 쓸 수 있고, 모든 편집은 한 번의 실행 취소와 개체·책갈피 보호 아래 동작한다.
- 뒤이을 차례·색인·제출본 기능과 참고문헌 기능이 바로 올라탈 문서 안 표시(`doc-marks.mjs`)와 확장 가능한 작업창 탭 틀이 마련되었다.
- 한컴 한글 2024에서 저장 파일을 열어 책갈피와 이동 결과를 보는 것, 339쪽급 실문서 반응 속도, 22개 언어 화면 넘침은 사람 확인 항목으로 남긴다.
