# 0178. 모바일 1판 홈·파일·설정: 꺼진 편집기 확인, 사본 편집, 목록 빼기·삭제 구분, 경로 기반 안전 쓰기

- 날짜: 2026-11-26
- 상태: 모바일 1판(배포 전), 일부 주인 승인(2026-11-26)

## 맥락

모바일 1판의 바깥 틀(T6)은 홈 4탭(`[최근][폴더][도구][설정]`), 문서 폴더 연결, 즐겨찾기·그룹, 파일 다루기, 공유로 받기, 편집기 켜고 끄기, 저장 공간·도움말·첫 실행·화면 꺼짐 막기를 맡았다. 개발 중 두 가지 제약이 함께 드러났다. 하나는 Android SAF 삭제가 휴지통 없이 되돌릴 수 없다는 점이고, 다른 하나는 기존 base64 문자열 인자 전달 방식이 Android에서 2,000만 자(약 14.3 MiB 파일)를 넘으면 거절되고 `"wt"` 쓰기가 실패 시 원본을 비울 수 있다는 점이었다(T1 시제품에서 발견).

## 결정

1. **꺼진 편집기의 파일은 열 때 묻는다.** 설정에서 끈 편집기는 홈 카드·만들기 시트에서 숨기되, 그 형식 파일을 열면 PC(결정 [0143](0143-editor-choice-and-ai-off.md))와 같이 `[켜고 열기][취소]`를 묻는다. 이를 위해 `App.tsx`의 여는 길에 `confirmEditorOn`을 둔다(트랙 밖 수정 승인).
2. **받은 파일·예시 문서·읽기 전용 파일은 `[사본으로 편집]`으로 고친다.** 원본 위치에 쓸 수 없는 문서는 편집 문지기(`view-edit-gate.ts`)를 넓히지 않고, 같은 내용의 이름 없는 문서로 열어 고치게 한다.
3. **첫 실행 말풍선은 기존 화면 요소를 찾아 띄운다.** 편집 화면(`EditorShell.tsx`)을 고치지 않고 기존 요소(`testid` 등) 옆에 말풍선을 놓는다.
4. **PDF 도구 연결은 역방향 등록 자리로 둔다.** T6이 `providePdfToolsLink` 자리를 두고 T3이 채워, 두 트랙 중 어느 쪽이 먼저 합쳐져도 독립 빌드되게 한다.
5. **목록 빼기와 파일 삭제 구분 및 기본값(주인 선택 2026-11-26).** `[최근]`·`[즐겨찾기]` 다중 선택 막대의 `[지우기]`는 "목록에서 빼기"이고, 실제 파일 지우기는 `[⋯]` 메뉴에 따로 둔다(Android SAF 삭제는 되돌릴 수 없음). `[폴더]` 탭의 `[지우기]`는 파일을 지우며, 연결 폴더를 빼면 그 안 파일의 최근·즐겨찾기 줄도 함께 뺀다. 새 한글 문서 기본 형식은 `.hwpx`, 예시 문서는 한국어·영어 `.hwpx` 두 벌, 읽는 동안 화면 꺼짐 막기는 기본 켜짐, 홈 공유는 원본 그대로로 둔다.
6. **파일 경로 기반 스트리밍 복사·안전 쓰기.** `MobileFileService`에 `copy_session_to_file`, `save_file_from_path`, `save_as_file_from_path`를, 모바일 플러그인에 `copy_uri_to_file`, `stream_file_to_uri`, `write_uri_from_file`을 둔다. `write_uri_from_file`은 ① 원본을 임시 작업 자리(`ieum-tmp/home/write`)에 복사 → ② 새 파일을 흘려 쓰기(Android `"wt"` + `fd.sync`, iOS 임시 파일 바꿔치기) → ③ 다시 읽어 바이트 비교 → ④ 실패·불일치 시 원본 복사본 복구 순서로 동작한다. 기존 `read_uri_bytes`·`write_uri_bytes_atomic`도 내부에서 같은 길을 쓴다.

## 버린 대안

- **꺼진 편집기 파일을 숨기기만 하고 열 때 묻지 않기:** PC판 편집기 고르기 동작과 뜻이 달라진다.
- **`[최근]` 막대에서 바로 파일 삭제:** Android SAF에서 실수로 원본 파일을 되돌릴 수 없이 지울 위험이 크다.
- **T6이 T3 모듈을 직접 가져오기:** T3 병합 전 빌드가 깨져 트랙 독립성이 무너진다.
- **base64 문자열 인자 유지:** 약 14.3 MiB를 넘는 엑셀·PDF 파일의 저장·복사·공유가 Android에서 막힌다.

## 결과

- Android 16 에뮬레이터에서 첫 실행 안내(OS 권한 창 없음), 4탭 홈, 예시 문서 사본 편집, PDF 안전 쓰기, 시스템 공유 시트가 확인되었다.
- T1 엑셀은 T6 병합 뒤 파일 경로 기반 명령으로 갈아타 14.3 MiB 한도를 해소한다.
- Android SAF에서 쓰기 도중 강제 종료 시 원본이 잘릴 수 있는 한계와 iOS 네이티브 빌드·실행 확인은 미해결 항목으로 남는다.
