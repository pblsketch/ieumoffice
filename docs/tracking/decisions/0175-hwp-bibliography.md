# 0175 — 한글 참고문헌 모음, 본문 인용·목록·점검과 AI 문헌 찾기

날짜: 2026-11-27

## 맥락

논문과 보고서를 한글 문서(`.hwp`, `.hwpx`)로 쓸 때는 여러 문서에 걸쳐 참고문헌을 한곳에 모아 두고, 본문에 인용을 넣은 뒤 인용 꼴(APA 7판, Chicago, MLA 9판, IEEE)을 바꾸면 본문 인용과 참고문헌 목록이 함께 바뀌어야 한다. 아울러 본문 인용과 목록이 어긋나지 않았는지 점검하고, 기존 문서에 적혀 있던 참고문헌을 모음으로 읽어 오며, 필요할 때는 AI로 문헌 후보를 찾되 근거 없는 서지 정보가 그대로 논문에 들어가지 않도록 막을 장치가 필요했다.

## 결정

1. **앱 전체 단일 문헌 모음(`src/main/bibliography.ts`, `src/main/bibliography-ipc.ts`, `studio-plugin/citation-io.mjs`)**:
   - 문헌 모음은 앱 데이터 폴더의 `<userData>/hwp-bibliography.json` 한 곳에 저장하고, 꼬리표(`tags`)로 주제·문서별로 걸러 쓴다. 쓰기는 동기 임시 파일 교체(원자적 저장)로 처리하고, 모음이 바뀌면 열린 모든 한글 탭에 `hwp:bib-changed`로 알린다.
   - 모든 참고문헌 IPC 창구는 `hwpViews.has(e.sender.id)`를 확인한다. `BibTeX`(`.bib`), `RIS`(`.ris`), `CSL JSON`(`.json`) 가져오기·내보내기 경로는 메인 프로세스의 파일 대화상자에서만 정하고, 렌더러는 파일 경로를 넘기지 못한다. 가져오기는 미리 보기(새 항목·중복 건너뜀) 확인 뒤 확정하는 2단계다.
2. **네 가지 인용 꼴과 문서 안 표시(`studio-plugin/citation-styles.mjs`, `studio-plugin/citations.mjs`)**:
   - `APA 7판`, `Chicago 저자-연도`, `MLA 9판`, `IEEE` 네 가지 인용 꼴을 지원하며, 국문 문헌은 네 꼴 모두에서 한국 학술 관례(겹낫표·굵은 학술지명 없음)로 통일해 적는다. 문서의 인용 꼴은 `설정:인용꼴` 책갈피에 저장한다.
   - 본문 인용은 `인용:` 시작·끝 책갈피와 `설정:인용` 메타데이터로 관리하고, 표 칸·글상자·각주·미주에는 책갈피 없이 글자만 넣는다. 참고문헌 목록은 `참고문헌:` 범위 표시와 `설정:참고문헌` 기대 줄 목록을 기록하고 내어쓰기를 건다.
   - 괄호·서술·다중 인용과 쪽수 지정, 같은 저자·연도 구분 기호(`a`, `b`), IEEE 등장 순 번호 매기기를 지원한다. 인용 꼴을 바꾸면 본문 인용과 참고문헌 목록이 한 번의 실행 취소 단계로 함께 바뀌며, 손으로 직접 고친 인용은 건너뛰고 건수를 알린다.
3. **안전장치·점검·낡은 것 알림(`workpane/BibliographyTab.tsx`, `i18n/biblio/`, `studio-plugin/staleness.mjs`)**:
   - 왼쪽 작업창에 **참고문헌** 탭(`[개요 | 찾기 | 참고문헌]`)과 도구 메뉴 항목 4종을 둔다. 작업창 편집을 포함한 모든 인용·목록 변경은 사람의 편집(`foreign`)이며, 개체·메모 보호(`keepingObjects`)와 실행 취소 한 단계·실패 시 통째 되돌리기를 거친다.
   - 6가지 읽기 전용 점검(목록 누락, 미인용 항목, 정렬 어긋남, 구분 기호 누락, 직접 수정한 인용, 미확인 문헌 인용)과 항목 클릭 이동을 제공한다. 기존 낡은 것 검사 등록부(`staleness.mjs`)에 참고문헌 목록·IEEE 번호 검사를 등록해 수동 저장·인쇄·PDF·제출본 저장 직전에 알리고, 제출본 저장은 `인용:`·`참고문헌:`·`설정:` 표시를 깨끗이 뺀 사본을 만든다.
4. **AI 문헌 찾기와 확인 필수 원칙(`hwp-skill.ts`, `AiPanel.tsx`, `packages/cli`)**:
   - AI가 기존 웹 검색("AI가 인터넷 도구 쓰기" 설정과 보호 규칙 준수)으로 찾은 문헌 후보(`search_references`)는 항상 **확인 필요**(`verified: false`) 상태와 출처 주소를 담은 메모로만 모음에 들어간다.
   - AI는 어떤 도구·경로로도 문헌을 **확인함**(`verified: true`)으로 바꿀 수 없으며, 확인 전 문헌은 본문 인용과 참고문헌 목록 생성에서 거절된다. 사람이 직접 출처를 확인한 뒤 작업창에서 **확인함**을 눌러야 인용할 수 있다. 터미널 명령어(`ieumoffice hwp apply`)에서는 화면·웹 검색 확인 흐름이 없어 `search_references`를 `unsupported`로 돌려준다.

## 버린 대안

- **프로젝트 폴더마다 문헌 모음을 따로 두기**: 논문이나 보고서가 프로젝트 폴더 밖에서도 자주 열리고 같은 문헌을 여러 글에서 다시 쓰는 경우가 많다. 단일 로컬 모음 + 꼬리표 분류가 단순하고 관리하기 쉽다.
- **AI가 찾은 문헌을 바로 확인함 상태로 넣기**: 웹 검색 요약에서 저자·연도·쪽수·DOI가 어긋나거나 존재하지 않는 서지가 섞일 위험이 크다. 사람이 확인하기 전에는 인용과 목록에 넣지 못하게 막는 편이 안전하다.
- **표시 없는 기존 참고문헌 목록이나 손으로 고친 목록을 확인 없이 덮어쓰기**: 사용자가 직접 다듬은 서지나 다른 도구에서 가져온 목록이 말없이 사라질 수 있다. 범위를 칠해 보이고 확인받거나 모음으로 읽어 오는 선택지를 함께 주었다.

## 결과

- AI 없이도 왼쪽 작업창과 도구 메뉴에서 문헌 관리, 가져오기·내보내기(`BibTeX`, `RIS`, `CSL JSON`), 문서 목록 읽어 오기, 본문 인용, 참고문헌 목록 생성·새로 고침, 인용 꼴 전환, 6종 점검을 모두 끝낼 수 있다.
- 다시 연 `.hwp`·`.hwpx` 문서에서도 인용과 참고문헌 목록을 알아보고 새로 고칠 수 있으며, 제출본 저장으로 내부 표시 없는 최종 파일을 떼어 낼 수 있다.
- AI 문헌 찾기를 쓸 때도 출처 미확인 서지가 논문에 그대로 인용되는 연구 부정 위험을 줄인다. 외부 한글 편집기에서 저장 파일 열기, 22개 언어 작업창 넘침, 실제 웹 검색을 통한 AI 문헌 찾기 확인은 사람 확인 항목으로 남긴다.
