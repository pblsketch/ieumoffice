# 0177. 모바일 1판 EPUB·PPT 읽기: PC 엔진·Konva 재사용, `blob:` 자원, 읽던 자리 저장

- 날짜: 2026-11-26
- 상태: 모바일 1판(배포 전), 주인 승인(2026-11-26)

## 맥락

모바일 1판(T5)은 EPUB 책과 PowerPoint(`.pptx`) 파일을 읽기 전용으로 지원해야 한다(고치기는 2판, 결정 [0165](0165-mobile-scope-and-design-system.md)). 두 형식의 문서 엔진(`@genoffice/epub-engine`, `@genoffice/pptx-engine`, `@genoffice/pptx-render`)은 원본·PC와 공유하므로 고치지 않고 재사용해야 했으며, 책 안의 스크립트 실행과 외부 네트워크 요청을 차단해야 했다.

## 결정

1. **EPUB 기본 읽기 방식과 `blob:` 자원 격리(주인 승인 2026-11-26).** EPUB은 쪽 넘기기를 기본으로 두고 이어 읽기로 전환할 수 있게 하며, PC 미리보기의 쪽 계산을 그대로 쓴다. 책 안의 HTML은 PC와 같은 정리(스크립트·`on…`·`javascript:`·`<base>` 제거)를 거쳐 스크립트 없는 틀(`sandbox="allow-same-origin"`)에 넣고, 책 zip 안의 그림·스타일·글꼴만 `blob:` 주소로 바꿔 책 밖(네트워크·기기 파일) 접근을 막는다.
2. **PPT PC 그리기(Konva)와 빌드 대역 재사용(주인 승인 2026-11-26).** PPT는 PC 슬라이드 앱의 같은 부품(`SlideThumb`, `konva`·`react-konva`)으로 그린다. PPT 엔진의 PC 전용 가져오기(`node:crypto` 등)는 엔진을 고치지 않고 이 트랙 빌드 규칙(`config/tracks/readers.ts`)으로 모바일 대역에 연결한다(결정 [0174](0174-mobile-v1-pdf-editor.md)와 같은 방식).
3. **PPT 글꼴 치수와 발표 범위(주인 승인 2026-11-26).** 1판 PPT 글꼴·줄 나눔은 앱 글꼴과 추정 치수를 쓰고, 내장 글꼴과 실제 글꼴 치수는 2판으로 미룬다. 발표는 앱 안 전체 화면 층(애니메이션·전환·영상 재생 없음, 숨긴 슬라이드 건너뜀, 방향 잠금 없음)으로 제공하며 슬라이드 글·노트 찾기를 넣는다.
4. **읽던 자리 Rust 파일 저장과 바깥 링크 확인(주인 승인 2026-11-26).** 읽던 자리는 iOS에서 지워질 수 있는 웹뷰 저장소 대신 앱 데이터 폴더의 `readers/positions.json`(문서별, 최근 1,000개)에 저장하고, 읽기 설정은 기기 전체에 하나를 둔다. 바깥 링크는 확인 시트를 거쳐 시스템 브라우저(T6 다리)로 열며 늘 `[주소 복사]`를 함께 둔다.
5. **1판 AI 진입점 제외와 열기 순서(주인 승인 2026-11-26).** EPUB·PPT는 1판에서 `editable: false`, `hasAi: false`로 AI 진입점을 두지 않는다(디자인 시스템 5.6 표와 달라 합칠 때 표를 맞춘다). 열기 순서는 한글 편집기와 같이 `open()`에서 바이트만 읽고 엔진은 화면 진입 뒤 실행하며, 거절 시 알림 뒤 홈으로 돌아간다.

## 버린 대안

- **모바일 전용 PPT 렌더러 별도 작성:** 표·차트·효과를 새로 구현해야 하고 PC와 렌더링이 갈라진다.
- **EPUB 자원에 커스텀 URI 스킴 또는 `data:` URI 사용:** 커스텀 스킴은 공용 `lib.rs` 빌더를 고쳐야 하고, `data:` URI는 큰 그림에서 메모리를 두 배로 쓴다.
- **읽던 자리를 웹뷰 `localStorage`에 저장:** iOS가 저장 공간 부족 시 웹뷰 저장소를 비울 수 있다.
- **`open()` 안에서 엔진을 돌려 오류를 던지기:** 현재 `App.tsx`가 홈에서 열기 오류를 표시하거나 열기 진행 표시를 보이지 못해 공용 파일을 고쳐야 한다.

## 결과

- `EpubWorkspace`, `PptxWorkspace`, `pptxDocument`가 지연 적재 덩어리로 분리되어 앱 시작 묶음에 Konva·jszip·엔진이 들어가지 않는다.
- Android 16 에뮬레이터에서 EPUB 스크립트 미실행 격리와 PPTX Konva 슬라이드 렌더링·넘기기가 확인되었다.
- `http:`·`mailto:` 바깥 링크의 T6 다리 허용 여부와 대용량 EPUB·PPTX의 iPhone 메모리·손짓은 추가 결정과 실기기 확인이 남아 있다.
