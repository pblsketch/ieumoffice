# 0163. 인쇄 출력 대상 통합·10개 편집기 라이브 미리보기·그림 저장·오버레이 고도화

날짜: 2026-11-23

## 맥락

고급 인쇄 배치(결정 [0141](0141-advanced-print-layout.md), [0158](0158-rust-print-layout-wasm.md))가 들어간 뒤에도 사용자 입장에서 몇 가지 불편이 남았다.

1. 인쇄 창에서 바로 **그림(PNG·JPG)으로 저장**할 수 없고, PDF 저장도 고급 배치 옵션을 켠 뒤 패널 맨 아래 단추로 숨어 있었다.
2. PDF·HTML·마인드맵·다이어그램·화이트보드 5개 편집기는 인쇄 창에 실제 출력 미리보기가 없었고, 나머지 5개 편집기도 고급 배치를 켜면 실제 결과 대신 추상 배치도만 보였다.
3. 한글 편집기 인쇄 미리보기에는 페이지 범위(전체·현재 쪽·특정 쪽)가 없었고, 배율 4모드(실제/맞춤/큰 쪽만 축소/사용자 지정 %)·용지 방향 강제·모아찍기 쪽 테두리·포스터 타일 좌표·인쇄 전용 워터마크/머리글·바닥글 같은 실무 인쇄 설정이 빠져 있었다.

## 결정

1. **출력 대상 드롭다운 통합**: 10개 편집기 모두 프린터 선택 목록에 `기본 프린터` · `설치된 프린터` · `PDF로 저장` · `그림으로 저장` · `시스템 인쇄 창`을 한 목록으로 둔다. 저장 대상을 고르면 프린터 전용 칸(매수·한 부씩·양면)을 숨기고, 저장 형식 칸을 보이며, 확인 단추 문구를 "인쇄"에서 "저장"으로 바꾼다. 기본 배치 상태에서도 바로 PDF·그림으로 저장할 수 있다.
2. **그림으로 저장(PNG/JPG, 개별/ZIP)**: PNG(기본)와 JPG(3단계 품질 90/80/65)를 지원한다. 1면이면 지정한 이름으로 1파일, 2면 이상이면 연번 파일(`이름-01.png`…) 또는 UTF-8 STORE `.zip` 1파일로 쓴다. JPEG 인코딩은 `packages/print-layout/wasm`에 `jpeg-encoder`(`(MIT OR Apache-2.0) AND IJG`, 네트워크 의존 0)를 더해 Rust WASM 기본 + 순수 TS 폴백으로 처리한다.
3. **권한 제한 PDF 이중 차단**: 결정 0141의 정책을 그림 저장까지 똑같이 넓힌다. 권한 제한이 걸린 PDF에서는 드롭다운의 `PDF로 저장`·`그림으로 저장`을 둘 다 비활성화하고 사유를 한 줄 안내하며, 메인 프로세스 IPC에서도 파일 대화상자 이전과 바이트 읽기 시점에 둘 다 거절한다.
4. **10개 편집기 온디맨드 라이브 미리보기 통일**:
   - 미리보기가 없던 5종(PDF·HTML·마인드맵·다이어그램·화이트보드)을 좌/우 분할 라이브 미리보기 창으로 바꾼다.
   - 기존 미리보기가 있는 5종(워드·엑셀·슬라이드·마크다운·한글)은 면 배치·회색조·워터마크·머리글/바닥글이 켜지면 `LivePrintPreview`로 자동 전환한다.
   - 메인 프로세스 `preview-faces` 세션이 작업 PDF와 배치 PDF를 캐시하고, 화면은 220ms 디바운스·LRU 24면 캐시·인접 면 프리페치로 보이는 면만 PDFium WASM으로 지연 렌더링한다. 패널 하단의 중복 "결과 미리 보기"·"배치한 결과를 PDF로 저장" 단추는 뺀다.
5. **실무 인쇄 기능 확장**:
   - 배율 4모드(`actual`·`fit`·`shrink`·`custom` 10–400%, 기존 `fitToPaper: true` 하위 호환), 용지 방향 강제(`auto`·`portrait`·`landscape`), 모아찍기 쪽 테두리 선(`nup.border`), 포스터 타일 좌표 라벨(`poster.tileLabels`).
   - 인쇄 전용 워터마크(글자·그림)와 6칸 머리글/바닥글은 **최종 출력 면 기준**으로 문서를 건드리지 않고 얹는다. 렌더러 Canvas 2D가 OS 글꼴(22개 언어 포함)로 투명 RGBA PNG 스탬프를 만들어 전달하면, Rust `lopdf` WASM(`stamp_pdf_overlays`, `pdf-lib` 폴백)이 Image XObject + `/SMask` + `/ExtGState`로 중복 없이 합성한다.
   - 한글 편집기 `PrintPreview`에 페이지 범위(전체·현재 쪽·특정 쪽)를 추가한다. 전체+기본 배치+시스템 인쇄 창 경로는 기존 그대로 둔다.

## 버린 대안

- **패널 하단에 "그림으로 저장" 단추를 따로 추가**: PDF 저장 단추와 중복되고 기본 배치 상태에서는 접근할 수 없어, 한컴오피스·Chrome과 같은 출력 대상 드롭다운 통합을 택했다.
- **인쇄 시 전체 면을 미리 한꺼번에 래스터화**: 대용량 문서에서 첫 화면 대기 시간과 메모리가 급증하므로, 메인 세션 캐시 + 보이는 면 온디맨드 지연 렌더링으로 설계했다.
- **워터마크/머리글·바닥글 글꼴을 PDF에 직접 임베드**: 22개 언어 CJK/아랍/히브리/힌디/태국 글꼴 서브세팅 복잡도와 번들 크기가 과도하므로, 렌더러 Canvas에서 OS 글꼴로 스탬프 PNG를 만들어 XObject로 한 번만 임베드하는 방식을 택했다.

## 결과

- 10개 편집기에서 같은 방식으로 출력 대상을 고르고, 실제 출력 모양을 미리 보며, PDF·PNG·JPG·ZIP으로 저장할 수 있다.
- 기존 `isDefaultOptions`·열 때마다 기본값 초기화·원본 문서 엔진 불변·`./plan` 무의존 경계는 그대로 유지된다.
