# T6 — 홈·파일·설정·첫 실행·모바일 전용 기능 (모바일 1판)

모바일 앱의 바깥 틀을 1판 모양으로 채웠다. 근거는 `docs/plans/mobile-scope.md`(A표 홈·파일·안전·설정, C표 폴더·휴지통·기본 앱·도움말·업데이트 소식, D표 공유·받기·첫 실행·저장 공간·화면 꺼짐)와 `docs/plans/mobile-design-system.md` 5.10·5.13·5.14·6·7·8. 자리 표는 [README.md](README.md), 쓰는 법은 `apps/mobile/AGENTS.md`의 `### T6 홈·설정 (1판)`.

## 한 일

- **홈 틀**(`components/HomeScreen.tsx`, `home/frame/`): 아래 탭 [최근][폴더][도구][설정](medium 이상은 왼쪽 레일). [도구]는 "PDF 도구"를 끄면 탭째 숨는다. [설정]은 설정 화면을 열고, 돌아오면 보던 탭으로 간다. [최근] 위쪽에 복구 사본 알림, 형식 카드(켜 둔 편집기의 새 문서, 설정의 숨기기·순서), "파일 열기" 카드. 그 아래 거르개 칩([전체][즐겨찾기], 그룹마다 하나, 형식 묶음이 둘 이상이면 형식 칩)과 목록. [+] 떠 있는 단추 → 만들기 시트(형식 타일, 파일 열기, PDF 도구). 빈 상태는 [예시 문서 열어 보기][파일 열기][새로 만들기].
- **파일 다루기**(`home/actions/`): 줄 [⋯] 메뉴(공유·이름 바꾸기·복사본·즐겨찾기·그룹으로 이동·목록에서 빼기·파일 지우기), 길게 눌러 여러 개 고르기와 아래 막대(최근·즐겨찾기는 [공유][목록에서 빼기][⋯], 폴더는 [공유][지우기][⋯], 모두 PDF면 [합치기], 모두 사진이면 [PDF로 만들기]), 이름 바꾸기·그룹 시트, 지우기 확인(Android "되돌릴 수 없습니다", iOS "휴지통으로 옮깁니다").
- **즐겨찾기와 그룹**: 별표 파일은 최근 목록(30개)과 따로 남고, 그룹은 파일 하나에 하나까지. 그룹을 지우면 파일은 별표 그대로 그룹 없음.
- **문서 폴더와 [폴더] 탭**(`home/folders/`): 시스템 폴더 선택 창으로 여러 폴더를 연결한다(Android 폴더 트리 + 오래 가는 허락, iOS 보안 범위 책갈피. OS 권한 창 없음, 모든 파일 접근 권한 없음). 하위 폴더로 들어가고, 열 수 있는 문서와 사진만 보인다. 허락을 잃으면 이유와 [다시 연결]. 폴더를 빼면 그 안 파일의 최근·즐겨찾기 줄도 함께 빠진다(개수를 먼저 보인다).
- **공유로 받기**(`home/incoming.ts`, `home/layer/ReceiveScreen.tsx`): 파일 하나는 전처럼 보기 모드로 연다(앱이 켜져 있을 때 받은 것도 앞으로 돌아올 때 연다). Android에서 여러 개나 사진을 받으면 받는 화면: [합치기]·[PDF로 만들기]·[열기], PDF 도구가 꺼져 있으면 [켜고 계속].
- **읽기 전용 문서의 [사본으로 편집]**(`home/layer/ReadOnlyStrip.tsx`): 받은 파일·예시 문서·읽기만 허락된 파일 위에 띠를 띄우고, 같은 내용의 이름 없는 문서로 열어 고친다(복구 사본 되살리기와 같은 길). 원본은 바뀌지 않는다.
- **편집기 켜고 끄기**(설정 > 일반 "편집기"): 꺼진 편집기는 카드·만들기 시트에서 빠지고, 그 형식 파일을 열면 [켜고 열기][취소]를 묻는다(PC와 같음, `home/editorGate.ts`). 모두 끈 값은 모두 켜짐으로 읽는다.
- **설정**(`settings/`): 일반에 편집기·홈 화면의 새 문서(보이기·위로·아래로)·읽는 동안 화면 꺼짐 막기를 더했다(맨 끝 줄은 AI 스위치 그대로). 문서 폴더 절, 한글 원본 백업 합계 크기, 저장 공간(복구 사본·임시 파일·원본 백업 크기, 임시 파일 지우기, 복구 사본 모두 지우기 — 열린 문서 것은 남김), 도움말, 앱 판 번호.
- **도움말**(`settings/sections/HelpSection.tsx`, `home/help/`): 사용법 짧은 글 6개, 처음 안내 다시 보기, 의견 보내기(PC와 같은 설문을 시스템 브라우저로, 판·OS·언어를 클립보드에 복사, 앱은 아무것도 보내지 않음), 이번 판에서 바뀐 것.
- **첫 실행**(`home/layer/FirstRunOverlay.tsx`): 두 단계(반가워요 → 문서 폴더 연결(선택)), 어느 단계든 건너뛰기, AI를 묻지 않음. 설정 값에 그 칸이 없으면(옛 뒷단) 띄우지 않는다.
- **처음 쓰는 순간의 말풍선 넷**(`home/layer/TipLayer.tsx`): 편집 단추, 흐름 보기 전환, 첫 편집, 첫 키보드. 한 번씩, 막는 창이 아니고, 낭독기는 알림으로 읽고 초점을 옮기지 않는다. 편집 화면 파일을 고치지 않고 기존 화면 요소(testid, "쪽 보기" 단추 이름)를 찾아 옆에 놓는다.
- **이번 판에서 바뀐 것**: 판 번호를 기억해 올랐을 때 한 번 띄운다. 새로 깔 때는 띄우지 않는다. 1판 내용은 도움말에서만 보인다.
- **읽는 동안 화면 꺼짐 막기**: 설정 하나(기본 켜짐) + T2·T5가 부르는 훅(아래).
- **예시 문서**: 한국어·영어 `.hwpx` 두 벌(`src-tauri/src/storage/samples/`), 읽기 전용으로 열리고 최근 목록에 들어가지 않는다.
- **Rust**(`src-tauri/src/storage/home/`, `commands/home.rs`): 연결 폴더(`folders.json`), 즐겨찾기·그룹(`favorites.json`), 이름 바꾸기 뒤 최근·즐겨찾기·복구 사본·원본 백업 열쇠 다시 묶기, 받은 묶음, 저장 공간 크기·지우기, 앱 정보, 예시 문서. 최근 목록에 선택 칸 `folder_id`(옛 `recent.json` 그대로 읽힘).

## 결정 후보 (번호는 합칠 때)

1. **꺼진 편집기의 파일은 열 때 묻는다(PC와 같음).** 숨기기만 하는 안은 버렸다(PC와 뜻이 달라짐). 이 때문에 `App.tsx`의 여는 길에 한 줄이 들어갔다.
2. **받은 파일·예시 문서는 원본에 바로 고쳐 쓰지 않고 "사본으로 편집"으로 고친다.** 편집 문지기(`view-edit-gate.ts`)를 넓히는 안은 원본 보호 규칙과 얽혀 버렸다.
3. **말풍선은 편집 화면 파일을 고치지 않고 기존 화면 요소를 찾아 놓는다.** `EditorShell.tsx`에 자리를 내는 안은 남의 파일이라 버렸다. 대신 그 요소 이름이 바뀌면 말풍선이 뜨지 않는다(`tests/home-layer.test.tsx`가 지킨다).
4. **T3 연결은 T6 파일의 등록 자리를 T3이 채운다.** T3 함수를 직접 가져오면 T3이 늦게 합쳐질 때 빌드가 깨져서다.
5. **[최근]·[즐겨찾기]의 막대 [지우기]는 "목록에서 빼기"이고, 파일 지우기는 [⋯] 안에 따로 둔다.** Android SAF 지우기는 되돌릴 수 없어서다(사람이 고름). [폴더] 탭의 [지우기]는 파일을 지운다.
6. **새 한글 문서의 기본 형식은 `.hwpx`.** 화면 쪽 기본값(`.hwp`)을 뒷단(`.hwpx`)에 맞췄다.
7. **화면 꺼짐 막기는 기본 켜짐**, 홈 공유는 원본 그대로, 폴더를 빼면 그 안 파일 줄도 함께 지움, 예시 문서는 `.hwpx` 두 벌(사람이 고름).

## 발견 (고치지 않음)

1. **받은 하나짜리 문서의 원본 위치 저장.** 편집 문지기가 쓸 수 없는 문서의 편집을 막아, 받은 파일은 "사본으로 편집"으로만 고친다. 디자인 시스템 5.13의 "원본 위치에 저장할 수 없으면 사본으로 저장"은 이 길로 이룬다.
2. **같은 파일이 두 줄이 될 수 있다.** 폴더로 연 것과 파일 고르기로 연 것은 문서 위치가 달라 최근 목록에 따로 보인다. 1판은 받아들였다.
3. **iOS 네이티브는 빌드·실행 확인 안 됨.** Swift 코드를 썼지만 이 PC(Windows)에서 빌드할 수 없다. iOS의 "다른 앱에서 열기"는 앱 위임에 이어져 있지 않고(T6 전부터), 파일 고르기·저장 창(`pickOpenFile`·`createSaveFile`)도 iOS 구현이 없다(T6 전부터). 오래된 책갈피는 새로 고치지 않는다.
4. **Android 이름 바꾸기·복사는 `DocumentsContract.findDocumentPath`로 상위 폴더를 찾는다.** 이것을 지원하지 않는 저장소 앱에서는 "이 위치의 파일은 바꿀 수 없습니다"가 된다(지우기는 된다).
5. **예시 문서의 글머리표.** claw-hwp로 만든 뒤 글머리 문단 모양을 손으로 고쳤다. rhwp로는 맞게 보이지만 한컴 웹 문서에서는 글머리 모양이 빠질 수 있다(한컴으로 확인 안 함).
6. **말풍선·읽기 전용 띠가 편집 화면 요소 이름에 기댄다**(`editor-header`, `editor-notice-banner`, `editor-mode-toggle`, `editor-save-btn`, `format-panel-btn`, `hwp-flow-view`, "쪽 보기" 단추 이름). 셸이 바뀌면 함께 봐야 한다.
7. **새 문구의 번역**(T6 문구 약 200개 × 21개 언어)은 모국어 사용자가 보지 않았다.
8. **읽기 전용 띠가 문서 맨 위를 가린다.** 편집 화면 파일을 고치지 않으려고 띠를 고정 위치로 띄워서, 문서 첫 줄(예시 문서의 제목 등)이 띠 아래에 가려진다. [닫기]로 치우면 보인다. 문서 영역이 띠만큼 내려가게 하려면 셸(`EditorShell`)에 자리가 필요하다.
9. **[도구] 탭은 T3 병합 전에는 비어 있다.** "PDF 도구"가 켜져 있으면 탭은 보이지만 내용(`ToolsTab.tsx`)은 T3가 채운다.
10. **"이번 판에서 바뀐 것" 1판 목록**(`home/help/whatsNew.ts`)은 1판 범위 문서로 썼다. 합칠 때 실제로 들어간 트랙과 맞춰야 한다.
11. **"복구 사본 모두 지우기"는 이번 실행에서 쓴 복구 사본을 모두 남긴다**(열린 문서 것만이 아니라). 지금 고치는 중일 수 있는 사본을 지우지 않으려는 것으로, spec(열린 문서 것만 남김)보다 넓다.
12. **앱 정보를 읽는 곳이 넷이다**(설정·도움말·파일 다루기·폴더 탭이 각자 `appInfo`를 부르고 따로 기억). 같은 값이라 동작은 같지만, 하나로 모으면 좋다.
13. **TS 다리 감싸개와 Rust 명령 이름·인자 이름을 맞춰 보는 자동 시험이 없다.** 손으로 맞췄다(마지막 검토에서 27개 모두 일치 확인).
