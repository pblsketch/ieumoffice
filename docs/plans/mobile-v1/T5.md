# T5 — EPUB·PPT 읽기 (모바일 1판)

휴대폰·태블릿에서 EPUB 책과 PowerPoint(`.pptx`) 파일을 읽는다. 고치기는 2판이다. 근거는 `docs/plans/mobile-scope.md` A표 EPUB·PPT 줄, D표 "읽는 동안 화면 꺼짐 막기", 디자인 시스템 5.6(EPUB·PPT 읽기 막대)·5.12·5.13. 자리 표는 [README.md](README.md), 쓰는 법은 `apps/mobile/AGENTS.md`의 `### T5 EPUB·PPT 읽기 (1판)`.

## 한 일

- **EPUB 읽기**: 쪽 넘기기(기본, 좌우 밀기·가장자리 누르기)와 이어 읽기(위아래). 장의 끝·처음에서 앞뒤 장으로 넘어가고, 오른쪽에서 왼쪽으로 쓰는 책과 세로쓰기 책은 반대로 넘기며, `linear="no"` 항목은 건너뛴다. 목차 시트, 책 전체 찾기(찾은 곳 강조, 500곳까지), 읽기 설정 시트(글자 크기·줄 간격은 PC와 같은 단계, 바탕 [앱 따라·밝게·세피아·어둡게], 읽는 모양). 책 안 링크는 그 자리로, 바깥 링크는 확인 시트로. 고정 배치 책은 한 쪽씩 화면에 맞춘다. 읽던 자리와 읽기 설정을 기억한다.
- **책 안의 코드를 돌리지 않는다**: PC와 같은 정리(스크립트·`on…`·`javascript:`·틀·`<base>` 지움)를 거친 사본을 스크립트 없는 틀(`sandbox="allow-same-origin"`)에 넣고, 그림·스타일·글꼴은 책 zip 안의 항목만 `blob:` 주소로 바꿔 보인다. 책 밖(네트워크·기기 파일)으로는 아무것도 부르지 않는다. 감춘 글꼴은 엔진으로 풀어 쓴다.
- **PPT 읽기**: 슬라이드 하나씩 넘기기(밀기·가장자리·단추), 두 손가락 확대, 발표자 노트 칸(넓은 창은 오른쪽), 슬라이드 목록 격자(숨긴 슬라이드 흐리게), 슬라이드 글·노트 찾기, 전체 화면 발표(숨긴 슬라이드 건너뜀, "발표 끝" 화면), 마지막 본 슬라이드 기억. 그리기는 PC 슬라이드 앱의 같은 부품(`SlideThumb`, Konva)으로 한다.
- **공통**: 두 종류 모두 읽기 전용(`editable: false`, `hasAi: false`), 원본 그대로 공유, 다른 앱에서 열기(Android VIEW·SEND, iOS 문서 형식), 읽는 동안 화면 꺼짐 막기(T6 훅), 22개 언어 문구 69개.
- **엔진은 고치지 않았다**: EPUB 엔진은 읽기 진입점(`/core`)만, PPT 엔진은 PC 전용 가져오기(`node:crypto` 등)를 이 트랙의 빌드 규칙으로 휴대폰 대역에 이어 그대로 쓴다. PC 앱 파일(`apps/epub`, `apps/slides`)도 가져다 쓰기만 했다.
- **Rust**: 읽던 자리·읽기 설정 저장(`commands/readers.rs`, `commands/readers/store.rs`, 앱 데이터 `readers/positions.json`).

## 다른 트랙과의 약속

- **T6 화면 꺼짐 막기**: `home/keepScreenOn.ts`의 `useKeepScreenOn(client, active)`를 `import.meta.glob`으로 찾아 부른다(`editors/readers/shared/keepScreenOn.ts`). T6이 없으면 아무것도 하지 않는다. T6이 합쳐져도 이 트랙 코드를 고칠 필요가 없다. EPUB 읽는 화면, PPT 넘기기·발표 화면이 보이는 동안 켠다.
- **T6 바깥 주소 열기**: `@genoffice/mobile-bridge/home`의 `openExternalUrl`이 있으면 쓴다(`shared/externalUrl.ts`). T6 다리는 `https:`만 열기 때문에 [열기] 단추는 `https:` 주소에만 보이고, `http:`·`mailto:`는 [주소 복사]만 된다(spec은 http·https·mailto 셋을 열기로 적었다 — 아래 발견 11).
- **임시 파일**: 이 트랙은 앱 안 임시 파일을 만들지 않는다(쓸 일이 생기면 `ieum-tmp/readers/`).
- **편집기 켜고 끄기**: 종류 id는 `epub`·`pptx`, 이름은 `readersEpubKindLabel`("EPUB 책")·`readersPptxKindLabel`("PowerPoint").

## 결정 후보 (번호는 합칠 때, 11-26 주인 승인)

1. **EPUB 읽는 모양은 쪽 넘기기가 기본, 이어 읽기로 바꿀 수 있다.** 휴대폰 전자책 관례이고 PC 미리보기의 쪽 계산을 그대로 쓴다.
2. **PPT는 PC 슬라이드 그리기 부품(Konva)을 그대로 쓴다.** 모바일 전용 그리기는 PC와 그림이 갈라지고 표·차트·효과를 새로 짜야 해서 버렸다. 새 의존 `konva`·`react-konva`(MIT).
3. **PPT 글꼴·줄 나눔은 앱 글꼴과 추정 치수.** 파일 안 내장 글꼴과 실제 글꼴 치수는 2판.
4. **발표는 앱 안 전체 화면 층**(지원되면 시스템 막대도 숨김), 애니메이션·전환 효과·영상 재생 없음, 숨긴 슬라이드 건너뜀, 방향 잠금 없음. 슬라이드 글·노트 찾기를 넣었다.
5. **읽던 자리는 기기 안 이 트랙 파일**(Rust, 문서마다, 최근 1,000개 — PC와 같은 수). 웹뷰 저장소는 iOS에서 지워질 수 있어 버렸다. 읽기 설정은 기기 전체에 하나.
6. **EPUB·PPT에는 1판 AI 진입점이 없다.** 디자인 시스템 5.6 표의 [AI]와 어긋나므로 합칠 때 그 표를 맞춘다.
7. **바깥 링크는 확인 시트 → 시스템 브라우저**(T6 다리), 늘 주소 복사.
8. **여는 순서는 한글 편집기와 같다**: 종류의 `open()`은 바이트만 읽고 엔진은 문서를 연 뒤 돈다. 거절이면 알림 뒤 홈으로. `open()` 안에서 엔진을 돌리고 오류를 던지는 안은, 지금 앱이 그 오류를 홈에 보이지 못하고 여는 동안 진행 표시도 없어 `App.tsx`를 고쳐야 해서 버렸다.
9. **EPUB 자원은 `blob:` 주소로 바꿔 그린다.** 커스텀 URI 스킴 등록은 공용 `lib.rs` 빌더를 고쳐야 해서, 장 전체를 `data:`로 넣는 안은 큰 그림에서 메모리가 두 배라서 버렸다.
10. **PPT 엔진의 PC 전용 가져오기는 이 트랙 빌드 규칙으로 바꿔 끼운다**(엔진 경로 안 모듈에만). T2가 PDF 저장 코드에 쓴 방식과 같다.

## 발견 (고치지 않음)

1. **열지 못한(거절된) 파일도 최근 목록에 남는다.** 문서 전환 뒤에 엔진이 열기 때문이다(결정 후보 8).
2. **[더 보기]에 "다른 이름으로 저장" 줄이 늘 보이고 눌러도 아무 일이 없다.** 공용 셸이 그 줄을 늘 그린다. 셸에서 저장 함수가 없는 종류에는 숨겨야 한다(주인 승인: 합칠 때 셸에서 정리).
3. **PPT의 EMF·WMF 그림은 빠진 그림으로 보인다**(PC 변환은 워드 엔진 패키지까지 묶여 들이지 않았다). TIFF 그림도 웹뷰가 그리지 못해 보이지 않는다. 테마 색을 쓰는 SVG는 다시 칠하지 않는다(PC의 다시 칠하기가 메인 프로세스 파일에 있다. 엔진 테마 함수로 다시 짤 수 있다).
4. **추정 치수 때문에 PPT 글의 낱말 사이가 PC보다 넓어 보일 수 있다**(미리보기에서 제목 낱말 사이가 한 칸보다 넓게 벌어져 보였다). 결정 후보 3의 대가이고, 실제 글꼴 치수는 2판.
5. **슬라이드 안 링크는 누를 수 없다**(그림으로 그려짐).
6. **PPT 엔진은 열 때 zip의 모든 항목(영상·소리 포함)을 풀어 두고 모든 슬라이드 모델을 만든다**(엔진 동작). "보일 때만"은 그림 주소·그림·그리기 데이터에만 해당한다. 영상이 든 큰 덱의 메모리는 실기기에서 볼 것.
7. **받은 파일(임시 세션)은 받을 때마다 문서 열쇠가 달라지면 읽던 자리를 기억하지 못한다.** 같은 파일을 폴더와 파일 고르기로 따로 열어도 자리가 따로 남는다(T6 발견 2와 같은 뿌리).
8. **공용 셸의 위 막대·아래 도구는 숨길 수 없다.** 가운데 누르기는 이 트랙의 쪽 위치 줄만 숨긴다. 전체 화면 읽기를 하려면 셸에 자리가 필요하다.
9. **PPT 확대는 그림을 CSS로 키운 것이라 많이 키우면 흐려진다**(더 큰 폭으로 다시 그리지 않음).
10. **0장 덱에서는 목록·발표 단추를 끄지 않고 뺀다**(셸의 보기 도구에 꺼짐 상태가 없다).
11. **`http:`·`mailto:` 바깥 링크는 열지 못하고 주소 복사만 된다.** T6 다리가 `https:`만 연다. 셋 다 열려면 T6 다리를 넓혀야 한다.
12. **PPT 찾기는 슬라이드 자신의 글과 노트만 본다.** 마스터·레이아웃에서 온 글(꼬리말·쪽 번호)은 찾지 않는다.
13. **jsdom은 Konva를 그리지 못하고 `srcdoc`·배치를 재지 못한다.** 화면 시험은 `SlideThumb`·배치를 흉내 냈고, 실제 그림·쪽 나누기·손짓은 390px 미리보기에서 봤다. 실기기에서 손짓·`CSS.highlights`·넘김을 볼 것.
14. **PPT 어댑터 시험 하나는 Node 자식 프로세스(`node --import tsx`)로 PC와 같은 그리기 데이터가 나오는지 견준다.** `tsx`가 루트 `node_modules`에 있어야 돈다.
15. **새 문구(69개 × 21개 언어)는 모국어 사용자가 보지 않았다.**

## 확인한 것

- 시험: `apps/mobile` 30개 파일 304개(이 트랙 7개 파일), `packages/mobile-bridge` 31개, Rust `cargo test readers` 14개. 형 검사·eslint·`format:check`·`check:lang-count`·`check:theme-colors`·`check:english-comments`·`licenses`·모바일 웹 묶음 빌드 통과.
- 빌드 결과: 앱 시작 덩어리에 Konva·jszip·엔진·PC 읽기 코드가 들지 않는다(`EpubWorkspace`·`PptxWorkspace`·`pptxDocument` 덩어리로 따로 불러온다). 빌드 결과에 `node:` 모듈이 남지 않는다.
- 390px 미리보기(가짜 다리, 포트 47815): 견본 EPUB(시험에서 만든 세 장짜리 책)과 PPT 엔진 시험 덱으로 열기·쪽 넘기기·목차·어두운 바탕·큰 글자·슬라이드 넘기기·노트·슬라이드 목록·발표·발표 끝 화면. 책 안의 스크립트는 돌지 않았다.

## 실기기에서 볼 것

- 큰 EPUB(그림 많은 수백 MB)·큰 PPT(영상 포함)의 메모리, 특히 iPhone.
- 밀기·가장자리 누르기·두 손가락 확대와 글 고르기(길게 누르기)가 부딪히지 않는지.
- 쪽 넘기기의 단 나누기(세로쓰기·rtl 책 포함), 찾은 곳 강조(`CSS.highlights`가 없는 웹뷰).
- 화면 꺼짐 막기(T6 병합 뒤), 전체 화면 발표에서 시스템 막대가 숨는지(웹뷰 전체 화면 API 지원).
- 다른 앱(메신저·메일·파일 앱)에서 `.epub`·`.pptx` 열기·공유로 받기.
- PPT 글꼴: 한글 슬라이드의 줄 나눔과 낱말 사이.

## 합칠 때 정리할 것

- `package-lock.json`을 다시 만든다(`npm install --package-lock-only`). T2와 같은 의존(`buffer`, `@noble/hashes`)이 겹친다.
- Node 대역 두 벌(T2 `editors/pdf/engine/node-shims/`, T5 `editors/readers/build/node-shims/`)을 하나로 모을지 정한다.
- `native-config/android/intent-filters-fragment.xml`의 SEND 거르개: T5 표시 아래에 T6이 `image/*` 줄을 넣었다. 두 트랙 줄을 모두 남긴다.
- 공용 셸(`EditorShell`)에서 저장 함수가 없는 종류에는 "다른 이름으로 저장" 줄을 숨긴다(발견 2, 주인 승인).
- 디자인 시스템 5.6 표의 EPUB·PPT 줄에서 [AI]를 뺀다(결정 후보 6).
- 결정 후보 1번부터 10번까지 → 결정 파일, 발견 1번부터 14번까지 → `docs/tracking/findings.md`(15는 PR 본문에만).
- `docs/tracking/status.md` 줄 초안: "모바일 1판 EPUB·PPT 읽기(T5): EPUB 쪽 넘기기·이어 읽기·목차·찾기·글자 크기·바탕·읽던 자리, PPT 넘기기·노트·슬라이드 목록·찾기·전체 화면 발표, 원본 공유·다른 앱에서 열기·화면 꺼짐 막기. 엔진은 그대로(PPT는 빌드 대역). 실기기 확인 남음."
