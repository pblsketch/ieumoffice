# 모바일 1판 트랙

모바일 1판에 남은 일을 트랙 일곱이 나란히 만든다. 세션 0(S0)이 공용 파일을 트랙 자리로 갈라 둔 뒤(가지 `feat/mobile-v1-base`), 트랙마다 자기 사본·가지(`feat/mobile-v1-<트랙ID 소문자>`)에서 일하고 `feat/mobile-v1-base`로 PR을 연다. 범위의 근거는 `docs/plans/mobile-scope.md`, 화면 부품·AI 보임 규칙은 `docs/plans/mobile-design-system.md`, 결정 0165.

## 어디에 넣는가

S0이 만든 자리는 미리 이어 붙여 두었다. 등록표·문구 묶음·아이콘 지도·다리 내보내기·`commands/mod.rs`는 import·펼침·`pub mod`·`exports` 줄까지 써 있으므로 트랙은 자기 폴더의 파일만 채운다. 공용 파일에 줄을 더하는 곳은 Rust 명령 등록·관리 상태(`lib.rs`), Rust 의존(`Cargo.toml`), 플랫폼 형식 선언(`native-config`) 셋뿐이고, 모두 자기 표시 주석 바로 아래에 넣는다. 경로의 기준: `editors/`·`i18n/`·`components/`·`settings/`·`home/`·`ai/`는 `apps/mobile/src/renderer/` 아래, `commands/`는 `apps/mobile/src-tauri/src/` 아래, `native-config/`는 `apps/mobile/` 아래, 다리 모듈은 `packages/mobile-bridge/` 아래.

공통 규약에 더한 소유: 앱 설정 형(`packages/mobile-bridge/src/transport.ts`의 `MobileAppPrefs`·`MobileAppPrefsPatch`)과 `settings/defaultPrefs.ts`는 T6. `native-config/**`는 편집기 트랙(T1·T2·T4·T5)이 자기 표시 아래 줄만, 나머지는 T6. `editors/markdownKind.tsx`는 T4.

어느 트랙도 고치지 않는 것(바꿔야 하면 기획에서 승인, 따로 커밋): `vite.config.ts`·`vitest.config.ts`·`tsconfig.json`(트랙 설정은 `config/tracks/`), `App.tsx`, `shell/**`, `editors/editorKind.ts`·`registry.ts`·`hwpKind.tsx`와 기존 한글 편집기 파일, 기본 사전(`i18n/<언어>.ts`)·`i18n/strings.ts`, `components/MobileIcons.tsx`·`components/icons/index.ts`·`types.ts`·`svgIcon.tsx`, 다리의 `transport.ts`(앱 설정 형 빼고)·`index.ts`·`package.json`.

문서마다 다른 읽기 전용·AI 숨김, 닫을 때 정리(`dispose`), 열다가 취소는 편집기 종류의 문서 객체가 앱에 알린다(11-25 보강, `apps/mobile/AGENTS.md`의 "문서마다 다른 것").

자리마다 쓰는 법은 `apps/mobile/AGENTS.md`의 "1판 트랙 자리"에 있다.

## 공통 규약 요약

- **절대 게이트**: 구독 로그인 정보에 손대지 않고 ChatGPT 바로 연결을 켜지 않는다. 요금 경로로 스스로 바꾸지 않는다(OpenRouter 무료는 `:free`만). 실제 구독·API 키로 AI를 돌려 확인하지 않는다. 문서 엔진 동작·저장 결과를 바꾸지 않는다(엔진 패키지·크레이트를 고쳐야 하면 멈추고 묻는다). `@genoffice/*`·`GENOFFICE_*`를 바꾸지 않는다. PC 동작을 바꾸지 않는다. 모바일 AI는 기본 꺼짐, 꺼지면 진입점을 자리째 숨긴다. 화면 문구 22개 언어(터키어 포함), 색은 토큰만, 강조 띠 없음, 코드 주석은 영어. iPhone 웹뷰 메모리 안에서(고정 상한으로 자르지 않음). 첫 실행에서 OS 권한 창 없음, 파일은 시스템 선택 창으로만.
- **충돌 규칙**: 자기 자리와 자기 폴더만 고친다. `docs/tracking/**`, 루트 `CLAUDE.md`·`AGENTS.md`, `docs/plans/mobile*.md`, 엔진 패키지는 고치지 않는다. npm·Rust 의존은 "deps:" 커밋 하나로 따로(잠금 파일은 합칠 때 다시 만든다), 새 의존은 라이선스 확인.
- **git**: `git add`는 경로를 적어서, `git stash` 쓰지 않음, 강제 푸시 없음, 푸시는 가지를 적어서. 커밋은 영어, PR 본문·보고는 한국어. PR은 `feat/mobile-v1-base`로 열고 병합하지 않는다.
- **임시 파일**: `F:\ieum-scratch\mobile-v1-<트랙ID 소문자>\` 아래만. 미리보기 포트는 S0 47810, T1 47811 … T7 47817.
- **검사**: 모바일·고친 패키지 typecheck, vitest, eslint, `format:check`, `check:lang-count`, `check:theme-colors`, `check:english-comments`, 모바일 웹 묶음 빌드, Rust를 고쳤으면 `cargo test`, 390px 미리보기 한 바퀴.
