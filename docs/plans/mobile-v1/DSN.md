# DSN — 모바일 1판 디자인 시스템 (토큰 층·공용 부품·쓰는 규칙)

상태: **앞 단계 끝(2026-11-26)** — 토큰 층, 토큰 파일 나누기, 공용 부품 `ds/`, 지키는 시험. 화면은 아직 바뀌지 않았다. **뒤 단계**(화면 갈아끼우기)는 트랙 PR(T2~T7)이 바탕 가지에 합쳐진 뒤 그 위에서 한다.

확정 디자인 시스템([mobile-design-system.md](../mobile-design-system.md), 결정 0165)을 바꾸지 않고 그 위에 쌓는다. 점검 근거는 390·820·1280px, 밝게·어둡게 미리보기 한 바퀴(11-26)다.

## 왜

트랙 여섯은 색·글자·간격 토큰을 잘 지켰다. 직접 색 0건, 직접 글자 크기도 사실상 0건이다. 그런데 같은 역할의 화면 조각이 트랙마다 다른 모양이 되었다.

- 고른 것 표시가 다섯 가지다(채움, 두꺼운 테두리, 바깥 고리, 파란 테두리, 흰 고리).
- 선 아이콘 크기가 열다섯 가지다(14~38px).
- 빈 상태가 네 모양이다.
- 보기 도구와 쪽 표시가 세 가지다.
- 누를 영역이 48px에 못 미치는 곳이 여섯 군데다(저장 상태 15px, 거르개 칩 32px, 스위치 24px, AI 보내기 38px, [편집]·[완료] 40px, 선택 상자 36px).
- 도구 탭은 좌우 여백이 0이다.
- 설정 탭이 다른 화면으로 열려서 태블릿에서 레일이 사라진다.
- 말풍선이 편집 막대와 AI 입력칸을 가린다.
- 넓은 창에서 줄 길이에 제한이 없다.

## 쓰는 규칙

1. **고른 것은 두 모양뿐이다.**
   - 목록 줄·칩·메뉴 줄·탭 안 선택은 바탕 `--m-selected-bg`와 글 `--m-selected-fg`.
   - 선택지 타일과 칸 나눔은 안쪽 고리(`--m-selected-ring-w` `--m-selected-ring`).
   - 색 견본은 바깥 고리. 고르지 않은 견본에도 1px 둘레가 있어 어두운 시트 위 검정 견본이 보인다.
   - "지금 열린 것"은 고른 것과 따로 `--m-current`와 `aria-current`로 나타낸다.
   - 색만으로 알리지 않는다. `aria-pressed`·`aria-checked`·`aria-selected`·`aria-current` 중 맞는 것을 단다.
2. **선 아이콘은 네 크기만 쓴다.** 숫자 대신 크기 이름(`<Icon size="m">`, 숫자를 받는 아이콘 함수에는 `iconPx('m')`)을 쓰고, 같은 역할은 같은 크기다. 형식 그림(`DocTypeIcon`)과 제품 아이콘(`IeumAppIcon`)은 그림이라 제외한다.
3. **누를 영역은 48×48 이상, 서로 8px 이상 떨어진다.** 스위치가 있는 설정 줄은 줄 전체가 누를 영역이다. 저장 상태 글도 48 높이다.
4. **탭 화면 머리(`ScreenHeader`)는 하나다.** 제목·설명 한 줄·오른쪽 동작으로 이뤄진다. 좌우 여백은 600px 미만 16px, 그 이상 24px이고, 840px 이상에서는 `--m-content-max` 안에서 가운데에 둔다.
5. **설정 묶음(`SettingsGroup`)의 머리는 카드 밖에, 설명은 카드 아래에 둔다.** 첫 묶음에도 머리가 있다. 줄 높이는 한 줄 `--m-row-h`, 두 줄 `--m-list-item-h`다.
6. **빈 상태(`EmptyState`)는 한 모양이다.** 아이콘(xl)·제목·설명·주 단추 하나·보조 단추 하나로 이뤄진다. 화면에서는 점선 카드, 시트 안에서는 테두리 없이 그린다.
7. **단계 화면의 주 단추는 아래 고정 줄(`StickyActions`)에 둔다.** 첫 실행, PDF 도구의 [다음]·[실행]이 그렇다. 보조 동작은 같은 줄의 선·글 단추나 머리 오른쪽에 둔다.
8. **진행 표시는 세 부품이다.**
   - `Spinner`: 300ms가 넘을 때만 보인다.
   - `LinearProgress`: 시트·단계 화면 안에서 [멈추기]와 함께 쓴다. 양을 모르면 흐르는 막대로 그린다.
   - `DocSkeleton`: 문서 열기가 300ms를 넘으면 쪽 모양 자리표시를 보인다.
9. **더보기·문서 메뉴(`ActionList`)는 모든 줄에 아이콘이 있다.** 아이콘이 없는 줄은 그려지지 않는다. 다른 회사 로고·앱 아이콘은 쓰지 않는다.
10. **상단 바 이름은 가운데를 줄이고 확장자를 남긴다.**
11. **보기 도구는 `FloatingTools`로 쓴다(오른쪽).** 쪽 표시는 `PageIndicator`로, 같은 줄 왼쪽에 둔다.
12. **말풍선은 한 화면에 하나다.** 시트·확인 창·AI 창·키보드가 열려 있거나 다른 말풍선이 떠 있으면 미룬다(`canShowTip`). 막대·입력칸·주 단추를 가리는 자리에는 띄우지 않는다(`pickTipBox`가 null이면 띄우지 않음).
13. **넓은 창(840px 이상)에서 본문 글은 `--m-measure`, 목록·설정·도구 화면은 `--m-content-max`로 가운데에 둔다.** 한글 흐름 보기의 좌우 여백은 0이 되지 않는다.
14. **그림자는 `--m-elev-*`만 쓴다.** 바·막대·카드에는 그림자가 없다. 번짐 없는 고리(`[inset] 0 0 0 Npx var(…)`)는 테두리 대용이라 허용한다. 반투명 면은 쓰지 않는다.
15. **강조 띠(왼쪽 색 막대 등)를 넣지 않는다.**
16. **겉모습은 하나다.** 토큰과 부품에 `ios`·`android` 갈래를 두지 않는다.

## 공용 부품 (`apps/mobile/src/renderer/ds/`)

부품은 글을 갖지 않는다. 이름·설명·단추 글은 부르는 쪽 트랙이 자기 문구 묶음에서 넘긴다. 기존 공용 클래스가 있는 것은 그 클래스를 그리고, 새 모양은 `ds/ds.css`의 `ds-*` 클래스에만 둔다(이 파일을 실어도 기존 `mobile-*` 모양은 바뀌지 않는다). `ds/index.ts`를 가져와야 `ds.css`가 묶음에 들어간다.

| 부품                                       | 그리는 것                                                                      | 상태·접근성                                                         |
| ------------------------------------------ | ------------------------------------------------------------------------------ | ------------------------------------------------------------------- |
| `Icon`, `iconPx`, `ICON_SIZE`              | `SvgIcon` + 크기 이름                                                          | 장식 `aria-hidden`                                                  |
| `Button`                                   | `mobile-touch-btn` + `mobile-btn-primary`/`secondary`/`ghost`/`danger-text`    | 기본·눌림·끔·기다림(`aria-busy`, 폭 유지, 돌림표)                   |
| `IconButton`                               | `mobile-icon-btn`(둥근 모양 `ds-icon-btn-round`)                               | 이름 필수, 토글이면 `aria-pressed`                                  |
| `Chip`                                     | `home-frame-chip` + 누를 영역 48                                               | `aria-pressed`                                                      |
| `ChoiceGroup`                              | `mobile-choice-btn` 타일·칸 나눔                                               | `radiogroup`/`radio`, `aria-checked`, 화살표로 옮김, 끈 타일 건너뜀 |
| `Swatch`                                   | 문서 색 견본                                                                   | 색 이름, `aria-pressed`                                             |
| `Switch`, `SwitchRow`                      | `input[type=checkbox][role=switch].mobile-switch`, 줄은 `label.mobile-set-row` | 켬·끔·끔(누를 수 없음)                                              |
| `SettingsGroup`                            | `h2.mobile-section-heading` + `.mobile-set-card`(줄이 곧바로 아래) + 설명      | S0 설정 시험의 모양 그대로                                          |
| `ListRow`                                  | 한 줄·두 줄                                                                    | 고름 `aria-pressed`, 지금 `aria-current`, 위험, 끔                  |
| `ActionList`                               | `mobile-menu-stack` + `mobile-menu-row-btn`                                    | `menu`/`menuitem`, 아이콘 없는 줄은 그리지 않음                     |
| `ScreenHeader`                             | 제목 `h1`                                                                      | —                                                                   |
| `EmptyState`                               | `mobile-empty-state` + `mobile-empty-icon`                                     | 제목 `h2`                                                           |
| `StickyActions`                            | 아래 고정 줄(키보드·안전 영역 위)                                              | —                                                                   |
| `InlineNotice`                             | 문서 위 알림 띠                                                                | `role="status"`                                                     |
| `FloatingTools`, `PageIndicator`           | 떠 있는 줄                                                                     | `toolbar` 이름, 쪽 글 낭독 이름                                     |
| `Spinner`, `LinearProgress`, `DocSkeleton` | 진행                                                                           | `progressbar`, `aria-busy`, 300ms 지연                              |
| `canShowTip`, `pickTipBox`                 | 말풍선 자리 판정                                                               | —                                                                   |

**떠 있는 줄의 약속.** 셸의 보기 도구와 트랙의 쪽 표시는 서로 다른 파일이 그린다. `EditorKind`에 자리를 더하지 않고, 둘 다 `--m-floating-*`와 `--m-z-floating`으로 자리를 잡는다. 셸 묶음과 트랙 묶음이 함께 나오면 트랙 묶음이 셸 묶음 왼쪽에 붙는다(셸이 `--m-floating-tools-w`를 내보냄, 뒤 단계).

## 지키는 시험

- `apps/mobile/tests/ds-guard.test.ts` — 화면 코드 전체를 훑는다.
  - (a) 선 아이콘에 숫자 크기를 적으면 위반이다(`size={20}`, `size="20"`, 여러 줄 포함). 식은 위반이 아니다.
  - (b) z-index는 토큰(`auto`·`0`·`-1`은 허용), 그림자는 `--m-elev-*`이거나 번짐 없는 고리여야 한다.
  - (c) 고른 상태 규칙(`[aria-pressed='true']` 등)이 고른 것·지금·주 동작 토큰만 써야 한다. 스위치 `:checked`는 대상이 아니다.
  - 앞 단계 전부터 어기던 파일은 **파일마다** 허용 목록에 있다(선 아이콘 47, 겹침·그림자 19, 고른 것 11). 새 파일은 처음부터 검사받는다. 허용 목록에 새 파일을 더하지 않는다. 뒤 단계에서 고친 파일부터 목록에서 뺀다.
