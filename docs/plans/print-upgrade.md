# 인쇄 기능 고도화 계획

상태: **구현됨(사람 확인 남음)**(2026-11-23, 결정 [0163](../tracking/decisions/0163-print-upgrade-destination-preview-overlays.md)). 기존 고급 인쇄 배치(결정 [0141](../tracking/decisions/0141-advanced-print-layout.md), [0158](../tracking/decisions/0158-rust-print-layout-wasm.md)) 위에서 10개 편집기의 인쇄 출력 대상·미리보기·배치·오버레이·한글 범위를 한 번에 고도화한다.

## 1. 목표

1. **출력 대상 드롭다운 통합**: 모든 편집기의 프린터 선택 목록에 `기본 프린터` · `설치된 프린터` · `PDF로 저장` · `그림으로 저장` · `시스템 인쇄 창`을 통합한다. 고급 배치를 켜지 않은 기본 상태에서도 `Ctrl+P` 안에서 바로 PDF·그림으로 저장한다.
2. **그림으로 저장(PNG / JPG, 개별 / ZIP)**: 1면은 지정한 이름으로 1파일, 2면 이상은 연번 파일(`이름-01.png`…, `numberedExportPaths`) 또는 UTF-8 STORE ZIP 1파일로 저장한다. JPG 품질은 3단계(높음 90 / 보통 80 / 작은 용량 65), 기본 형식은 PNG, 기본 해상도는 자동(200dpi, 대용량 150dpi 하한)이다.
3. **권한 제한 PDF 일관 차단**: 결정 0141의 배치 PDF 저장 제한과 동일하게, 권한 제한이 걸린 PDF에서는 드롭다운의 `PDF로 저장`·`그림으로 저장`을 비활성화하고 사유를 한 줄 안내하며, 메인 프로세스 IPC에서도 이중 차단한다.
4. **10개 편집기 라이브 미리보기 통일**:
   - 미리보기가 없던 5종(PDF·HTML·마인드맵·다이어그램·화이트보드)을 좌/우 분할 라이브 미리보기 창으로 격상한다.
   - 기존 미리보기가 있는 5종(워드·엑셀·슬라이드·마크다운·한글)은 고급 배치·회색조·워터마크·머리글/바닥글이 켜지면 도식 대신 **보이는 면부터 온디맨드 PDFium 지연 렌더링** 실제 미리보기로 자동 전환한다.
   - 중복되는 패널 하단의 "결과 미리 보기" / "배치한 결과를 PDF로 저장" 버튼은 제거한다.
5. **실무 인쇄 기능 확장**:
   - 상단바 빠른 인쇄 스플릿 버튼(`[ 🖨 | ▾ ]`): 10개 편집기 상단 빠른 실행 줄(한글은 우상단 바, 다이어그램은 캔버스 우상단, 화이트보드는 헤더 인쇄 버튼 업그레이드)에 공통 배치한다. 본체 클릭은 기본으로 인쇄 미리보기 창을 열어 오클릭 사고를 막고, `▾` 메뉴에서 바로 인쇄(OS 기본 프린터·1부)·인쇄 미리보기·PDF로 저장·그림으로 저장 및 앱 전체 `아이콘 클릭 시 바로 인쇄` 전환을 제공한다. 바로 인쇄 시 20쪽 이상 문서는 확인 창(취소·인쇄 창 열기·바로 인쇄)을 띄우고, 설치된 프린터가 없으면 인쇄 창으로 자연스럽게 안내한다.
   - 한글 편집기 페이지 범위 지정(전체·현재 쪽·특정 쪽 `1-3, 5`).
   - 배율 4모드(`실제 크기 100%` / `용지에 맞춤` / `큰 쪽만 축소` / `사용자 지정 %`), 방향 강제 전환(`자동` / `세로` / `가로`), 모아찍기 쪽 테두리 선, 포스터 타일 좌표 라벨.
   - 인쇄 전용 워터마크(글자·그림, 최종 출력 면 기준) 및 6칸(상·하 × 좌·중·우) 머리글/바닥글.
6. **기존 불변 원칙 유지**: 열 때마다 기본값으로 시작(직접 입력 라벨 규격만 유지), 기본값 OS 인쇄 경로 보존, `./plan` 무의존 경계, 22개 언어(`tr` 포함), CSS 토큰, 문서 엔진 불변.
