# 고급 인쇄 계획

상태: **구현됨**(2026-11-14). 실제 프린터와 빌드한 앱에서의 확인이 남았다(`docs/tracking/findings.md`). 정한 것은 결정 기록 [0141](../tracking/decisions/0141-advanced-print-layout.md)에 있다. 구현하면서 이 문서를 고친다.

## 1. 무엇을 하려는가

인쇄가 있는 모든 문서 편집기(워드·PDF·엑셀·슬라이드·한글·마크다운·HTML·마인드맵·다이어그램)에 같은 고급 인쇄 선택지를 넣는다.

- 홀수 면만·짝수 면만, 역순
- 한 장에 여러 쪽(2·4·6·9·16, 가로 줄 먼저·세로 줄 먼저)
- 소책자(왼쪽·오른쪽 묶기, 같은 종이에 반 크기 책)
- 포스터(가로×세로 장 수, 겹침 폭, 재단선)
- 라벨(같은 쪽 반복·쪽마다 한 칸씩, 시작 칸, 흔한 A4 규격과 직접 입력)
- 회색조, 용지에 맞춰 줄이기, 그림 해상도(자동·150·300·600)
- 선택한 부분만 인쇄(워드·마크다운·엑셀·슬라이드·PDF)
- 배치도와 결과 미리 보기, 배치한 결과를 PDF로 저장

EPUB은 인쇄 기능이 없어 뺀다. 한글·마인드맵·HTML·다이어그램에는 선택 인쇄를 넣지 않는다(까닭은 결정 0141).

## 2. 확인한 것 (2026-11-13)

### 편집기마다 지금 인쇄하는 법

| 편집기     | 지금                                                                                                                | 인쇄할 PDF를 만드는 곳                    |
| ---------- | ------------------------------------------------------------------------------------------------------------------- | ----------------------------------------- |
| 워드       | 자기 화면(쪽 미리 보기)을 `webContents.print`. 앱 안 프린터·매수·한 벌씩·양면·범위. macOS 앱 안 프린터는 PDF → `lp` | PDF 내보내기의 쪽별 `printToPDF`와 합치기 |
| PDF        | 쪽을 200dpi JPEG로 바꿔 `window.print()`. 범위·주석 포함                                                            | 저장된 파일 바이트                        |
| 엑셀       | 인쇄용 HTML을 숨은 창에서 `print`. 범위(시트·통합 문서·선택)·배율·용지·여백. 미리 보기 있음                         | 같은 HTML을 `printToPDF`                  |
| 슬라이드   | 슬라이드 그림을 싣는 인쇄용 HTML을 숨은 창에서 `print`. 범위·유인물·노트. 미리 보기 있음                            | 같은 HTML을 `printToPDF`                  |
| 한글       | 쪽마다 SVG인 인쇄용 HTML을 숨은 창에서 `print`. 인쇄 미리 보기 있음                                                 | PDF 저장과 같은 `printToPDF`              |
| 마크다운   | 인쇄용 HTML을 숨은 창에서 `print`. 미리 보기는 `printToPDF` 결과                                                    | 미리 보기 PDF 그대로                      |
| HTML       | 인쇄 창 없이 바로 시스템 인쇄 창                                                                                    | 인쇄 창과 같은 조건으로 `printToPDF`      |
| 마인드맵   | 보고 있는 시트를 A4 가로 한 장에 맞춰 바로 시스템 인쇄 창                                                           | 같은 한 장을 `printToPDF`                 |
| 다이어그램 | 모든 쪽을 바로 시스템 인쇄 창                                                                                       | 같은 HTML을 `printToPDF`                  |
| EPUB       | 인쇄 없음                                                                                                           | —                                         |

### Electron 인쇄 선택지(Electron 43, 소스·이슈로 확인, 실제 인쇄는 안 함)

| 선택지                        | 결과                                                                          |
| ----------------------------- | ----------------------------------------------------------------------------- |
| `pagesPerSheet`               | 세 운영체제 모두 아무 일도 하지 않는다                                        |
| `pageRanges`                  | Windows 창은 받음. macOS는 첫 구간만                                          |
| `color:false`                 | 드라이버가 정한다                                                             |
| `duplexMode`·`landscape`·매수 | 창 없이 인쇄할 때만 쓰인다. Windows 시스템 창은 버리고 프린터 기본값에서 시작 |
| `dpi`                         | 정하지 않으면 프린터 기본값                                                   |

그래서 홀짝·역순·모아찍기·소책자·포스터·라벨·회색조·용지 맞춤은 앱이 PDF에서 해야 한다.

## 3. 흐름

```
편집기 ─ 인쇄할 쪽을 PDF로(범위·선택·편집기 자기 배치 반영)
   → 공용 배치(@genoffice/print-layout) ─ 쪽을 다시 놓은 PDF(글자는 글자로)
   → (회색조면) 면마다 회색 그림 PDF
   → 공용 보내기 ─ 쪽 그림 파일 → 숨은 창 → 시스템 인쇄 창 또는 앱 안 프린터
                    (가로 면은 이때만 90° 돌림, macOS 앱 안 프린터는 PDF를 lp로)
```

- 공용 칸에서 아무것도 고르지 않으면 편집기의 지금 인쇄가 그대로 돈다.
- 쪽 그림은 별도 작업 스레드에서 한 면씩 파일로 만든다. 진행(몇 면 중 몇 면)과 취소가 있고, 취소·실패면 아무것도 보내지 않고 임시 파일을 지운다.

## 4. 화면

- **쪽 배치 칸**(공용): 배치 방식(한 장에 한 쪽·여러 쪽·소책자·포스터·라벨 중 하나)과 그 선택지, 홀짝·역순, 용지·맞춤(편집기가 허락할 때), 회색조, 해상도, 배치도, 결과 미리 보기, PDF로 저장. 열 때마다 기본값. 직접 적은 라벨 규격만 기억한다.
- **붙이는 곳**: 워드·PDF·엑셀·슬라이드·마크다운의 인쇄 창, 한글의 인쇄 미리 보기. HTML·마인드맵·다이어그램은 범위와 이 칸만 든 작은 인쇄 창을 새로 둔다(아무것도 바꾸지 않고 인쇄하면 지금과 같다).
- **겹칠 때**: 슬라이드는 "전체 슬라이드"일 때만 배치 방식을 고른다. 엑셀·마크다운은 자기 용지·맞춤 칸을 쓴다. 쪽 범위와 배치는 앱 인쇄 창에서만 정한다. 워드 양면은 홀짝이면 꺼지고 소책자면 짧은 쪽 넘김.
- **미리 보기**: 배치를 켜면 편집기의 원래 미리 보기 자리에 배치도가 보인다. 끄면 돌아온다.
- **선택 인쇄**: 워드·마크다운은 범위에 "선택 영역"(고른 글만 첫 쪽부터 다시 쪽을 나눔), 슬라이드는 "고른 슬라이드", PDF는 "고른 쪽". 엑셀은 지금 그대로.
- 문구는 22개 언어. 도움말 "파일 다루기"의 인쇄 절을 고친다.

## 6. 확인

- 쪽마다 표식 글자("P1"…)와 서로 다른 크기를 가진 시험용 PDF를 만들어 배치하고, 결과 PDF에서 면 수·면 크기·칸마다의 표식·회색 그림의 색 공간을 읽어 판정한다. 소책자 8쪽은 [8|1] [2|7] [6|3] [4|5]여야 한다.
- 편집기마다 기본값 인쇄가 지금과 같은 인수로 불리는지 지키는 시험을 둔다.
- 실제 프린터로 찍지 않고, 이 PC에서 앱을 띄우지 않는다. 드라이버가 쪽 그림 인쇄를 받는 방식, 돌린 가로 면의 양면 방향, macOS `lp`의 회전은 사용자 보고로 확인한다.
